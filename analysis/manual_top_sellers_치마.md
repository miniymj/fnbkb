## 분석 인사이트

### 성공 요인
1. **상황 수요 안정** — 하객룩·면접·오피스 등 의무적·반복적 수요. 계절·유행 덜 탐(치마가 유일 +성장 카테고리인 배경).
2. **체형 커버 핏** — A라인 플레어·뒷밴딩·허리밴딩이 4050·빅사이즈 핵심 니즈. "뱃살/옆구리 커버" 후기 다수.
3. **가격대 양극화** — 가성비(글램디브 2만원대) vs 프리미엄(마인 10만원대). 중간~중상(3~8만)이 우리 진입 지점.

### 벤치마킹 포인트
- **퍼플리아**: 소재 명시(비스코스/리오셀 100%) — 정보성 신뢰 + 시즌별 BEST 큐레이션
- **마인**: "싼 옷 여러 벌보다 제대로 된 옷 한 벌" — 프리미엄 스토리텔링
- **마마걸/카카오**: 빅사이즈 + 허리밴딩 기능성 — 체형 솔루션

### 개선 기회 (우리 공략 포인트)
- **상황 × 체형 큐레이션** — 퍼플리아가 "스타일"로 파는 걸, 우리는 **"면접·하객·데이트 상황 + 키별 기장(미니/미디/롱)"** 매트릭스로 차별
- **캘린더 마케팅** (`skirt-market-research.md`): 3~4월 봄 면접룩, 5~6월 하객룩 — 계절별 상황 타겟팅
- **니치 가격 진입** — 마인(10만+)·SSG(7~8만)보다 낮은 3~5만원대로 중간대 공백 공략
- **실구매 니치 키워드 SEO** — 테니스스커트(CTR 4.42%)·플리츠스커트(월검색 18,170) 등 하꼬가 안 쓰는 전환 키워드
