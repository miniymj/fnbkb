## 분석 인사이트

### 성공 요인
1. **사이즈 스펙트럼** — 리리앤코(44~120)·우리다움(66~130)이 사이즈로 차별화. 사이즈프리는 검증된 USP.
2. **SNS 퍼널** — 아뜨랑스 검색량 92,100. 인스타·틱톡이 트래픽 핵심. 4050층도 릴·쇼츠로 유입("trendora_4050" 계정 등 전문 채널 등장).
3. **상황형 마케팅** — 리리앤코의 하객/오피스/데이트/바캉스 태그가 전환율 견인. 하객룩 원피스는 2~8만원대(글램디브 28,900원~SSG 77,425원)로 시장 형성.
4. **통기성 소재 + 체형 디테일** — 레이온·린넨 혼방 + A라인/셔링/허리 리본/밴딩이 통통 체형에 유리. "몸에 달라붙지 않는 가벼운 소재" 후기 다수.

### 벤치마킹 포인트
- **리리앤코**: 상황형 스타일 태그 + 멀티 채널(지그재그·에이블리·G마켓) + 린넨 라인 확장
- **타이니모**: 정교한 실측 사이즈 차트 + 체형별 후기 (신뢰 신호)
- **무이/마이엘린스토어**: 4050·5060 빅사이즈 휴양지룩 1년 내내 판매 + 틱톡 콘텐츠

### 개선 기회 (우리 공략 포인트)
- **가격 + 니치** — 리리앤코보다 저렴(2~4만)하면서, 그들이 약한 **"린넨·레이온 통기성 휴양지원피스 44~120"**로 차별 (현재 결합 키워드 전무 → 선점)
- **캘린더 마케팅** — 봄·가을 성수기(원피스 계절성: 9~11월 65~89 회복) + 여름 휴양지 수요 결합
- **지그재그·에이블리 입점** — 리리앤코·무이가 쓰는 채널에서 가시성 확보
- **실측 사이즈 차트 + 체형별 후기** — 하꼬 공통 약점(신뢰 신호 부족) 정면 공략
