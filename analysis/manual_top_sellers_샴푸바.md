1. **가격대 양극화** — 하꼬(8천~1만원대, 비누옹달샘·케세리·동구밭) vs 프리미엄(1.7~2.2만원, 아로마티카). 중간대(1.2~1.8만원)가 우리 자리.
2. **천연·숙성 스토리** — 비누옹달샘의 "6주 숙성·2011년부터 100% 천연"이 신뢰 자산. 스토리텔링이 곧 가격 정당성.
3. **묶음·세트 구성** — 비누옹달샘 5개 묻음(41,670원), 동구밭 기획세트로 객단가 상승 + 진입장벽 완화를 동시 수행.

- **동구밭** 계단식 업셀 + 무료배송 진행률 바 (0원~30,000원)
- **아로마티카** 올리브영 1위 배지 + 8월 올영픽 = 채널 신뢰 신호
