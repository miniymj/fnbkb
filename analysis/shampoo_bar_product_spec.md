## 🎯 포지셔닝

### 브랜드 컨셉
- **명칭**: (가칭) 퓨어바 (PureBar)
- **태그라인**: 지속 가능한 뷰티의 시작
- **핵심 가치**: 친환경, 비건, 제로 웨이스트

### 타겟층
- **프라이머리**: 2030 여성 (환경 의식较高的 소비자)
- **세컨더리**: 3040 직장인 (프리미엄 선호)
- **터셔어리**: 여행객 (휴대성 선호)

## 📦 제품 스펙

### 기본 사양
| 항목 | 내용 |
|:---|:---|
| **형태** | 솔리드 바 (고체) |
| **무게** | 80g / 100g |
| **사용 횟수** | 약 50~70회 (80g 기준) |
| **보관 방법** | 건조한 곳, 전용 케이스 |
| **유통기한** | 제조일로부터 12개월 |

### 제형 옵션
1. **스탠다드**: 80g (일반용)
2. **트래블**: 50g (여행용)
3. **이코노미**: 120g (가족용)

## 🌿 성분 구성

### 베이스 (Base)
- **SLS/SLES Free**: 비이온 계면활성제
- **코코넛 오일**: 클렌징 + 보습
- **시어 버터**: 모발 보호
- **피마자유**: 거품 형성

### 기능성 추가 성분
- **판테놀**: 모발 강화
- **비오틴**: 두피 건강
- **아르간 오일**: 모질 개선
- **티트리 오일**: 두피 진정 (항균)

### 향료 옵션 (한국적 향)
1. **유자 (Yuzu)**: 상큼한 시트러스
2. **유칼리투스 (Eucalyptus)**: 청량감
3. **소나무 (Pine)**: 포레스트
4. **쌀뜨물 (Rice Water)**: 한국적 미묘한 향
5. **무향 (Unscented)**: 순수

## 🎨 패키지 디자인

### 주요 요소
- **컬러**: 지속 가능한 컬러 (녹색, 베이지, 갈색 톤)
- **소재**: 재활용 가능한 종이, 생분해성 필름
- **형태**: 박스 타입 + 전용 케이스 (별도 판매)
- **문구**: "플라스틱 1개를 줄이면 지구가 살아갑니다"

### 라벨링
- 제품명, 무게, 성분, 사용법
- 비건 인증 마크 (추후 획득)
- 친환경 인증 마크 (추후 획득)
- 제조일자, 유통기한

## 📝 사용법

### 추천 사용법
1. **젖은 모발**: 바를 촉촉하게 적신다
2. **거품**: 두 손으로 문질러 거품을 낸다
3. **마사지**: 두피에 바르고 2-3분 마사지
4. **헹굼**: 깨끗이 헹군다
5. **건조**: 통풍이 잘되는 곳에 보관

### 주의사항
- 눈에 들어가지 않도록 주의
- 알레르기 체크 후 사용
- 직사광선 피해서 보관
