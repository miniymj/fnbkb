# MD 라인업 설계 — 바디바

> 작성일: 2026-08-03
> 카테고리: 바디바 (온 가족 친환경 컨셉)
> 경쟁사 벤치마크: 톤28, 동구밭, 시드물

---

## MD 라인업 4단계 구조

```
① 미끼상품 (Entry) → ② 메인상품 (Core) → ③ 프리미엄 (Premium) → ④ 세트/번들 (Bundle)
```

---

## ① 미끼상품 (Entry) — 첫 경험

| 항목 | 내용 |
|------|------|
| **목적** | 가족 체험용, 여행 휴대용 진입장벽 최저화 |
| **제품** | 미니 바디바 30g (단품) |
| **가격** | 3,900원 (정가) / 2,900원 (첫 구매 할인) |
| **포지셔닝** | "가족과 함께 첫 경험, 여행의 필수품" |
| **타겟** | 바디바 입문자, 여행/체험용 수요, 아이 피부 걱정 부모 |

---

## ② 메인상품 (Core) — 수익의 핵심

| 항목 | 내용 |
|------|------|
| **목적** | 가장 많이 팔리고 리뷰가 쌓이는 대표 상품 |
| **제품** | 바디바 100g (정품) |
| **가격** | 9,800원 (정가) |
| **포지셔닝** | "가족의 피부, 자연으로 씻기다" |
| **핵심 차별점** | 온 가족 사용 가능, 알레르기 프리, 딥 클렌징 + 보습 |

### 상세 스펙

| 구분 | 내용 |
|------|------|
| **성분** | 천연 계면활성제, 쌀겨추출물, 올리브유, 알로에 |
| **기능** | 딥 클렌징, 보습, 진정 |
| **향** | 무향, 라벤더, 시트러스 3종 |
| **특징** | 눈에 들어가도 찡하지 않음, 삼켜도 안전 |

---

## ③ 프리미엄 (Premium) — 객단가 UP

| 항목 | 내용 |
|------|------|
| **목적** | 소재·기능·한정판으로 프리미엄 부각, 매출 20~30% 목표 |
| **제품** | 프리미엄 바디바 120g + 아로마 세럼 10ml |
| **가격** | 16,800원 |
| **포지셔닝** | "프리미엄 자연 원료, 스파 같은 샤워 타임" |
| **프리미엄 요소** | 한정판 아로마(라임·버베나), 천연 에센셜 오일 증정 |

---

## ④ 세트/번들 (Bundle) — 재구매율 × 객단가

| 항목 | 내용 |
|------|------|
| **목적** | 재구매율과 객단가 동시 상승, 가족 전용 세트 |
| **제품 구성** | 바디바 100g × 3개 |
| **가격** | 24,000원 (단품 29,400원 대비 18% 할인) |
| **포지셔닝** | "가족 3개월 분량, 자연으로 씻기다" |

### 추가 번들 옵션

| 번들명 | 구성 | 가격 | 할인율 |
|--------|------|------|--------|
| **입문 세트** | 미니 30g + 정품 100g | 11,000원 | 18% |
| **3개 번들** | 정품 100g × 3개 | 24,000원 | 18% |
| **가족 세트** | 정품 100g × 5개 | 35,000원 | 29% + 무료배송 |
| **여행 세트** | 바디바 100g + 거품망 + 휴대용 파우치 | 14,000원 | 20% |

---

## 5가지 상품구성 방식 적용

### 1. 정기구독 (Subscription)

| 항목 | 내용 |
|------|------|
| **구조** | 2달/3달 자동 배송 + 10% 할인 |
| **타겟** | 재구매 가정, 소모성 주기 구매자 |
| **혜택** | 10% 할인 + 무료배송 + 한정판 향 우선권 |
| **경쟁사 벤치마크** | 톤28 크루할인 → 더 간편한 구독 모델 |

### 2. 묶음판매 (Bundle)

| 항목 | 내용 |
|------|------|
| **구조** | 3개 세트 = 무료배송 진입 (24,000원) |
| **타겟** | 배송비 민감 가정주부, 가격 합리적 소비자 |
| **경쟁사 벤치마크** | 동구밭 무료배송 프로그레스바 → 명시적 금액 기준 |

### 3. 업셀 (Upsell)

| 항목 | 내용 |
|------|------|
| **구조** | 무향 → 라벤더/시트러스 → 한정판 아로마 |
| **옵션** | 100g → 120g 프리미엄 + 에센셜 오일 증정 |
| **경쟁사 벤치마크** | 동구밭 계단식 세트 → 단순명료한 3단계 구조 |

### 4. 크로스셀 (Cross-sell)

| 항목 | 내용 |
|------|------|
| **구조** | 바디바 + 샴푸바 + 거품망 + 파우치 |
| **타겟** | 친환경 라이프스타일 전체 구매자 |
| **경쟁사 벤치마크** | 톤28 제로웨이스트 크로스셀 → 바디+샴푸 연결 |

### 5. 예약판매 (Pre-order)

| 항목 | 내용 |
|------|------|
| **구조** | 시즌 한정판 여행 세트 얼리버드 20% 할인 |
| **타겟** | 여행 시즌 구매자, 한정판 선호층 |
| **목적** | 수요 검증 + 초기 자금 확보 + 재고 리스크 최소화 |
