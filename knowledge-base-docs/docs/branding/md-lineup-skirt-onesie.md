# MD 라인업 설계 — 스커트/원피스

> 작성일: 2026-08-03
> 카테고리: 스커트/원피스 (상황별 스타일링 컨셉)
> 경쟁사 벤치마크: 케네스레이디, 써스데이아일랜드, 타이니모

---

## MD 라인업 4단계 구조

```
① 미끼상품 (Entry) → ② 메인상품 (Core) → ③ 프리미엄 (Premium) → ④ 세트/번들 (Bundle)
```

---

## ① 미끼상품 (Entry) — 첫 경험

| 항목 | 내용 |
|------|------|
| **목적** | 가격 부담 없이 브랜드 첫 경험 제공 |
| **제품** | 플리츠 미니 스커트 (단품) |
| **가격** | 19,000원 (정가) / 15,200원 (첫 구매 20% 할인) |
| **포지셔닝** | "상황별 핏, 첫 스타일의 시작" |
| **타겟** | 면접/하객/캐주얼 입문자 |

---

## ② 메인상품 (Core) — 수익의 핵심

| 항목 | 내용 |
|------|------|
| **목적** | 가장 많이 팔리고 리뷰가 쌓이는 대표 상품 |
| **제품** | 플리츠 미디 스커트 (셔링·랩 디테일) |
| **가격** | 29,000원 (정가) |
| **포지셔닝** | "갑갑하지 않은 세상에서 가장 편한 스커트" |
| **핵심 차별점** | 조절식 웨이스트, 신축성 소재, 셔링·랩 체형 커버 |

### 상세 스펙

| 구분 | 내용 |
|------|------|
| **사이즈** | 44 ~ 99 (7cm 간격) |
| **소재** | 폴리에스터 95% + 스판덱스 5% (신축성) |
| **기장** | 미니(45cm) / 미디(65cm) / 맥시(85cm) |
| **색상** | 블랙, 네이비, 베이지, 그레이 4종 |
| **디테일** | 셔링, 랩, 조절식 웨이스트밴드, 주머니 |

---

## ③ 프리미엄 (Premium) — 객단가 UP

| 항목 | 내용 |
|------|------|
| **목적** | 소재·디자인·한정판으로 프리미엄 부각, 매출 20~30% 목표 |
| **제품** | 프리미엄 플리츠 원피스 (린넨 혼방) |
| **가격** | 49,000원 |
| **포지셔닝** | "상황별 완벽한 핏, 첫인상의 완성" |
| **프리미엄 요소** | 린넨 혼방 소재, 한정판 컬러, 브랜드 태그 증정 |

---

## ④ 세트/번들 (Bundle) — 재구매율 × 객단가

| 항목 | 내용 |
|------|------|
| **목적** | 재구매율과 객단가 동시 상승, 코디 세트 |
| **제품 구성** | 스커트 2종 (미디 + 미니) |
| **가격** | 45,000원 (단품 58,000원 대비 22% 할인) |
| **포지셔닝** | "상황별 코디, 한 번에 완성" |

### 추가 번들 옵션

| 번들명 | 구성 | 가격 | 할인율 |
|--------|------|------|--------|
| **입문 세트** | 미니 스커트 + 베이직 블라우스 | 35,000원 | 20% |
| **오피스 세트** | 미디 스커트 + 셔츠 + 자켓 | 65,000원 | 25% |
| **캐주얼 세트** | 미니 스커트 + 티셔츠 2종 | 40,000원 | 22% |
| **봄 시즌 세트** | 플리츠 원피스 + 가디건 | 55,000원 | 18% |

## 5가지 상품구성 방식 적용

### 1. 정기구독 (Subscription)

| 항목 | 내용 |
|------|------|
| **구조** | 시즌별 신상 구독 + 10% 할인 + 멤버십 5% |
| **타겟** | 시즌 패션 따라가는 고객, 재구매층 |
| **혜택** | 시즌 신상 우선권 + 한정판 컬러 예약 |
| **경쟁사 벤치마크** | 시드물 목요이벤트 → 시즌별 정기 구독 모델 |

### 2. 묶음판매 (Bundle)

| 항목 | 내용 |
|------|------|
| **구조** | 2종 세트 = 무료배송 진입 (45,000원) |
| **타겟** | 배송비 민감 고객, 코디 한번에 원하는 층 |
| **경쟁사 벤치마크** | 동구밭 기획세트 → 상황별 코디 세트 |

### 3. 업셀 (Upsell)

| 항목 | 내용 |
|------|------|
| **구조** | 미니 → 미디 → 프리미엄 원피스 |
| **옵션** | 베이직 → 린넨 혼방 → 실크 한정판 |
| **경쟁사 벤치마크** | 동구밭 계단식 세트 → 단순명료한 3단계 구조 |

### 4. 크로스셀 (Cross-sell)

| 항목 | 내용 |
|------|------|
| **구조** | 스커트 + 블라우스 + 가디건 + 벨트 |
| **타겟** | 상황별 풀 코디 구매자 (면접/하객/오피스) |
| **경쟁사 벤치마크** | 케네스레이디 하객룩 → 상황별 큐레이션 강화 |

### 5. 예약판매 (Pre-order)

| 항목 | 내용 |
|------|------|
| **구조** | 시즌 한정판 컬러 얼리버드 20% 할인 |
| **타겟** | 시즌 트렌드 민감층, 한정판 선호층 |
| **목적** | 수요 검증 + 재고 리스크 최소화 |

## 경쟁사 대비 차별점 요약

| 차별 요소 | 내용 |
|----------|------|
| **진입장벽** | 플리츠 미니 15,200원 (케네스레이디 10~40만원 대비 낮음) |
| **사이즈** | 44~99 폭 넓게 (타이니모 대비 inclusivity) |
| **체형 커버** | 셔링·랩 디테일 (갑갑하지 않는 핏) |
| **상황별** | 면접/하객/오피스 세트 분화 |
| **정기구독** | 시즌별 신상 구독 (패션 트렌드 실시간 대응) |
