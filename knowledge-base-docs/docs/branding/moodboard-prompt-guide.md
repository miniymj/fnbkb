## 🧼 프롬프트 1 — 하이피부 (HIGHSKIN) · Happy Natural Care

```text
한 장의 브랜드 무드보드를 생성해줘. 세로 9:16 포스터 캔버스에 10개 구역으로 구성된 그리드 레이아웃. 전체 배경은 크림(#FFF8EF), 흰색 카드 프레임, 둥근 모서리, 부드러운 드롭 섀도우.
브랜드: HIGHSKIN(하이피부) — "가족의 일상에 즐거운 목욕 습관을 만드는 브랜드". 온가족(아이·엄마·아빠) 바디 케어. 귀여운 얼굴 캐릭터 × 자연주의 색 안정감. 위글위글의 캐릭터성과 자연주의 브랜드의 신뢰를 함께.

컬러 팔레트(비율 50-20-12-7-8-5-3): Cream #FFF8EF(베이스 50%) / Soft Pink #F6A6B8(메인 20%) / Milk Pink #FCE8EC(12%) / Apricot #F4B27D(7%) / Soft Sage #AFC7A8(자연 8%) / Leaf Green #6F9470(5%) / Deep Brown #403735(텍스트 3%).
핵심: 핑크 브랜드지만 화면이 온통 핑크는 아니다 — 크림 베이스가 우세.

구역별 콘텐츠:
01 (좌측 상단, 2x2 대형) 귀여운 얼굴 캐릭터(둥근 형태·단순한 눈과 미소)가 비눗방울과 거품 사이에 있는 아늑한 욕실. 아이·엄마·아빠의 목욕 시간, 행복한 분위기.
02 컬러 팔레트 — 7색을 비율대로 가로 스트라이프 스와치, 각 색 아래 HEX 코드와 이름 표기.
03 주 텍스처 — 크림처럼 풍성한 거품, 부드러운 질감 클로즈업.
04 보조 텍스처 — 린넨 / 코튼 / 우드 / 세라믹(2x2 타일). 자연 소재의 안정감.
05 무드 메인 — 거품 목욕 중인 귀여운 캐릭터, 비눗방울과 아침 햇살.
06 무드 서브 — 아이와 함께하는 샤워, 가족의 웃음과 물보라.
07 (2칸 와이드) 라이프스타일 — 온가족이 함께하는 목욕 루틴, 여행용 미니 바디케어 키트.
08 패턴 · 그래픽 — 물방울·잎사귀·거품·구름·햇살. 둥근 곡선 라인 아트 패턴.
09 타이포그래피 — 라운드 산세리프 "Happy Natural Care" + 한글 태그라인 "가족이 함께 즐기는 작은 즐거움", 크림 카드 위 딥 브라운 #403735 텍스트.
10 소재 스와치 — 7색 원형 칩과 린넨·나무·돌·크라프트지·세라믹 소재 배열.

스타일: 귀엽지만 유치하지 않은, 따뜻하고 부드러운 자연광. 고채도 원색 금지, 강한 핑크(#FF4081 계열) 금지 — 소프트 핑크 #F6A6B8 유지. 위글위글 100% 팝아트가 아니라 캐릭터성 + 자연 색 안정감의 조화. 모든 텍스트는 한국어 우선.
```

## 👗 프롬프트 2 — 치마 (SKIRT) · Confident Curation

```text
한 장의 브랜드 무드보드를 생성해줘. 세로 9:16 포스터 캔버스에 10개 구역 그리드 레이아웃. 전체 배경은 웜 아이보리(#F7F4EF), 흰색 카드 프레임, 절제된 드롭 섀도우.
브랜드: SKIRT — "당당한 큐레이션(Confident Curation)". 상황(면접·하객·오피스) × 체형(키·밴딩)을 맞춰주는 치마 전문관. 타겟 19~45세 여성(취준생 29%, 직장인 22%, 하객 26%), "첫인상의 3초"를 위한 선택.

컬러 팔레트(네이비 앵커 35~40%): 넌 트루 네이비 #1B3A5C(Primary) / 웜 아이보리 #F7F4EF(여백) / 샌드 비스트 #C4A77D(따뜻한 큐레이션) / 블러시 코랄 #D4856A(자신감) / 소프트 라벤더 #A89BB5(포용·섬세함) / 인크 차콜 #2C2E31(품격·텍스트).

구역별 콘텐츠:
01 (좌측 상단, 2x2 대형) 패션 에디토리얼 — 네이비 블레이저로 깔끔하게 정돈한 여성, 단정한 자세, 격식 있는 조명. "첫인상의 3초"를 위한 당당함.
02 컬러 팔레트 — 6색 세로 스트라이프 스와치 + HEX 코드와 한글 이름, 네이비를 가장 넓게.
03 주 텍스처 — 테일러링 우븐·트위드 원단의 정제된 표면, 구조 있는 디테일.
04 보조 텍스처 — 린넨 주름 / 새틴 광택 / 플리츠 / 세일러 우브(2x2 타일).
05 무드 메인 — 오피스룩 컨피던스, 네이비 수트와 아이보리 블라우스.
06 무드 서브 — 웨딩 하객룩, 블러시 코랄 드레스와 라벤더 톤, 축제의 온기.
07 (2칸 와이드) 라이프스타일 — 출근길 커피를 든 직장인, 면접장 건물 앞 취준생, 웨딩홀 로비 하객 — 상황별 큐레이션 장면.
08 패턴 · 그래픽 — 테일러 스트라이프와 미니멀 체크 패턴, 구조적인 선.
09 타이포그래피 — 세리프 "Confident Curation" + 한글 "당당한 큐레이션" 태그라인, 아이보리 카드 위 인크 차콜 텍스트.
10 소재 스와치 — 6색 원형 칩과 트위드·우브·새틴 조각.

스타일: 프로페셔널한 편집화보 무드, 부드러운 스튜디오 조명, 미니멀한 여백. 원색·네온·캐주얼 스트릿 무드는 피할 것. 모든 텍스트는 한국어 우선, 얼굴은 젊은 성인 여성 다양성 포함.
```

## 🌊 프롬프트 3 — 원피스 (RESORT ONESIE) · Garden Sea

```text
한 장의 브랜드 무드보드를 생성해줘. 세로 9:16 포스터 캔버스에 10개 구역 그리드 레이아웃. 전체 배경은 세라믹 화이트(#F5F0EB), 흰색 카드 프레임, 은은한 드롭 섀도우.
브랜드: RESORT ONESIE — "바다의 정원(Garden Sea)". 체형과 디자인, 양자택일 없는 사이즈프리(44~120) 휴양지원피스. 타겟 40·50대 여성, 체형 스트레스를 내려놓고 바다를 바라보는 여유. "모두가 아름다운 바다".

컬러 팔레트(블루 앵커 40%): 라군 블루 #5B8FA8(Primary) / 세라믹 화이트 #F5F0EB(여백 25%) / 샌드 베이지 #C4A882(모래 15%) / 코랄 블러썸 #E8917A(자신감) / 소프트 세이지 #A8B5A0(포용·진정) / 딥 챠콜 #2C2C2C(품격·텍스트).

구역별 콘텐츠:
01 (좌측 상단, 2x2 대형) 푸른 바다 전경 — 수평선과 잔잔한 파도, 하늘과 바다의 라군 블루 그라데이션, 여유로운 휴양 분위기.
02 컬러 팔레트 — 6색 가로 스트라이프 스와치 + HEX 코드와 한글 이름, 라군 블루를 가장 넓게.
03 주 텍스처 — 바다 표면의 질감, 수평선의 곡선 — 원피스 실루엣의 은유.
04 보조 텍스처 — 시원한 린넨 / 섬세한 레이스 / 편안한 코튼 / 햇볕에 마른 소재(2x2 타일).
05 무드 메인 — 리조트 풀사이드의 여성, 조절식 웨이스트의 여유로운 실루엣, 라군 블루 드레스.
06 무드 서브 — 해변의 바람, 셔링·랩 디테일로 체형을 감싸는 원피스.
07 (2칸 와이드) 라이프스타일 — 캐리어 위에 접힌 리넨 원피스, 비치클럽에서 선셋 디너로 이어지는 휴양 하루.
08 패턴 · 그래픽 — 트로피컬 플로럴과 라군 웨이브 프린트, 부드러운 곡선 패턴.
09 타이포그래피 — 세리프 "Garden Sea" + 한글 "바다의 정원" 태그라인, 세라믹 화이트 카드 위 딥 챠콜 텍스트.
10 소재 스와치 — 6색 원형 칩과 린넨·레이스·코튼 조각.

스타일: 햇살이 투과하는 밝은 자연광, 에어리한 휴양지 무드, 체형을 비판하지 않는 포용적 이미지(다양한 사이즈 여성). 원색 레드·자극적 할인광고 무드는 피할 것. 모든 텍스트는 한국어 우선.
```

## ⚙️ 공통 사용 가이드

| 목적 | 방법 |
|---|---|
| **팔레트 고정** | 프롬프트의 HEX를 그대로 사용. 무시될 경우 ②구역 스와치만 먼저 생성 → 편집 모드로 해당 부분 재생성 |
| **부분 리파인** | 전체 생성 후 마음에 안 드는 구역만 "이 타일만 교체해줘, 같은 팔레트·같은 조명 유지" 지시 |
| **시드 유지** | 연속 챗으로 진행 — 문맥 유지 시 색감·레이아웃 안정적 |
| **텍스트 오류** | 한국어/영문 텍스트가 깨지면 "텍스트는 간소화하고 브랜드명만 남겨줘" 후 편집 합성 |
| **비율** | 9:16(세로 포스터)이 스토어·SNS 최적. 4:5·1:1 대응 시 스와치만 재배치 |
| **캐릭터 리소스** | 하이피부는 캐릭터를 별도 생성(동일 스타일 시드) 후 편집 합성 권장 |
| **저작권** | 상업 사용 전 나노바나 프로 이용약관(수익화 권리) 확인 |

## 프롬프트 A — 패키지 인쇄용 (컬러 콜라주 로고)

```text
브랜드 로고를 생성해줘 — HIGHSKIN(하이피부), 온가족 바디케어 브랜드의 메인 로고. 패키지 인쇄용.

구성: 2x3 격자(6칸) 직사각형 타일 콜라주. 각 타일 안에는 서로 다른 표정을 지은 "아이가 그린 듯한" 손그림 얼굴이 하나씩.
- 타일 1 (행복): 입을 크게 벌리고 웃는 얼굴
- 타일 2 (스파 휴식): 눈을 감고 편안한 얼굴 (뜨거운 목욕의 표정)
- 타일 3 (놀람): 거품을 보고 반짝이는 눈으로 놀란 얼굴
- 타일 4 (하품): 목욕 후 졸린 하품 얼굴
- 타일 5 (씩씩): 주먹을 굳게 쥔 듯 미소 짓는 얼굴
- 타일 6 (포근): 미소 + 동그란 볼터치 (온가족의 안심)

그림체: 크레용/어린이 손그림 풍 — 두꺼운 윤곽선 없이 부드럽고 살짝 삐뚤어진 선, 단순한 점눈과 곡선 입, 동그란 볼. 각 얼굴은 타일 중앙에 배치.

색상(하이피부 공식 팔레트): 전체 배경은 크림 #FFF8EF. 타일 배경은 소프트 핑크 #F6A6B8 / 밀크 핑크 #FCE8EC / 애프리콧 #F4B27D / 소프트 세이지 #AFC7A8 / 리프 그린 #6F9470 을 번갈아. 얼굴의 선과 표정은 딥 브라운 #403735 한 가지.

하단 중앙에 손글씨체 "HIGHSKIN" 텍스트(딥 브라운). 로고 전체는 흰색 카드 위 1:1 정사각형, 가장자리 여백 충분.

스타일: 귀엽지만 유치하지 않은 크래프트/리소그래프 감성. 그라데이션·네온·3D·과한 디테일 금지. 어린이 작품의 진정성이 느껴지는 오리지널 로고.
```

## 프롬프트 B — 비누 각인(스탬핑)용 (단색 모노크롬)

```text
비누 표면에 스탬핑할 브랜드 로고를 생성해줘 — HIGHSKIN 하이피부, 단색 엠보스(음각·양각)용.

구성: 모서리가 둥근 직사각형 배지 안에 어린이 손그림 풍 얼굴 4개를 2x2 콜라주. 각 얼굴은 표정이 다름(크게 웃음 / 감은눈 휴식 / 놀란 눈 / 하품). 배지 중앙 하단에 손글씨풍 "HIGHSKIN".

그림체: 각인했을 때 선이 뭉개지지 않도록 가늘고 단순한 한 줄 스트로크 — 점눈·곡선 입·동그란 볼만으로 최소화. 음각 스탬프 효과, 평면 벡터형.

색상: 모노크롬 1색 — 크림색 비누(아이보리) 위 딥 브라운 #403735. 순수 블랙 대신 부드러운 웜 브라운. 배경은 비누 표면(단색)으로 처리.

사이즈: 실제 비누 6~8cm 기준으로 눈·입·볼이 서로 붙지 않게 여백 확보, 최소 선 굵기 0.5mm 이상.

스타일: 미니멀, 손 감성, 대칭보다 자연스러운 리듬. 그라데이션·그림자·원근·복잡한 텍스처 금지.
```

### 로고 생성 팁
1. 콜라주보다 **캐릭터 1개 먼저 생성 → 표정만 바꿔 가며 variant → 그리드 합성** (얼굴 일관성 유지)
2. 핀 이미지를 스타일 참고 업로드해도 좋지만 **기존 디자인 복제 금지** — 오리지널 캐릭터 조건 유지
3. 생성 이미지는 **벡터화** 후 선 굵기 통일 → 스탬프 업체에 1도 컬러 전달

# 🧴 부록 B — 제품 시각화 프롬프트 (고객용 제품 이미지)

> **출처**: `highskin-product-ideas.md` — 샴푸브러시×비누 홀더(리필) · 여행용 미니 세트

## 프롬프트 P1 — 샴푸브러시 × 비누 홀더

```text
제품 사진을 생성해줘 — 샴푸브러시와 바디바가 결합된 리필형 홀더 제품. 쇼핑몰 상세페이지용 클로즈업.
구성: 대나무 손잡이 샴푸브러시(부드러운 실리콘 브러시, 소프트 핑크 #F6A6B8) 반대편에 크림색 바디바(#FFF8EF)가 홀더에 꽂혀 있다. 홀더는 배수구멍이 있는 미니멀 디자인, 크림 톤.
배경: 밝은 욕실 타일, 비눗방울과 유칼립투스/로즈마리 가지가 흐릿하게. 부드러운 아침 자연광.
색/질감: 전체적으로 하이피부 파스텔(크림·밀크핑크·세이지), 웜톤 브라운 그림자. 제품은 실제 크기감 있게.
스타일: 고급스러우면서도 따뜻한 라이프스타일 광고 사진. 과장된 반사·네온·텍스트 오버레이 금지.
```

## 프롬프트 P2 — 여행용 미니 세트 (비누 + 거품망)

```text
제품 사진을 생성해줘 — 여행용 미니 바디케어 세트. 쇼핑몰 상세페이지용.
구성: 50g 미니 바디바(크림 #FFF8EF, 하이피부 로고 각인) + 거품망(샤워볼, 밀크핑크 #FCE8EC) + 크래프트지 케이스가 여행 가방 위에 깔끔하게 놓임. 곁에 미니 트래블 브러시와 허브 가지.
배경: 밝은 창가, 리넨 소재, 여행 짐(캐리어 손잡이). 자연 채광.
색상: 하이피부 파스텔 팔레트 유지 — 크림·핑크·세이지·애프리콧 포인트.
스타일: 미니멀 플랫레이/라이프스타일 광고. 텍스트·가격표·네온 금지.
```
