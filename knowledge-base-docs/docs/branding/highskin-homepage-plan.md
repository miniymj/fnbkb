## 0. 홈페이지 방향성

### 한 줄 정의

> HI-SKIN 하이피부 홈페이지는 **'표정을 고르는 재미'를 입구로 삼아**, 바디바의 사용·보관·여행·리필까지 하나의 목욕 경험으로 연결하고 제품 구매로 이어지게 하는 **패밀리 배스케어 브랜드 플랫폼**입니다.

### 3대 디자인 키워드

| 축 | 키워드 | 의미 |
|----|--------|------|
| **PLAYFUL** | 표정과 재미 | 캐릭터성, 인터랙션, 감성적 경험 |
| **USEFUL** | 실제 사용 편의성 | Bath System 시각화, 상황별 솔루션 |
| **NATURAL** | 편안한 소재와 습관 | 성분, 자연 소재, 지속가능한 리필 |

> 이 세 축이 홈페이지 전체에서 흔들리지 않는 게 가장 중요합니다.

### 홈페이지 핵심 목표

방문 고객이 5~10초 안에 세 가지를 이해해야 합니다:

| 고객이 이해해야 할 것 | 내용 |
|----------------------|------|
| **① 누구를 위한 브랜드인가?** | 민감피부 당사자부터 가족까지 함께 사용하는 패밀리 배스케어 |
| **② 무엇이 다른가?** | 표정을 고르는 바디바 + 욕실·여행·수영장까지 이어지는 Bath System |
| **③ 왜 사야 하는가?** | 목욕을 더 재미있게 만들고, 고체비누의 보관·휴대 불편까지 해결 |

### 포지셔닝

> **민감피부 당사자의 눈으로 설계한, 표정을 고르는 즐거움부터 사용하는 편리함까지 — 가족의 목욕을 더 즐거운 습관으로 만드는 패밀리 배스케어 브랜드**

### 슬로건 · 미션

| 항목 | 내용 |
|------|------|
| **브랜드 태그라인** | 오늘, 어떤 표정으로 씻을래? |
| **서브 메시지** | 표정을 고르는 즐거움부터, 사용하는 편리함까지. |
| **브랜드 미션** | 가족의 일상에 즐거운 목욕 습관. Happy Natural Care |
