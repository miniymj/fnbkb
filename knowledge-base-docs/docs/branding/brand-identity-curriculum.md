## 2. 브랜드 아이덴티티 — 6가지 필수 요소

고객이 일관성 있게 기억할 수 있는 정체성과 캐릭터를 갖는 것이 브랜딩의 핵심이다.

1. **네이밍 (Naming)**: 기억·발음·검색 최적화된 이름
2. **컬러 팔레트 (Color Palette)**: 브랜드 감정을 시각화하는 색상
3. **타이포그래피 (Typography)**: 폰트로 전하는 브랜드 성격
4. **보이스앤톤 (Voice & Tone)**: 브랜드의 글쓰기 방식과 말투
5. **무드보드 (Mood Board)**: 브랜드 분위기를 이미지로 정의
6. **슬로건 (Slogan)**: 브랜드 존재 이유를 한 문장으로

## 3. 브랜드 네이밍 — 고객이 기억하는 이름 만들기

좋은 이름 하나가 광고비를 아낀다. 발음하기 쉽고, 기억에 남고, 검색이 되어야 한다.

### 3.1. 네이밍 4대 원칙
- **발음 용이성**: 소리 내어 3번 읽었을 때 자연스러운가? 짧을수록 좋음 (2~3음절 권장) *예: 마켓컬리, 쿠팡, 무신사, 당근*
- **의미 연상성**: 브랜드 카테고리나 가치를 연상시키는가? 직접적·감성적 의미 모두 가능 *예: 초록마을, 오설록, 이니스프리*
- **검색 가능성**: 네이버·구글에서 찾기 쉬운가? 동음이의어나 기존 유명 브랜드 충돌 피하기
- **확장 가능성**: 카테고리가 확장되어도 어색하지 않은가? 특정 제품명이 아닌 브랜드 철학을 담은 이름 *예: 오늘의 집*

### 3.2. 네이밍 5단계 검증 프로세스
이름을 확정하기 전, 반드시 5단계 검증을 거쳐야 상표 충돌이나 도메인 선점 문제를 사전에 방지할 수 있다.

1. **상표검색**: KIPRIS(특허청 정보검색시스템)에서 확인
2. **도메인**: 가비아 등 도메인 등록 기관에서 가용성(GTLD, CTLD 등) 확인
3. **인스타 검색**: 인스타그램 내 계정명 및 유사명 활성화 여부 확인
4. **스토어명 확인**: 스마트스토어 등 주요 이커머스 플랫폼 내 중복 체크
5. **구글 검색**: 해당 이름 검색 시 이슈, 부정적 결과, 동명의 인물/기업 존재 여부 확인

*(참고: 네이밍 시 영문 표기법 고려하기)*
*영문으로 표기될 때를 대비해 발음대로 표기할지(마켓컬리 -> Market Kurly), 의미대로 표기할지 고민해야 함. 검색 엔진 최적화(SEO)를 위해 고유명사임이 확실하게 드러나도록 짓는 것이 유리함.*

## 4. 브랜드 컬러 팔레트 — 감정을 시각화하는 법

컬러는 가장 빠르게 브랜드를 인식시키는 도구다. 보기 전에 느끼게 만드는 것이 컬러다.
> **컬러 팔레트 공식**: 메인 컬러 1개 + 포인트 컬러 1개 + 배경 컬러 1개 (총 3가지로 시작)

### 4.1. 계열별 컬러 감성
- **파랑 계열**: 신뢰·전문성·안정감 (건강기능식품, 의료기기, 금융) - *삼성, 쿠팡*
- **초록 계열**: 자연·건강·친환경·생명 (유기농 식품, 클린뷰티, 에코 리빙) - *오설록, 이니스프리, 풀무원*
- **핑크/복숭아**: 따뜻함·친근함·여성성 (뷰티, 유아, 감성 홈데코) - *룸앤, 레아퓨어, 마리끌레르*
- **블랙/화이트**: 고급·미니멀·세련됨 (프리미엄, 하이엔드 브랜드) - *무신사, 프레시망고*
- **노랑/오렌지**: 에너지·활기·주목도 (포인트 컬러로만 활용 권장) - *카카오, 배달의민족, 에이블리*

### 4.2. A Rainbow of Brands
색상은 구매 결정의 50~85%에 영향을 미치며, 소비자가 로고에서 가장 먼저 인식하는 요소다.

| 컬러 | 키워드 | 글로벌 브랜드 예시 |
| :--- | :--- | :--- |
| 블랙 | 고귀·럭셔리·미스터리 | Prada, Gucci, Chanel |
| 블루 | 신뢰·안정·전문성 | Samsung, Ford, Facebook |
| 레드 | 열정·긴박감·식욕 자극 | McDonald's, Coca-Cola, CNN |
| 옐로 | 낙관·창의·주목성 | Shell, Burger King, Renault |
| 오렌지 | 활력·친근·CTA 효과 | Fanta, FedEx, Dunkin' |
| 퍼플 | 고귀·창의·신비 | Yahoo, Cadbury, Hallmark |
| 그린 | 자연·건강·성장 | Starbucks, Hulu, Heineken |
| 그레이 | 세련·중립·균형 | Apple, Mercedes-Benz, Nestlé |
| 브라운 | 안정·신뢰·역사 | UPS, Louis Vuitton, J.P. Morgan |
| 핑크 | 감성·낭만·젊음 | Barbie, T-Mobile, Victoria's Secret |

## 5. 타이포그래피 — 폰트가 전하는 브랜드 성격

> **원칙**: 한 브랜드에 폰트 최대 2가지 (제목용 1개 + 본문용 1개). 무료 폰트는 눈누(noonnu.cc) 활용.

- **세리프체 (고딕 굵음)**: 고급·전통·신뢰감 (프리미엄 식품, 전통 브랜드) - *나눔명조, 본명조, 돋움*
- **산세리프체 (고딕 얇음)**: 모던·친근·깔끔 (뷰티, 라이프스타일, 2030 타겟) - *Pretendard, 나눔스퀘어, 스포카한산스*
- **둥근 산세리프**: 따뜻함·부드러움·귀여움 (유아 제품, 건강식품, 여성 타겟) - *배달의민족 한나체, 여기어때 잘난체*
- **손글씨체**: 개성·감성·아날로그 (감성 잡화, 핸드메이드) - *히야 봄봄, 잉크립퀴드, 롯데마트행복*

## 6. Voice & Tone — 브랜드가 말하는 방식

상세페이지·CS 답변·SNS 캡션의 말투를 통일하는 것이 핵심. AI에게 브랜드 보이스 가이드 작성을 요청할 수 있다.

- **전문가 어조**: 영양 성분 최적화 배합으로 개발된 프리미엄 유아식을 새롭게 선보입니다. *(신뢰감, 전문성)*
- **친한 언니 어조**: 엄마들이 기다리던 그거 드디어 나왔어요! 성분 직접 다 확인했고 우리 아이도 잘 먹어요. *(친근함, 공감)*
- **감성적 어조**: 아이와 함께하는 작은 식탁 위에, 우리의 정성이 담긴 새 메뉴가 올라왔습니다. *(따뜻함, 프리미엄)*
- **유머 어조**: 또 나왔습니다. 아이가 안 먹겠다고 뿌리칠 수 없는 바로 그 맛. *(재미, 개성)*

*(참고: 패션/뷰티 e커머스에서의 Voice & Tone 적용 팁)*
*뷰티 브랜드의 경우 '전문가 어조'와 '감성적 어조'를 혼합하여 성분에 대한 신뢰를 주면서도 사용감에 대한 기대감을 높이는 방식을 많이 씀. 패션 브랜드의 경우 타겟 페르소나(예: 힙한 Z세대, 여유 있는 3040 직장인)의 일상적인 언어를 그대로 끌어와 '친한 언니/형 어조'나 '유머 어조'를 사용하는 것이 SNS 전환율을 높이는 데 유리함.*

## 7. 무드보드 — 브랜드 감성을 이미지로 정의하기

아직 존재하지 않는 브랜드의 감성을 이미지로 미리 구성해보는 도구.

### 5단계 제작법
1. Pinterest에서 `브랜드명 + mood board` 검색
2. 원하는 이미지 20~30장 저장
3. 공통된 색감·분위기 파악
4. Canva 무드보드 템플릿에 이미지 배치
5. 완성된 무드보드에서 컬러 코드(HEX) 3개 추출

### 카테고리별 무드보드 예시
- **유아 용품**: 파스텔 톤 / 부드러운 텍스처 / 아이 미소 / 목재 장난감 / 따뜻한 조명
- **클린뷰티**: 흰 배경 / 식물 성분 / 미니멀 패키지 / 투명 용기 / 자연 소재
- **홈카페 굿즈**: 따뜻한 원목 / 라떼 아트 / 리넨 원단 / 창가 햇빛
- **프리미엄 식품**: 고급 식기 / 어두운 배경 / 식재료 클로즈업 / 깔끔한 플레이팅
- **운동/건강**: 깔끔한 라인 / 역동적 동작 / 선명한 컬러 / 활기찬 이미지

## 8. 배경 제거 & 합성 — 스튜디오 없이 고퀄 상품 사진 만들기

- **Remove.bg**: 무료(저해상도)/유료(고해상도). 5초 만에 자동 배경 제거. Canva 합성 후 투명 PNG 다운로드.
- **PhotoRoom (앱)**: 무료 플랜 충분. 스마트폰 촬영/업로드 → AI 배경 제거 → 스튜디오 배경 선택 → 텍스트 추가.
- **Canva**: 상세페이지·SNS 카드뉴스 템플릿, 무드보드 제작, AI 이미지 생성, 배경 합성 최적화.

*(참고: 패션/뷰티 상품 사진 합성 시 주의점)*
*패션 상품의 경우 옷감의 질감과 핏이 중요하므로 단순 배경 제거 시 가장자리(소매, 넥라인 등)가 잘리지 않도록 주의해야 함. 뷰티 상품(스킨케어, 메이크업)은 제품의 빛 반사(광택)와 글씨가 훼손되지 않도록 챙겨야 함. 화장품 로고나 글자가 번져 보인다면 PhotoRoom보다 전문 툴(포토샵 등)을 활용해야 함.*

## 9. 브랜드 슬로건 — 존재 이유를 한 문장으로

고객에게 내가 누구인지, 무엇을 해주는지를 가장 직관적으로 압축 전달하는 문장.

- **고객의 변화를 표현**: 당신의 피부가 기억하는 하루 (클린뷰티) *TIP: 브랜드 사용 후 고객이 어떤 상태가 되는지 묘사*
- **핵심 가치를 압축**: 성분만 보는 엄마들의 선택 (유아 식품) *TIP: 가장 중요한 차별점 한 가지를 짧게 표현*
- **감성 + 기능 결합**: 매일 건강한 선택 / 오늘도 당신 편 (건강식품) *TIP: 이성적 혜택(기능)과 감성적 혜택(느낌)을 함께 담기*

> **ChatGPT 프롬프트 예시**: 
> "아래 브랜드 정보로 슬로건 10개를 만들어주세요. 타겟: [직접 입력] / 핵심 가치: [직접 입력] / 브랜드 톤: [따뜻한/전문적/유머러스]"

## 10. 1페이지 브랜드 가이드라인 워크시트

아래 항목을 직접 완성하면 나만의 브랜드 가이드라인이 완성된다.

| 항목 | 설명 | 내 브랜드 (예시) |
| :--- | :--- | :--- |
| **브랜드명** | 상표 검증 완료된 최종 확정 이름 | (예: 글로우픽) |
| **슬로건** | 브랜드 존재 이유를 담은 한 문장 | (예: 매일 발견하는 나만의 뷰티) |
| **메인 컬러 HEX** | 브랜드를 대표하는 주 색상 | (예: #1B2B5E / 네이비) |
| **보조 컬러 HEX** | 메인 컬러를 돕는 서브 색상 (최대 2개) | (예: #E8E4F8 / 페일 바이올렛) |
| **제목용 폰트** | 시선을 끄는 두꺼운 폰트 | (예: Pretendard Bold) |
| **본문용 폰트** | 가독성을 위한 얇은 폰트 | (예: Noto Sans KR Regular) |
| **브랜드 보이스** | 말투 특징 3가지 | (예: 전문적이지만 친근하게) |
| **금지 표현 3가지** | 브랜드 이미지를 해치는 단어 | (예: 최고 / 1등 / 절대) |

| **무드보드** | Pinterest | 세계 최대 비주얼 레퍼런스. `브랜드명 + mood board` 검색 필수 |

## 12. 용어 사전 — 브랜드 & 디자인 핵심 용어

- **브랜드 아이덴티티**: 브랜드의 시각적·언어적 표현 시스템 (컬러·폰트·로고·말투·무드보드 등)
- **HEX 코드**: 색상을 표현하는 6자리 숫자+알파벳 (예: #1B2B5E = 진한 네이비)
- **보이스앤톤**: 브랜드가 글로 소통하는 방식 (친근한/전문적/유머러스 등 기준)
- **CTA (Call To Action)**: 고객 행동을 유도하는 문구 ("지금 구매하기", "바로 확인하세요")
- **전환율 (CVR)**: 상세페이지를 본 사람 중 실제 구매한 비율 (초기 목표 1~2%)
- **포지셔닝**: 경쟁사 대비 내 브랜드가 고객 마음속에서 차지하는 위치
- **타이포그래피**: 폰트 선택, 크기, 간격 등 글씨의 시각적 배열에 관한 디자인 요소
- **HACCP**: 식품 안전관리 인증 (식품 브랜드 신뢰도를 높이는 핵심 인증)

*(참고: 패션/뷰티 e커머스 추가 필수 용어)*
- **MOQ (Minimum Order Quantity)**: 최소 주문 수량. 브랜드 입점이나 도매 시 처음 결정해야 하는 최소 생산/주문 단위.
- **OEM / ODM**: OEM은 발주자가 디자인/기획을 하고 공장이 생산만 하는 방식, ODM은 공장이 디자인/기획/생산을 다 하고 브랜드가 이름만 붙여 파는 방식.
- **SKU (Stock Keeping Unit)**: 품목 번호. 색상, 사이즈 등이 다르면 각각 다른 SKU로 관리되는 단위.
- **CAC (Customer Acquisition Cost)**: 신규 고객 1명을 유치하기 위해 들어가는 마케팅 비용.
- **LTV (Life Time Value)**: 한 고객이 브랜드를 이용하는 기간 동안 창출하는 총 수익.
