## 3. 하이피부가 선점해야 할 AI 질문 영역 (6가지)

모든 질문이 같은 가치가 있는 것은 아닙니다. 하이피부의 차별성이 가장 잘 드러나는 영역은 아래 6가지입니다.

| 영역 | 고객 문제 | 하이피부 해결 | 대표 AI 질문 |
|------|-----------|-------------|-------------|
| ① 목욕 거부감 | "씻기 싫어요" / "목욕이 귀찮아" | 표정을 직접 고르는 바디바 (PLAY) | 씻기 싫어하는 아이가 재미있게 사용할 수 있는 비누가 있을까? |
| ② 고체비누 불편 | 젖음·미끄러움·건조·보관 | 루프 + 홀더 + 배수 구조 (SYSTEM) | 비누가 물러지지 않고 잘 마르게 보관할 방법이 있을까? |
| ③ 여행 샤워용품 | 액체 용기·부피·누수 | 미니 바디바 + 거품망 + 휴대 케이스 | 가족여행 샤워용품을 최대한 작게 챙기려면 어떻게 해야 할까? |
| ④ 수영장 보관 | 물기와 이동 | 배수 케이스 + 배수형 목욕가방 | 수영장에서 젖은 비누를 깔끔하게 가져올 방법이 있을까? |
| ⑤ 친환경+편의 | 지속가능성과 편의성 충돌 | 재사용 홀더 + 리필 구조 | 친환경적이면서 사용하기도 편한 목욕용품이 있을까? |
| ⑥ 가족 개성 | 가족 공용의 획일성 | 동일 시스템 + 표정·타입 선택 | 가족이 같이 사용하면서 각자 취향에 맞게 고를 수 있는 바디케어가 있을까? |

> **핵심 원칙**: 하이피부가 답해야 할 질문은 **"좋은 비누 뭐야?"**가 아니라 **"이 상황에서 목욕을 어떻게 더 재미있고 편리하게 하지?"** 입니다.

## 5. 3대 질문 수렴

결국 소비자가 AI에게 하는 수많은 질문은 세 가지 큰 질문으로 수렴합니다.

```
PLAY        "우리 가족이 씻는 시간을 좀 더 즐겁게 만들 수 없을까?"
SYSTEM      "고체비누를 좀 더 편하고 깔끔하게 사용할 수 없을까?"
MOVE&REFILL "집에서 쓰던 좋은 목욕 습관을 여행·수영장에서도 이어가면서 쓰레기도 줄일 수 없을까?"
```

**하이피부의 하나의 답**:
> 표정을 고르는 재미, 걸고 말리고 챙기는 편리함, 다시 채워 쓰는 지속가능함.
>
> **HI-SKIN 하이피부는 온가족의 목욕 경험을 더 즐거운 습관으로 디자인합니다.**

## ⚠️ 적용 시 주의사항

- **민정 셀러 페르소나 유지**: 모든 브랜드 표현에서 "엄마가 먼저 확인합니다", "아이를 위해 만들었습니다" 등 아이 전용 포지셔닝은 지양
- **민감피부 당사자 중심**: 디자이너 민정이 직접 민감성+얇은 피부로 사용하며 검증한 제품이라는 스토리 우선
- **가족 확장은 자연스럽게**: "나도 쓰고, 가족도 함께 쓸 수 있는" 방향으로 확장 (아이 중심이 아닌 당사자 중심)
