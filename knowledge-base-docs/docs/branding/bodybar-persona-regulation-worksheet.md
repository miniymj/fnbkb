### 우선순위 2순위: 행동·소비패턴 (C)

| 요소 | 내 페르소나 규정 (바디바) | 데이터 근거 | 가장 영향받는 영역 |
|------|-------------------------|------------|-------------------|
| **정보탐색 방식** | 유튜브 뷰티·아트 콘텐츠 + 메타(인스타) 감성 콘텐츠 → 구매 의사결정 | 채널 참여도: 유튜브 아트 튜토리얼 **2.21x**·뷰티 팁 **1.99x**, 메타 패션 트렌드 **2.18x** | ★콘텐츠 전략 (채널 선정) |
| **구매 의사결정 기준** | 브랜드 신뢰도·가족 사용 여부·성분/세정력 중심 — '추천 및 후기'로 최종 결정 | 가족 세그먼트 관심사 1위: 브랜드 신뢰도 12.02%. 전체 관심사: 가족 사용 여부 7.79%(1위), 세정력 6.66%(2위), 추천 및 후기 6.59% | ★콘텐츠 전략 (리뷰·후기 콘텐츠) |
| **가격 민감도** | 중간 (미니 2,900원 ~ 세트 24,000원) — 실용·가성비 세그먼트만 최저가 고민감 | 가격대 관심 6.62%(전체 3위). 실용·가성비: 가격 대비 만족도 64.07%, 온라인 최저가 검색 54.48%. 동구밭 가격대 관심 낮음(5.2%) | 브랜드 (가격 포지셔닝) |
| **미디어 소비 습관** | 유튜브(롱폼 뷰티·아트) + 메타(감성·가족 콘텐츠) + 틱톡(자연·숏폼) | 유튜브 아트 **2.21x**, 메타 패션 트렌드 **2.18x**, 틱톡 랩 **2.16x**·자연 **1.84x** | ★콘텐츠 전략 (포맷 정책: 영상 + 감성 숏폼 + 성분 리뷰) |

| 요소 | 내 페르소나 규정 (바디바) | 데이터 근거 | 가장 영향받는 영역 |
|------|-------------------------|------------|-------------------|
| **핵심 가치관** | "건강과 웰빙이 최우선, 가족 피부 건강이 안전해야 한다" — 환경 친화적 가치에도 관심 | 경영진 요약: 건강·웰빙이 구매 결정의 최대 영향 요인, 가족 필요 고려, 친환경 가치 관심. 관심사 클러스터: 윤리 및 환경 요소 19.63% | 브랜드 (브랜드 가치) |

| **생활 유형** | 안심·실용 우선주의 — 매일 샤워 루틴 사용 + 온라인 최저가 비교 검색 | 건강·웰빙 토픽: 매일 사용 목표 42.17%. 실용·가성비 토픽: 온라인 최저가 검색 54.48% | 브랜드 (브랜드 성격) |
| **자기표현 욕구** | "환경을 생각하는 소비 = 나의 가치 실현" — 제로 웨이스트·비건 실천 | 친환경: 업사이클링 포장재 73.81%, 동물성 원료 배제 70.56%, 친환경적인 브랜드 선호 70.25% | ★콘텐츠 전략 (UGC·가치 소비 콘텐츠) |
