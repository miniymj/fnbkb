# MD 라인업 설계 — 샴푸바

> 작성일: 2026-08-03
> 카테고리: 샴푸바 (청정구역 컨셉)
> 경쟁사 벤치마크: 톤28, 동구밭, 시드물

---

## MD 라인업 4단계 구조

```
① 미끼상품 (Entry) → ② 메인상품 (Core) → ③ 프리미엄 (Premium) → ④ 세트/번들 (Bundle)
```

---

## ① 미끼상품 (Entry) — 첫 경험

| 항목 | 내용 |
|------|------|
| **목적** | 가격 부담 없이 브랜드 첫 경험 제공, 재구매로 연결 |
| **제품** | 미니 샴푸바 30g (단품) |
| **가격** | 4,900원 (정가) / 3,900원 (첫 구매 할인) |
| **포지셔닝** | "가능한 친환경, 첫 경험은 더 가능하게" |
| **타겟** | 샴푸바 입문자, 여행/체험용 수요 |

### 경쟁사 차별점

| 경쟁사 | 우리 | 차별점 |
|--------|------|--------|
| 톤28: 미니 2종 5,900원 | 미니 단품 3,900원 | 더 낮은 진입장벽, 첫 구매 강력 할인 |

## ② 메인상품 (Core) — 수익의 핵심

| 항목 | 내용 |
|------|------|
| **목적** | 가장 많이 팔리고 리뷰가 쌓이는 대표 상품 |
| **제품** | 샴푸바 80g (정품) |
| **가격** | 12,000원 (정가) |
| **포지셔닝** | "가능한 친환경, 불가능한 실력" |
| **핵심 차별점** | 펌/염색 후에도 가능한 천연 성분 |

### 상세 스펙

| 구분 | 내용 |
|------|------|
| **성분** | 천연 계면활성제, 아로마 오일, 식물 추출물 |
| **기능** | 두피 진정, 모발 보습, 비듬 예방 |
| **향** | 라벤더, 티트리, 유칼립투스 3종 |
| **인증** | 비건, 동물실험 무료, 친환경 포장재 |

## ③ 프리미엄 (Premium) — 객단가 UP

| 항목 | 내용 |
|------|------|
| **목적** | 소재·기능·한정판으로 프리미엄 부각, 매출 20~30% 목표 |
| **제품** | 프리미엄 샴푸바 100g + 실크 보주머니 |
| **가격** | 19,800원 |
| **포지셔닝** | "프리미엄 천연 성분, 특별한 샴푸 타임" |
| **프리미엄 요소** | 한정판 향(로즈·우디), 고급 포장, 실크 파우치 |

### 경쟁사 차별점

| 경쟁사 | 우리 | 차별점 |
|--------|------|--------|
| 동구밭: 괄사 사은품 | 실크 보주머니 | 샴푸바 전용 보관 솔루션 제공 |

## ④ 세트/번들 (Bundle) — 재구매율 × 객단가

| 항목 | 내용 |
|------|------|
| **목적** | 재구매율과 객단가 동시 상승 |
| **제품 구성** | 샴푸바 80g × 3개 |
| **가격** | 30,000원 (단품 36,000원 대비 17% 할인) |
| **포지셔닝** | "3개월 분량, 가능한 가격" |

### 추가 번들 옵션

| 번들명 | 구성 | 가격 | 할인율 |
|--------|------|------|--------|
| **입문 세트** | 미니 30g + 정품 80g | 14,000원 | 22% |
| **3개 번들** | 정품 80g × 3개 | 30,000원 | 17% |
| **가족 세트** | 정품 80g × 5개 | 45,000원 | 25% + 무료배송 |
| **풀 루틴 세트** | 샴푸바 80g + 컨디셔너바 80g + 거품망 | 25,000원 | 20% |

## 5가지 상품구성 방식 적용

### 1. 정기구독 (Subscription)

| 항목 | 내용 |
|------|------|
| **구조** | 매달 자동 배송 + 10% 할인 |
| **타겟** | 재구매 고객, 정기 샴푸 소비자 |
| **혜택** | 10% 할인 + 무료배송 + 한정판 선예약 |
| **경쟁사 벤치마크** | 톤28 크루할인 → 우리는 더 간편한 구독 모델 |

### 2. 묶음판매 (Bundle)

| 항목 | 내용 |
|------|------|
| **구조** | 3개 세트 = 무료배송 진입 (30,000원) |
| **타겟** | 배송비 민감 고객, 가격 합리적 소비자 |
| **경쟁사 벤치마크** | 동구밭 무료배송 프로그레스바 → 명시적 금액 기준 제시 |

### 3. 업셀 (Upsell)

| 항목 | 내용 |
|------|------|
| **구조** | 단품 → 3개 번들 → 프리미엄 한정판 |
| **옵션** | 향 선택(3종) → 한정판 향(2종) |
| **경쟁사 벤치마크** | 동구밭 계단식 세트 → 단순명료한 3단계 구조 |

### 4. 크로스셀 (Cross-sell)

| 항목 | 내용 |
|------|------|
| **구조** | 샴푸바 + 컨디셔너바 + 거품망 |
| **타겟** | 풀 루틴 구매자 |
| **경쟁사 벤치마크** | 톤28 사은품 컨디셔너바 → 본품 포함 번들 판매 |

### 5. 예약판매 (Pre-order)

| 항목 | 내용 |
|------|------|
| **구조** | 와디즈 얼리버드 20% 할인, 목표 200개 |
| **타겟** | 충성 고객, 신제품 선호층 |
| **목적** | 수요 검증 + 초기 자금 확보 + 재고 리스크 최소화 |
