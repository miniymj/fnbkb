# 🏷 부록 A — 로고 생성 프롬프트 (Pinterest 보드 분석 기반)

> **근거 자료**: Pinterest 공개보드 '바디바 표정들, 로고 등'(22 Pins) 분석 — 아이 손그림/스크리블, 둥근 셰이프(blob·슬라임), 표정 중심, 크림-핑크 파스텔, 손글씨 타이포. 하이피부 7색 팔레트와 색감 일치.
> **용도**: 비누 각인(스탬핑) + 패키지 인쇄

## 프롬프트 A — 패키지 인쇄용 (컬러 콜라주 로고)

```text
브랜드 로고를 생성해줘 — HIGHSKIN(하이피부), 온가족 바디케어 브랜드의 메인 로고. 패키지 인쇄용.

구성: 2x3 격자(6칸) 직사각형 타일 콜라주. 각 타일 안에는 서로 다른 표정을 지은 "아이가 그린 듯한" 손그림 얼굴이 하나씩.
- 타일 1 (행복): 입을 크게 벌리고 웃는 얼굴
- 타일 2 (스파 휴식): 눈을 감고 편안한 얼굴 (뜨거운 목욕의 표정)
- 타일 3 (놀람): 거품을 보고 반짝이는 눈으로 놀란 얼굴
- 타일 4 (하품): 목욕 후 졸린 하품 얼굴
- 타일 5 (씩씩): 주먹을 굳게 쥔 듯 미소 짓는 얼굴
- 타일 6 (포근): 미소 + 동그란 볼터치 (온가족의 안심)

그림체: 크레용/어린이 손그림 풍 — 두꺼운 윤곽선 없이 부드럽고 살짝 삐뚤어진 선, 단순한 점눈과 곡선 입, 동그란 볼. 각 얼굴은 타일 중앙에 배치.

색상(하이피부 공식 팔레트): 전체 배경은 크림 #FFF8EF. 타일 배경은 소프트 핑크 #F6A6B8 / 밀크 핑크 #FCE8EC / 애프리콧 #F4B27D / 소프트 세이지 #AFC7A8 / 리프 그린 #6F9470 을 번갈아. 얼굴의 선과 표정은 딥 브라운 #403735 한 가지.

하단 중앙에 손글씨체 "HIGHSKIN" 텍스트(딥 브라운). 로고 전체는 흰색 카드 위 1:1 정사각형, 가장자리 여백 충분.

스타일: 귀엽지만 유치하지 않은 크래프트/리소그래프 감성. 그라데이션·네온·3D·과한 디테일 금지. 어린이 작품의 진정성이 느껴지는 오리지널 로고.
```

## 프롬프트 B — 비누 각인(스탬핑)용 (단색 모노크롬)

```text
비누 표면에 스탬핑할 브랜드 로고를 생성해줘 — HIGHSKIN 하이피부, 단색 엠보스(음각·양각)용.

구성: 모서리가 둥근 직사각형 배지 안에 어린이 손그림 풍 얼굴 4개를 2x2 콜라주. 각 얼굴은 표정이 다름(크게 웃음 / 감은눈 휴식 / 놀란 눈 / 하품). 배지 중앙 하단에 손글씨풍 "HIGHSKIN".

그림체: 각인했을 때 선이 뭉개지지 않도록 가늘고 단순한 한 줄 스트로크 — 점눈·곡선 입·동그란 볼만으로 최소화. 음각 스탬프 효과, 평면 벡터형.

색상: 모노크롬 1색 — 크림색 비누(아이보리) 위 딥 브라운 #403735. 순수 블랙 대신 부드러운 웜 브라운. 배경은 비누 표면(단색)으로 처리.

사이즈: 실제 비누 6~8cm 기준으로 눈·입·볼이 서로 붙지 않게 여백 확보, 최소 선 굵기 0.5mm 이상.

스타일: 미니멀, 손 감성, 대칭보다 자연스러운 리듬. 그라데이션·그림자·원근·복잡한 텍스처 금지.
```

### 로고 생성 팁
1. 콜라주보다 **캐릭터 1개 먼저 생성 → 표정만 바꿔 가며 variant → 그리드 합성** (얼굴 일관성 유지)
2. 핀 이미지를 스타일 참고 업로드해도 좋지만 **기존 디자인 복제 금지** — 오리지널 캐릭터 조건 유지
3. 생성 이미지는 **벡터화** 후 선 굵기 통일 → 스탬프 업체에 1도 컬러 전달

# 📊 부록 B — 픽커 퀴즈 그래픽 프롬프트 (설문용 캐릭터)

> **출처**: `highskin-picker-quiz.md` — 피부타입·향·눈코입 얼굴 커스텀 설문 (구매 홈페이지, 스모어 제작)
> **스타일 계열**: Pinterest 보드 '바디바 표정들' — 아이 손그림·둥근 셰이프·크림-핑크 파스텔

## 프롬프트 G1 — 캐릭터 부품 시트 (눈·코·입 개별 선택지)

```text
설문조사용 캐릭터 부품 시트를 생성해줘 — 하이피부(HIGHSKIN)의 "아이가 그린 듯한" 손그림 얼굴 부품 모음.
구성: 크림 배경(#FFF8EF) 위에 3줄로 배열.
- 1번 줄 (눈 4종): 반짝 별눈(큰 원 + 별빛 하이라이트) / 감은 미소눈(반원 곡선) / 큰 동그란 눈 / 하트 눈
- 2번 줄 (코 3종): 작은 점코(점 1개) / 둥근 콩알코(작은 원) / 삐죽 삐죽코(물결 라인)
- 3번 줄 (입 4종): 크게 웃는 입(큰 초승달) / 고양이 입(작은 곡선) / 하트 입 / 잔잔 미소 입(옅은 곡선)
각 부품은 서로 떨어져 있어 개별로 잘라낼 수 있게 여백 확보. 선 색상은 딥 브라운(#403735), 부품은 소프트 핑크(#F6A6B8)·세이지(#AFC7A8)·애프리콧(#F4B27D) 톤.
스타일: 크레용/어린이 손그림, 가는 선, 순수 그래픽만(텍스트 없음). 그라데이션·네온·3D 금지.
```

## 프롬프트 G2 — 완성 캐릭터 4종 (결과 화면용)

```text
설문 결과용 완성 캐릭터 4마리를 한 장에 생성해줘 — 하이피부 친구들(피부타입×향 라인별).
- 수분·진정(허브): 감은 미소눈 + 콩알코 + 잔잔 미소 입, 배경 소프트 세이지(#AFC7A8), 라벤더 가지
- 센스티브(무향): 큰 동그란 눈 + 점코 + 고양이 입, 배경 크림(#FFF8EF), 민들레 홀씨
- 리프레시(시트러스): 반짝 별눈 + 삐죽니코 + 크게 웃는 입, 배경 연한 리프 그린(#6F9470), 시트러스 슬라이스
- 밸런스(플로랄): 하트 눈 + 점코 + 하트 입, 배경 소프트 핑크(#F6A6B8), 꽃과 비눗방울
각 캐릭터는 부드러운 구름(blob) 몸체를 가진 둥근 얼굴, 아이 손그림 스타일, 딥 브라운(#403735) 라인. 하이피부 7색 팔레트만 사용.
배경: 2x2 격자 4분할, 크림(#FFF8EF) 전체 배경. 어린이 작품의 진정성. 그라데이션·3D 금지.
```

## 프롬프트 G3 — 설문 UI 데코 (시작·로딩·공유)

```text
구매 홈페이지 설문 UI용 귀여운 일러스트 세트를 생성해줘 — 하이피부 스타일.
구성: 크림(#FFF8EF) 배경에 3개의 독립 요소가 위에서 아래로 서로 떨어져 배열.
- 시작 화면: 비눗방울이 피어오르는 오픈 카드 테두리 + 물음표 얼굴(단순한 캐릭터 1구)
- 로딩 거품: 둥실둥실 떠 있는 작은 거품 3~5개 아이콘
- 공유 버튼: 하트 모양 버튼 + 공유 화살표 아이콘
색상: 소프트 핑크(#F6A6B8)·세이지(#AFC7A8)·애프리콧(#F4B27D)·딥 브라운(#403735) 라인.
스타일: 아이 손그림·둥근 셰이프, 파스텔, 텍스트 없음(브랜드명 불포함). 네온·3D·복잡한 배경 금지.
```

## 픽커 퀴즈 제작 팁 (스모어)
1. **문항별 이미지 옵션**: Q3의 눈·코·입은 G1 부품 시트를 잘라 각 선택지 이미지로 업로드
2. **분기 로직**: Q1(피부타입)×Q2(향) → 결과 화면(quizzes 결과)에서 4개 라인(수분/센스티브/리프레시/밸런스)으로 분기
3. **이름 쿠폰**: Q4(이름)를 결과 문구·쿠폰 코드에 삽입 — "OO님 전용 하이피부 친구" 특별함
4. **추적**: 완료율·각 문항 이탈률을 보고 재미 요소(Q3 조합 수 4×3×4=48가지) 홍보

# 🧴 부록 C — 제품 시각화 프롬프트 (고객용 제품 이미지)

> **출처**: `highskin-product-ideas.md` — 샴푸브러시×비누 홀더(리필) · 여행용 미니 세트

## 프롬프트 P1 — 샴푸브러시 × 비누 홀더

```text
제품 사진을 생성해줘 — 샴푸브러시와 바디바가 결합된 리필형 홀더 제품. 쇼핑몰 상세페이지용 클로즈업.
구성: 대나무 손잡이 샴푸브러시(부드러운 실리콘 브러시, 소프트 핑크 #F6A6B8) 반대편에 크림색 바디바(#FFF8EF)가 홀더에 꽂혀 있다. 홀더는 배수구멍이 있는 미니멀 디자인, 크림 톤.
배경: 밝은 욕실 타일, 비눗방울과 유칼립투스/로즈마리 가지가 흐릿하게. 부드러운 아침 자연광.
색/질감: 전체적으로 하이피부 파스텔(크림·밀크핑크·세이지), 웜톤 브라운 그림자. 제품은 실제 크기감 있게.
스타일: 고급스러우면서도 따뜻한 라이프스타일 광고 사진. 과장된 반사·네온·텍스트 오버레이 금지.
```

## 프롬프트 P2 — 여행용 미니 세트 (비누 + 거품망)

```text
제품 사진을 생성해줘 — 여행용 미니 바디케어 세트. 쇼핑몰 상세페이지용.
구성: 50g 미니 바디바(크림 #FFF8EF, 하이피부 로고 각인) + 거품망(샤워볼, 밀크핑크 #FCE8EC) + 크래프트지 케이스가 여행 가방 위에 깔끔하게 놓임. 곁에 미니 트래블 브러시와 허브 가지.
배경: 밝은 창가, 리넨 소재, 여행 짐(캐리어 손잡이). 자연 채광.
색상: 하이피부 파스텔 팔레트 유지 — 크림·핑크·세이지·애프리콧 포인트.
스타일: 미니멀 플랫레이/라이프스타일 광고. 텍스트·가격표·네온 금지.
```

## 프롬프트 P3 — 바디바 언박싱 (크래프트지 패키지)

> **설계 의도**: 단순 제품 컷(제품만 찍는 사진)이 아닌 **언박싱 경험**을 한 장면에 담아, 고객이 "박스를 열면 자연의 정성이 보이는구나"라고 느끼게 하는 패키지 디자인. 하이피부 7색 팔레트와 "가족의 일상에 즐거운 목욕 습관" 컨셉을 반영.
> **참고**: 부록 E1 비주얼 설계 보드 5) 패키지/적용 섹션 · 부록 A 프롬프트 B(비누 각인) · 부록 P1·P2(제품 시각화) · **프롬프트 1 무드보드 3안** (위 이미지 참조 — 크림 베이스·파스텔 그리드·아이 손그림 캐릭터 시각 방향을 P3에 동일 적용)

```text
바디바(하이피부 HIGHSKIN)의 언박싱 장면을 생성해줘. 크래프트지 패키지를 열었을 때 보이는 전체 구성을 한 장면에 담은 패키지 디자인 시각화. 쇼핑몰 메인 상세페이지 최상단용.

구성(위에서 아래, 45도 약간 위에서 내려다보는 앵글):
- 중앙: 열린 크래프트지 박스(모서리 둥글고 낮은 형태, 박스 뚜껑은 접혀 뒤로). 박스 외면은 무프린트 자연 크래프트 톤, 내면은 크림 #FFF8EF.
- 박스 안쪽 정중앙: 크림색 바디바 비누(둥근 직사각형, 코너 라운드). 비누 표면에 하이피부 로고 각인(딥 브라운 #403735 엠보스 — 아이 손그림 표정 얼굴 + "HIGHSKIN" 손글씨).
- 비누 위/옆에 얇은 성분표 카드: 소프트 세이지 #AFC7A8 배경에 딥 브라운으로 성분·사용법 간결히 인쇄. 카드 한쪽 구석에 작은 리프 그린 #6F9470 잎사귀 아이콘.
- 비누 옆에 작은 허브 가지(라벤더 또는 로즈마리 1줄기) 자연스럽게 올려둠.
- 박스 밖으로 삐져나온 밀크 핑크 #FCE8EC 티슈 페이퍼(비누 감싸개 역할) 일부.

배경: 오트밀 크림 #FFF8EF 베이스. 우측에 대나무 트레이(대나무 손잡이 리필 홀더와 연결되는 소재)가 흐릿하게 보이고, 좌측에 린넨 천 한 겹이 자연스럽게 깔려 있음. 배경은 심플하고 넓은 여백.
```

### P3 프롬프트 설계 노트

1. **왜 단순 제품 컷이 아닌 "언박싱"인가?**
   - P1·P2는 각 제품(리필 홀더, 미니 세트)의 기능과 형태를 보여주는 용도
   - P3는 **고객이 상품을 받았을 때의 첫 순간** — 즉 패키지 전체 경험을 보여주는 용도
   - 쇼핑몰 상세페이지 최상단에 배치하여 "이 안에 뭐가 들어있나?" 호기심 → 구매 동기

2. **크래프트지 박스 디자인 전략**
   - 박스 **외면은 무프린트** — 자연 크래프트지 그대로. 하이피부 "자연주의" 컨셉을 시각적으로 전달
   - 박스 **내면은 크림색** — 열었을 때 따뜻한 색감이 보이는 서프라이즈(뜻밖의 즐거움) 효과
   - 비누 각인만 브랜드 아이덴티티를 담음 — 패키지에 로고 과다 노출 피하는 "조용한 브랜딩"

3. **성분표 카드의 역할**
   - 소프트 세이지(자연·진정) 배경 = "성분에 신경 쓰는 브랜드"를 시각적으로 암시
   - 카드가 비누 옆에 자연스럽게 놓여 있어 "사용법·성분을 투명하게 공개"하는 신뢰 메시지

4. **캐릭터 포인트(절제)**
   - P3는 "제품 사진"이므로 캐릭터를 전면에 배치하지 않음
   - 박스 가장자리에 작은 얼굴 하나만 걸터앉게 → 브랜드 캐릭터성을 유지하면서 제품에 집중하게 하는 균형
