## 🎯 개요

"가족의 일상에 즐거운 목욕 습관"이라는 브랜드 철학을 **제품 시스템**으로 확장합니다.
쓰고 버리는 1회성 소비 대신, **본체는 계속 쓰고 비누만 리필**하는 구조로 리사이클·지속가능·반복구매를 동시에 설계합니다.

**핵심 원칙**: 지속가능성은 "색이 아닌 **소재와 시스템**으로" — 크래프트지·재생 소재·리필 구독(무드보드 04 소재 전략과 동일한 논리).

## 🧴 제품 아이디어 1 — 샴푸브러시 × 비누 홀더 (리필 시스템)

### 컨셉
샴푸브러시 **반대편에 바디바를 꽂아** 목욕하며 브러싱 + 클렌징을 한 번에.
본체(브러시 홀더)는 재사용, 소모품은 **바디바 1개만 교체**하는 구조.

```
   [브러시 헤드] ●●●        손잡이 ──▶ [홀더 슬롯] + 바디바
        ↕ 세정 + 두피/바디 마사지          ↕ 끼워 쓰고, 다 쓰면 리필
```

### 핵심 스펙
| 항목 | 내용 |
|---|---|
| **체결 구조** | 마그네틱 / 나사식 / 푸쉬-클릭식 홀더 (비누 잔여물이 흘러내리는 배수 홀 포함) |
| **소재** | 대나무 손잡이 + 재생 플라스틱 홀더 + 부드러운 실리콘 브러시 — 하이피부 소재 언어(린넨·우드·돌)와 일치 |
| **색상** | 전체 크림 `#FFF8EF`, 브러시 실리콘은 Soft Pink `#F6A6B8` 포인트 |
| **리필** | 바디바 단품 + 정기리필 구독 (월 1개·2개 등 가족 구성원수 기반) |
| **포장** | 리필용 크래프트지 미니 패키지 (플라스틱 용기 제로) |

### 비즈니스 로직 — 반복구매(razor-and-blade)
- 브러시 홀더 **본체 1회 구매** (선물용 · 시그니처 번들)
- 이후 **바디바 정기 리필** → 고객 LTV·재구매율 상승
- 가족 단위 구독으로 "온가족 바디케어" 포지셔닝 강화
- BMC ⑤ 수익 흐름 연동: 정기구독·번들 전환 (기존 바디바 BMC와 동일 골격)

### 지속가능 효과
- 플라스틱 용기·거품병 감소 → 패키지 폐기물 최소화
- 본체 장기 사용 → 제품 교체 주기 자체를 설계에 포함 (리페어 서비스 가능)

## ✈️ 제품 아이디어 2 — 여행용 미니 세트 (비누 + 거품망)

### 컨셉
**50g급 미니 바디바 + 거품망(샤워볼)** 을 한 세트로. 짐이 가벼워지는 휴양·여행 동반자.

### 세트 구성
| 구성품 | 스펙 |
|---|---|
| 미니 바디바 | 50g — 아이 손에도 편한 그립, 온가족용 |
| 거품망(샤워볼) | 풍성한 거품 연출 — "순한 거품" 브랜드 경험 |
| (선택) 트래블 브러시 | 여행용 미니 브러시 — 제품 아이디어 1의 축소판 |
| 케이스 | 재생 소재 지퍼 케이스 또는 크래프트지 박스 |

### 활용처
- 등산·캠핑·호텔·해외여행 — 위생적이고 건조가 빠른 솔리드 바
- 선물세트(기프트): 미니 3종(바디바+샴푸바+클렌징바) + 거품망
- 시즌 한정: 여름 휴양지 캠페인과 연동

### 브랜드 메시지
- "여행에도, 씻는 게 즐거운 시간."
- "하나의 브러시, 평생의 비누." (아이디어 1과 통합 슬로건)
