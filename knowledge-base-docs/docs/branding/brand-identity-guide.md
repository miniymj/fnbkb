## 브랜드 네이밍 — 고객이 기억하는 이름 만들기

좋은 이름 하나가 광고비를 아낍니다. **발음하기 쉽고, 기억에 남고, 검색이 되어야** 합니다.

### 4가지 핵심 원칙

| 원칙 | 설명 | 예시 |
|------|------|------|
| **발음 용이성** | 소리 내어 3번 읽었을 때 자연스러운가? 짧을수록 좋음 (2~3음절 권장) | 마켓컬리, 쿠팡, 무신사, 당근 |
| **의미 연상성** | 브랜드 카테고리나 가치를 연상시키는가? 직접적·감성적 의미 모두 가능 | 초록마을, 오설록, 이니스프리 |
| **검색 가능성** | 네이버·구글에서 찾기 쉬운가? 동음이의어나 기존 유명 브랜드 충돌 피하기 | - |
| **확장 가능성** | 카테고리가 확장되어도 어색하지 않은가? 특정 제품명이 아닌 브랜드 철학을 담은 이름 | 오늘의 집 |

### 네이밍 5단계 검증 프로세스

이름을 확정하기 전, 반드시 5단계 검증을 거쳐야 합니다. 상표 충돌이나 도메인 선점 문제를 사전에 방지할 수 있습니다.

1. **도메인 검색** — 가비아 등에서 가용성 확인 (.com / .co.kr / .kr)
2. **스토어명 확인** — 네이버 스마트스토어 중복 체크
3. **상표 검색** — 특허청 KIPRIS(kipris.or.kr)에서 동일·유사 상표 확인
4. **구글 검색** — 이슈·부정적 결과 확인
5. **인스타 검색** — 계정 및 유사명 확인

> 💡 순서 중요: 도메인·스토어명부터 확인하면 가장 흔한 선점 문제를 빠르게 걸러낼 수 있습니다.

## 브랜드 컬러 팔레트 — 감정을 시각화하는 법

컬러는 가장 빠르게 브랜드를 인식시키는 도구입니다. **보기 전에 느끼게 만드는 것**이 컬러입니다.

> **컬러 팔레트 공식**: 메인 컬러 1개 + 포인트 컬러 1개 + 배경 컬러 1개 — 총 3가지로 시작하면 충분합니다.

### 색상 계열별 브랜드 이미지 (적합 카테고리)

| 색상 | 이미지 | 적합 카테고리 | 브랜드 예시 |
|------|--------|---------------|-------------|
| **파랑 계열** | 신뢰·전문성·안정감 | 건강기능식품, 의료기기, 금융 | 삼성, 쿠팡, 스마트스토어 |
| **초록 계열** | 자연·건강·친환경·생명 | 유기농 식품, 클린뷰티, 에코 리빙 | 오설록, 이니스프리, 풀무원 |
| **핑크/복숭아** | 따뜻함·친근함·여성성 | 뷰티, 유아, 감성 홈데코 | 룸앤, 레아퓨어, 마리끌레르 |
| **블랙/화이트** | 고급·미니멀·세련됨 | 프리미엄, 하이엔드 브랜드 | 무신사, 프레시망고 |

## 타이포그래피 — 폰트가 전하는 브랜드 성격

> **원칙**: 한 브랜드에 폰트 최대 2가지 — **제목용 1개 + 본문용 1개**. 눈누([noonnu.cc](https://noonnu.cc))에서 무료 다운로드 가능합니다.

| 폰트 종류 | 느낌 | 적합 카테고리 | 추천 폰트 |
|-----------|--------|---------------|-----------|
| **세리프체 (명조 계열)** | 고급·전통·신뢰감 | 프리미엄 식품, 전통 브랜드, 고가 제품 | 나눔명조, 본명조, 돋움 |
| **산세리프체 (고딕 얇음)** | 모던·친근·깔끔 | 뷰티, 라이프스타일, 20~30대 타겟 | **SUIT**, Pretendard, 나눔스퀘어, 스포카한산스 |
| **둥근 산세리프** | 따뜻함·부드러움·귀여움 | 유아 제품, 건강식품, 여성 타겟 | 배달의민족 한나체, 여기어때잘난체 |
| **손글씨체** | 개성·감성·아날로그 | 감성 잡화, 핸드메이드, 소규모 브랜드 | 히야 봄봄, 잉크립퀴드, 롯데마트행복 |

:::note 본 KB의 폰트 선택 — SUIT
이 KB(그리고 우리 브랜드 본문용)는 **SUIT**(산세리프, 모던·친근·깔끔)를 채택했습니다. 이유:
1. **한글-영문 조화** — 기하학적 영문·숫자로 한글과 어울림
2. **UI 최적화** — 위아래 빈 공간 같아 정렬 쉬움, 짝수 줄간격
3. **경량** — woff2 기준 200kb 미만 (빠른 로딩)
4. **안전한 라이선스** — SIL OFL (상업적 이용 무료, 향후 분쟁 없음)

자세한 내용은 [폰트 가이드](#suit-폰트--kb-전역-폰트) 참고.
:::

## Voice & Tone — 브랜드가 말하는 방식

상세페이지·CS 답변·SNS 캡션의 말투를 통일하는 것이 핵심입니다. **AI에게 브랜드 보이스 가이드 작성을 요청**할 수 있습니다.

| 보이스 타입 | 예시 | 느낌 |
|-------------|------|------|
| **전문가 어조** | 영양 성분 최적화 배합으로 개발된 프리미엄 유아식을 새롭게 선보입니다. | 신뢰감, 전문성, 다소 딱딱함 |
| **친한 언니 어조** | 엄마들이 기다리던 그거 드디어 나왔어요! 성분 직접 다 확인했고 우리 아이도 잘 먹어요. | 친근함, 신뢰, 공감대 형성 |
| **감성적 어조** | 아이와 함께하는 작은 식탁 위에, 우리의 정성이 담긴 새 메뉴가 올라왔습니다. | 따뜻함, 감성, 프리미엄 |
| **유머 어조** | 또 나왔습니다. 아이가 안 먹겠다고 뿌리칠 수 없는 바로 그 맛. | 재미, 개성, 젊은 브랜드 |

## 무드보드 — 브랜드 감성을 이미지로 정의하기

### 무드보드란?

아직 존재하지 않는 브랜드의 감성을 이미지로 미리 구성해보는 도구입니다. [Pinterest](https://pinterest.com) 또는 [mixboard.google.com](https://mixboard.google.com) 활용.

### 5단계 제작법

1. Pinterest에서 브랜드명 + **mood board** 검색
2. 원하는 이미지 **20~30장** 저장
3. 공통된 색감·분위기 파악
4. [Canva](https://canva.com) 무드보드 템플릿에 이미지 배치
5. 완성된 무드보드에서 **컬러 코드 3개** 추출

### 카테고리별 무드보드 예시

| 카테고리 | 무드 키워드 |
|----------|------------|
| **유아 용품** | 파스텔 톤 / 부드러운 텍스처 / 아이 미소 / 목재 장난감 / 따뜻한 조명 |
| **클린뷰티** | 흰 배경 / 식물 성분 / 미니멀 패키지 / 투명 용기 / 자연 소재 |
| **홈카페 굿즈** | 따뜻한 원목 / 라떼 아트 / 리넨 원단 / 창가 햇빛 |
| **프리미엄 식품** | 고급 식기 / 어두운 배경 / 식재료 클로즈업 / 깔끔한 플레이팅 |
| **운동/건강** | 깔끔한 라인 / 역동적 동작 / 선명한 컬러 / 활기찬 이미지 |

## 배경 제거 & 합성 — 스튜디오 없이 고퀄 상품 사진 만들기

스튜디오 촬영 없이도 전문적인 상품 사진을 만드는 3대 도구입니다.

| 도구 | 특징 | 가격 |
|------|------|------|
| **[Remove.bg](https://remove.bg)** | 사진 업로드 후 5초 만에 자동 배경 제거. Canva에서 새 배경 합성 후 투명 PNG 다운로드 | 무료(저해상도) / 유료(고해상도) |
| **PhotoRoom (앱)** | 스마트폰 촬영/업로드 → AI 배경 자동 제거 → 스튜디오 배경 선택 → 텍스트 추가 후 내보내기 | 무료 플랜 충분 / 월 9,900원 Pro |
| **[Canva](https://canva.com)** | 상세페이지·SNS 카드뉴스 템플릿. 무드보드 제작. AI 이미지 생성 포함. 배경 제거 후 합성 작업에 최적 | 무료 / Pro |

> 💡 **워크플로우**: 스마트폰 촬영 → PhotoRoom으로 배경 제거 → Canva에서 스튜디오 배경 합성 + 텍스트 → 완성. 스튜디오 비용 없이 고퀄 상품 사진 제작 가능.

## 브랜드 슬로건 — 존재 이유를 한 문장으로

슬로건은 고객에게 **내가 누구인지, 무엇을 해주는지**를 가장 직관적으로 압축 전달하는 문장입니다.

### 슬로건 작성 3가지 패턴

| 패턴 | 예시 | TIP |
|------|------|-----|
| **고객의 변화를 표현** | _당신의 피부가 기억하는 하루_ (클린뷰티) | 브랜드 사용 후 고객이 어떤 상태가 되는지 묘사 |
| **핵심 가치를 압축** | _성분만 보는 엄마들의 선택_ (유아 식품) | 가장 중요한 차별점 한 가지를 짧게 표현 |
| **감성 + 기능 결합** | _매일 건강한 선택 / 오늘도 당신 편_ (건강식품) | 이성적 혜택(기능)과 감성적 혜택(느낌)을 함께 담기 |

### ChatGPT 슬로건 작성 프롬프트

> "아래 브랜드 정보로 슬로건 10개를 만들어주세요.
> 타겟: [직접 입력] /
> 핵심 가치: [직접 입력] /
> 브랜드 톤: [따뜻한/전문적/유머러스]"

## 1페이지 브랜드 가이드라인 워크시트

아래 항목을 직접 완성하면 나만의 브랜드 가이드라인이 완성됩니다.

| 항목 | 설명 | 내 브랜드 |
|------|------|-----------|
| **브랜드명** | 상표 검증 완료된 최종 확정 이름 | _BodyBar (바디바)_ |
| **슬로건** | 브랜드 존재 이유를 담은 한 문장 | _디자이너의 눈으로, 민감피부도 안심하고_ |
| **메인 컬러 HEX** | 예: #1B2B5E (네이비) | _#4A9D5F (네추럴 그린)_ |
| **보조 컬러 HEX** | 예: #E8E4F8 (페일 바이올렛), 최대 2개 | _#F5A9C0 (포인트 핑크) + #FAFAF7 (백그라운드 오프화이트)_ |
| **제목용 폰트** | 예: Pretendard Bold | _SUIT ExtraBold (800)_ |
| **본문용 폰트** | 예: Noto Sans KR Regular | _SUIT Regular (400) / Medium (500)_ |
| **브랜드 보이스** | 말투 특징 3가지 (예: 전문적이지만 친근하게) | _감성적 + 친한 언니 + 전문가 (성분 설명)_ |
| **금지 표현 3가지** | 예: 최고 / 1등 / 절대 | _최고 / 1등 / 자극적 과장_ |

> 💡 위 '_BodyBar_' 행은 우리 브랜드에 대한 예시 입력입니다. 각자의 브랜드에 맞게 수정해서 사용하세요.

## SUIT 폰트 — KB 전역 폰트

이 Knowledge Base는 **SUIT(수트)** 폰트를 전역 폰트로 사용합니다.

### 왜 SUIT인가?

> _"SUIT는 반복되는 노력을 기울이지 않아도 완성도 높은 형태를 유지하며, 소모적인 커뮤니케이션도 줄일 수 있도록 제작한 UI 폰트입니다."_
> — [sun.fo/suit](https://sun.fo/suit/)

| 항목 | 내용 |
|------|------|
| **제작·배포** | Sun (sun.fo) · GitHub: [sun-typeface/SUIT](https://github.com/sun-typeface/SUIT) |
| **라이선스** | **SIL OFL (Open Font License)** — 상업적 목적 포함 자유 사용·수정·재배포. 향후 라이선스 변경 분쟁 소지 없음 |
| **디자인 철학** | 한글과 어울리는 기하학적 영문·숫자. 구두점·괄호 중앙 정렬 한글 맞춤. UI 환경(버튼·아이콘 정렬) 최적화 |
| **주요 특징** | ① 한글-영문 시각적 조화 ② 위아래 빈 공간 동일(가운데 정렬 용이) ③ 짝수 줄간격 ④ 자간 본고딕 기준 ⑤ Apple SD Gothic Neo 대비 97% 크기(공간 활용) ⑥ woff2 200kb 미만(경량) |
| **지원 굵기** | 9종 (100~900) + Variable 폰트 포맷 |
| **포맷** | OTF, TTF, **WOFF2** (웹폰트) |

### KB에 적용된 방식

- **폰트 파일**: `static/fonts/SUIT-*.woff2` (Variable 1종 + Static 6종)
- **CSS 정의**: `src/css/custom.css`에 `@font-face`로 정의, `--ifm-font-family-base`에 'SUIT' 적용
- **전역 적용**: 모든 제목·본문·코드 블록에 SUIT 사용

### 다운로드 (직접 사용 시)

```html
<!-- Variable 버전 (권장 — 단일 파일로 전 굵기 커버) -->
<link href="https://cdn.jsdelivr.net/gh/sun-typeface/SUIT@2/fonts/variable/woff2/SUIT-Variable.css" rel="stylesheet">

<!-- Static 버전 -->
<link href="https://cdn.jsdelivr.net/gh/sun-typeface/SUIT@2/fonts/static/woff2/SUIT.css" rel="stylesheet">
```

```css
/* CSS 적용 예 */
body { font-family: 'SUIT', sans-serif; }
```

> 💡 **제작사 참고**: 같은 제작자에서 헤드라인용 폰트 **[SUITE(스위트)](https://sun.fo/suite/)** 도 제공합니다. 제목용으로 더 개성 있는 폰트가 필요할 때 검토해볼 수 있습니다.
