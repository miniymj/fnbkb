## 브랜드 네이밍 — 고객이 기억하는 이름 만들기

좋은 이름 하나가 광고비를 아낍니다. **발음하기 쉽고, 기억에 남고, 검색이 되어야** 합니다.

### 4가지 핵심 원칙

| 원칙 | 설명 | 예시 |
|------|------|------|
| **발음 용이성** | 소리 내어 3번 읽었을 때 자연스러운가? 짧을수록 좋음 (2~3음절 권장) | 마켓컬리, 쿠팡, 무신사, 당근 |
| **의미 연상성** | 브랜드 카테고리나 가치를 연상시키는가? 직접적·감성적 의미 모두 가능 | 초록마을, 오설록, 이니스프리 |
| **검색 가능성** | 네이버·구글에서 찾기 쉬운가? 동음이의어나 기존 유명 브랜드 충돌 피하기 | - |
| **확장 가능성** | 카테고리가 확장되어도 어색하지 않은가? 특정 제품명이 아닌 브랜드 철학을 담은 이름 | 오늘의 집 |

### 네이밍 5단계 검증 프로세스

이름을 확정하기 전, 반드시 5단계 검증을 거쳐야 합니다. 상표 충돌이나 도메인 선점 문제를 사전에 방지할 수 있습니다.

1. **상표 검색**: 특허청 키프리스/KIPRIS에서 동일·유사 상표 확인
2. **도메인 확인**: .com / .co.kr / .kr 도메인 선점 가능성 확인
3. **SNS 핸들**: 인스타그램/유튜브 블로그 아이디어 중복 확인
4. **발음 테스트**: 3번 소리 내어 읽었을 때 자연스러운지 확인
5. **의미 테스트": 브랜드 가치를 연상시키는지 설문조사

## 브랜드 컬러 팔레트 — 감정을 시각화하는 법

컬러는 가장 빠르게 브랜드를 인식시키는 도구입니다. **보기 전에 느끼게 만드는 것**이 컬러입니다.

컬러 팔레트 공식: **메인 컬러 1개 + 포인트 컬러 1개 + 배경 컬러 1개** — 총 3가지로 시작하면 충분합니다.

### 색상별 브랜드 이미지

| 색상 | 이미지 | 적합 카테고리 | 예시 |
|------|--------|---------------|------|
| **파랑 계열** | 신뢰·전문성·안정감 | 건강기능식품, 의료기기, 금융 | 삼성, 쿠팡, 스마트스토어 |
| **초록 계열** | 자연·건강·친환경·생명 | 유기농 식품, 클린뷰티, 에코 리빙 | 오설록, 이니스프리, 풀무원 |
| **핑크/복숭아** | 따뜻함·친근함·여성성 | 뷰티, 유아, 감성 홈데코 | 룸앤, 레아퓨어, 마리끌레르 |
| **블랙/화이트** | 고급·미니멀·세련됨 | 프리미엄, 하이엔드 브랜드 | 무신사, 프레시망고 |
| **노랑/오렌지** | 에너지·활기·주목도 | 포인트 컬러로만 활용 권장 | 카카오, 배달의민족, 에이블리 |

## 타이포그래피 — 폰트가 전하는 브랜드 성격

원칙: **한 브랜드에 폰트 최대 2가지** — 제목용 1개 + 본문용 1개. 눈누([noonnu.cc](https://noonnu.cc))에서 무료 다운로드 가능합니다.

| 폰트 종류 | 느낌 | 적합 카테고리 | 추천 폰트 |
|-----------|--------|---------------|-----------|
| **세리프체 (고딕 굵음)** | 고급·전통·신뢰감 | 프리미엄 식품, 전통 브랜드, 고가 제품 | 나눔명조, 본명조, 돋움 |
| **산세리프체 (고딕 얇음)** | 모던·친근·깔끔 | 뷰티, 라이프스타일, 20~30대 타겟 | Pretendard, 나눔스퀘어, 스포카한산스 |
| **둥근 산세리프** | 따뜻함·부드러움·귀여움 | 유아 제품, 건강식품, 여성 타겟 | 배달의민족 한나체, 여기어때잘난체 |
| **손글씨체** | 개성·감성·아날로그 | 감성 잡화, 핸드메이드, 소규모 브랜드 | 히야 봄봄, 잉크립퀴드, 롯데마트행복 |

## Voice & Tone — 브랜드가 말하는 방식

상세페이지·CS 답변·SNS 캡션의 말투를 통일하는 것이 핵심입니다. AI에게 브랜드 보이스 가이드 작성을 요청할 수 있습니다.

| 보이스 타입 | 예시 | 느낌 |
|-------------|------|------|
| **전문가 어조** | 영양 성분 최적화 배합으로 개발된 프리미엄 유아식을 새롭게 선보입니다. | 신뢰감, 전문성, 다소 딱딱함 |
| **친한 언니 어조** | 엄마들이 기다리던 그거 드디어 나왔어요! 성분 직접 다 확인했고 우리 아이도 잘 먹어요. | 친근함, 신뢰, 공감대 형성 |
| **감성적 어조** | 아이와 함께하는 작은 식탁 위에, 우리의 정성이 담긴 새 메뉴가 올라왔습니다. | 따뜻함, 감성, 프리미엄 |
| **유머 어조** | 또 나왔습니다. 아이가 안 먹겠다고 뿌리칠 수 없는 바로 그 맛. | 재미, 개성, 젊은 브랜드 |

## 무드보드 — 브랜드 감성을 이미지로 정의하기

### 무드보드란?

아직 존재하지 않는 브랜드의 감성을 이미지로 미리 구성해보는 도구입니다. [Pinterest](https://pinterest.com) 또는 [mixboard.google.com](https://mixboard.google.com) 활용.

### 5단계 제작법

1. Pinterest에서 브랜드명 + mood board 검색
2. 원하는 이미지 20~30장 저장
3. 공통된 색감·분위기 파악
4. Canva 무드보드 템플릿에 이미지 배치
5. 완성된 무드보드에서 컬러 코드 3개 추출

## 브랜드 슬로건 — 존재 이유를 한 문장으로

슬로건은 고객에게 **내가 누구인지, 무엇을 해주는지**를 가장 직관적으로 압축 전달하는 문장입니다.

### 슬로건 작성 3가지 패턴

| 패턴 | 예시 | TIP |
|------|------|-----|
| **고객의 변화를 표현** | _당신의 피부가 기억하는 하루_ (클린뷰티) | 브랜드 사용 후 고객이 어떤 상태가 되는지 묘사 |
| **핵심 가치를 압축** | _성분만 보는 엄마들의 선택_ (유아 식품) | 가장 중요한 차별점 한 가지를 짧게 표현 |
| **감성 + 기능 결합** | _매일 건강한 선택 / 오늘도 당신 편_ (건강식품) | 이성적 혜택(기능)과 감성적 혜택(느낌)을 함께 담기 |

## 용어 사전 — 브랜드 & 디자인 핵심 용어

| 용어 | 설명 |
|------|------|
| **브랜드 아이덴티티** | 브랜드의 시각적·언어적 표현 시스템. 컬러·폰트·로고·말투·무드보드 등 |
| **HEX 코드** | 색상을 표현하는 6자리 숫자+알파벳. 예: #1B2B5E = 진한 네이비 |
| **보이스앤톤** | 브랜드가 글로 소통하는 방식. 친근한/전문적/유머러스 등 말투의 기준 |
| **CTA** | Call To Action. "지금 구매하기", "바로 확인하세요" 등 고객 행동을 유도하는 문구 |
| **전환율 (CVR)** | 상세페이지를 본 사람 중 실제 구매한 비율. 1~2%가 초기 목표 |
| **포지셔닝** | 경쟁사 대비 내 브랜드가 고객 마음속에서 차지하는 위치 |
| **타이포그래피** | 폰트 선택, 크기, 간격 등 글씨의 시각적 배열에 관한 디자인 요소 |
| **HACCP** | 식품 안전관리 인증. 식품 브랜드에서 신뢰도를 높이는 핵심 인증 |
