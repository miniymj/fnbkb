## 🎯 BRAND CONCEPT

**Garden Sea — 바다의 정원**

"44부터 120까지, 모두가 아름다운 바다"

체형과 디자인, **양자택일 없는 사이즈프리 휴양지원피스**. 해변에서도, 리조트에서도, 여행 캐리어 속에서도 **'나답게' 서 있는 당신**을 위한 브랜드. 트렌드를 쫓는 것이 아니라, 누구나 편안하게 아름다울 수 있는 **포용의 바다**를 큐레이션합니다.

## 📐 설계 방법론

### 왜 이 6색인가 — BMC 4축 연동

| 축 | BMC 요소 | 컬러 반영 |
|---|---------|----------|
| **Target (40·50대 빅사이즈 여성)** | 체형 스트레스 해소, 자신감 회복, 휴양지 여행 수요 | 라군 블루(여유·안정) + 코랄(자신감) |
| **Value (디자인+사이즈 동시)** | 청정구역 "모두가 아름다운 바다" (44~120) | 세라믹 화이트(청정) + 라군 블루(바다·폭넓음) |
| **Place (휴양지·해변·리조트)** | 바다, 모래사장, 자연 | 라군 블루(바다) + 샌드 베이지(모래) + 소프트 세이지(자연) |
| **Passion (체형 긍정·자신감)** | inclusive, 포용, 자기 수용 | 코랄(자신감) + 소프트 세이지(포용) + 세라믹 화이트(순수) |

### 색채 심리학 근거

> 색채 심리학은 **색상이 인간의 감정·행동·인지에 미치는 영향**을 연구하는 학문입니다. 브랜드 컬러는 구매 결정의 **50~85%**에 영향을 미치며, 소비자가 브랜드를 가장 먼저 시각적으로 인식하는 요소입니다.

## 🎨 컬러별 색채 심리학 해설

### 1. Primary — 라군 블루 `#5B8FA8`

| 항목 | 내용 |
|------|------|
| **색채 심리** | **바다·여유·신뢰·폭넓음**. 블루 계열은 색채 심리학에서 가장 **신뢰도가 높은 색**으로 알려져 있습니다. 진한 네이비(`#1B2B5E`)보다 밝고 부드러운 라군 블루는 **여유와 호감**을 동시에 전달하며, 바다의 **폭넓음(44~120)**을 시각화합니다. |
| **타겟 연동** | 40·50대 여성이 휴양지에서 느끼고 싶은 **"마음의 여유와 평온"**을 시각화합니다. 체형 스트레스를 내려놓고 바다를 바라보는 순간의 감정입니다. |
| **BMC 연동** | ② 가치제안 "44부터 120까지, 모두가 아름다운 바다" — **바다의 폭넓음이 곧 사이즈의 폭넓음(44~120)**과 연결됩니다. |
| **사용 비율** | 전체의 **40%** (로고, 헤더, 네비게이션, 주요 블록) |

#### 색채학 분석

- **명도(Value)**: 66% (중간~밝음) — 시각적 안정감
- **채도(Saturation)**: 46% (중간) — 과하지 않은 포인트
- **색온도**: 쿨톤 — Secondary(세라믹 화이트)와 **유사색 조화**, Accent(코랄)와 **보색 대비**
- **비교**: 네이비(`#1B2B5E`)보다 **밝고 친근**, 스카이블루(`#87CEEB`)보다 **신뢰감 있고 성숙**
- **Pantone 근사**: 549 C (Lagoon Blue 근처)

#### 왜 네이비가 아닌가

MD 라인업에 **네이비 색상**(제품 컬러)이 포함되어 있으나, 브랜드 아이덴티티 Primary로서의 **진한 네이비가 주는 '정장·격식' 이미지가 휴양지의 '여유·자유'와 충돌**합니다. 라군 블루는 네이비의 **신뢰감을 유지하면서 휴양지 무드에 맞게 밝고 부드럽게** 조정한 결과입니다. (치마 팔레트의 '네이비 = 프로페셔널'과 달리, 원피스는 '블루 = 바다·여유'로 차별화)

### 2. Secondary — 세라믹 화이트 `#F5F0EB`

| 항목 | 내용 |
|------|------|
| **색채 심리** | **순수함·청정·신뢰·새로운 시작**. 완전한 흰색(`#FFFFFF`)이 주는 차가운 느낌을 피하고, 미세한 웜톤 베이지가 섞인 세라믹 화이트는 **따뜻하면서도 청결한** 인상을 줍니다. |
| **타겟 연동** | 40·50대 빅사이즈 여성이 브랜드에서 가장 먼저 느끼는 감정이 되어야 합니다. **"여기는 나를 비판하지 않는 안전한 공간"**이라는 메시지를 색으로 전달합니다. |
| **BMC 연동** | ② 가치제안 "모두가 아름다운 바다" — **빈 여백이 곧 아름다움**이라는 inclusive(포용) 철학의 시각적 표현입니다. |
| **사용 비율** | 전체의 **25%** (배경, 카드, 여백, 상세페이지 베이스) |

#### 색채학 분석

- **명도(Value)**: 96% (매우 밝음) — 개방감·여유로움
- **채도(Saturation)**: 4% (매우 낮음) — 차분함·고급스러움
- **색온도**: 웜톤 (R:245, G:240, B:235 — 레드 채널 미세 우위)
- **비교**: `#FFFFFF`(순백)보다 **따뜻한 느낌** — 병원·화장실의 차가운 흰색과 차별화
- **Pantone 근사**: 663 C (Warm White 근처)

> 💡 **브랜드 패밀리 정합**: 바디바 `오트밀 크림 #FAF6EF` · 치마 `웜 아이보리 #F7F4EF`와 함께 **3개 아이템 모두 '웜 크림 계열' 배경**을 공유합니다. 세라믹 화이트는 그 원피스 버전입니다.

### 3. Tertiary — 샌드 베이지 `#C4A882`

| 항목 | 내용 |
|------|------|
| **색채 심리** | **따뜻함·자연·안정·모래**. 베이지 계열은 색채 심리학에서 **편안함과 접근성**을 나타냅니다. 샌드 베이지는 "모래사장의 포근함"과 "휴양지 카페의 여유"를 연상시킵니다. |
| **타겟 연동** | 40·50대 여성이 **"이 브랜드는 나를 따뜻하게 안내해준다"**는 감정. MD 라인업 Core 색상 중 **베이지**를 브랜드 팔레트에 직접 수용합니다. |
| **BMC 연동** | ① 고객 세그먼트 "휴양지 여행 수요 30~60대" — **여행지의 따뜻한 자연**을 색으로 표현. ⑧ 파트너십 "린넨·레이온 원단" — 자연 소재의 신뢰감. |

- **명도(Value)**: 77% (밝음) — 가독성 확보
- **채도(Saturation)**: 34% (중간) — 자연스러운 따뜻함
- **색온도**: 웜톤 — Secondary(세라믹 화이트)와 **유사색 조화** → 통일감
- **Pantone 근사**: 155 C (Sand Beige 근처)

### 4. Accent 1 — 코랄 블러썸 `#E8917A`

| 항목 | 내용 |
|------|------|
| **색채 심리** | **자신감·활기·여성성**. 코랄 계열은 색채 심리학에서 **자신감과 사교성을 높이는** 색으로 연구됩니다. 붉은색의 열정을 부드럽게 순화하여 **공격적이지 않은 당당함**을 표현합니다. |
| **타겟 연동** | TPSP 장면 1(여름의 바다, 나답게 서다)의 핵심 감정 — **"체형 걱정 없이 서는 자신감"**. TPSP 컬러 힌트 "코랄"을 직접 수용하여 **체형 긍정과 자기 수용**의 시각적 상징으로 활용합니다. |
| **BMC 연동** | ② 가치제안 "디자인과 사이즈를 동시에" — **선택의 기쁨과 당당함**을 시각화. ⑤ 수익 흐름 "CTA·번들 전환" — 코랄 CTA로 행동 유도. |
| **사용 비율** | 전체의 **8%** (하이라이트·CTA·세일 태그·여름 캠페인) |

#### 색채학 분석

- **명도(Value)**: 91% (밝음) — 활기찬 가시성
- **채도(Saturation)**: 47% (중간~높음) — Accent 역할, 시선 집중
- **색온도**: 웜톤 — 라군 블루(쿨톤)와 **보색 대비** → 강력 시선 유도 포인트
- **Pantone 근사**: 1635 C (Living Coral 변형)

#### 왜 원색 레드가 아닌가

할인 마트·SNS 과장 광고가 쓰는 **원색 레드**는 "저가·자극" 이미지를 줍니다. 코랄 블러썸은 레드의 **활기를 유지하면서 웜 브랜드 톤과 어우러지는 부드러운 자신감**을 만듭니다.

### 5. Accent 2 — 소프트 세이지 `#A8B5A0`

| 항목 | 내용 |
|------|------|
| **색채 심리** | **치유·포용·자연**. 그린 계열은 색채 심리학에서 **안정과 회복**을 나타냅니다. 채도가 낮은 소프트 세이지는 강하지 않은 자연감으로 **"다양한 체형을 포용하는"** 브랜드 철학을 시각화합니다. |
| **타겟 연동** | 44~120 사이즈 모두를 **포용**하는 사이즈 인클루시브 정신. TPSP 컬러 힌트 "민트"의 상큼함을 세이지의 **포용·진정**으로 승화합니다. |
| **BMC 연동** | ④ 고객 관계 "실측 사이즈 차트 + 체형별 후기" — **사이즈 inclusivity(포용)**의 시각적 상징. 청정구역 "사이즈프리 휴양지원피스"의 감성적 표현. |
| **사용 비율** | 전체의 **7%** (태그·부가 정보·시즌 캠페인·프리미엄 라인) |

#### 색채학 분석

- **명도(Value)**: 71% (밝음) — 편안한 가독성
- **채도(Saturation)**: 12% (낮음) — 차분함, 과하지 않음
- **색온도**: 뉴트럴~쿨 — 라군 블루(쿨)와 **유사색 방향**, 샌드·코랄(웜)과 균형
- **Pantone 근사**: 558 C (Soft Sage 근처)

### 6. Deep — 딥 챠콜 `#2C2C2C`

| 항목 | 내용 |
|------|------|
| **색채 심리** | **고급·검소·안정·품격**. 완전한 블랙(`#000000`)은 과한 무거움을 줄 수 있습니다. 딥 챠콜은 **고급스러움을 유지하면서 접근 가능한** 톤으로, 미니멀하면서도 품격 있는 인상을 전달합니다. |
| **타겟 연동** | 40~60대 타겟이 인지하는 **"디자이너 브랜드의 품격"**. 체형별 피팅 데이터로 완성된 전문성과 신뢰를 텍스트 컬러로 전달합니다. |
| **BMC 연동** | ⑥ 핵심 자원 "디자이너 감각, 체형별 피팅 데이터" — **전문성·신뢰**의 시각적 기반. 상세페이지 본문의 표준 텍스트 컬러. |
| **사용 비율** | 전체의 **5%** (본문 텍스트·소제목·로고 타입) |

#### 색채학 분석

- **명도(Value)**: 17% (어두움) — 텍스트 가독성 확보
- **채도(Saturation)**: 0% (무채색) — 차분함·중립
- **명암 대비**: Secondary `#F5F0EB` 대비 **12.3:1** → **WCAG AAA 준수** (본문 텍스트 기준 4.5:1 이상)
- **접근성**: 딥 챠콜 + 세라믹 화이트 조합은 **시각 장애·고령 타겟(40~60대)에게 최적화된 명암 대비**

## 🔄 컬러 팔레트 조화론 (Color Harmony)

### 색상환 기반 조화 구조

```
                라군 블루 (#5B8FA8 · 쿨)
               ╱                              ╲
    소프트 세이지 (#A8B5A0 · 뉴트럴)    코랄 블러썸 (#E8917A · 웜)
              ╲                              ╱
               샌드 베이지 (#C4A882 · 웜)

        ●  웜톤 삼각 조화: 코랄 — 샌드 — 세이지(뉴트럴)
        ▲  쿨+웜 대비 축: 라군 블루(쿨) ↔ 코랄(웜)
        ◆  무채색 앵커: 딥 챠콜 (안정) + 세라믹 화이트 (청정)
```

### 4가지 조화 원리 적용

| 원리 | 적용 | 효과 |
|------|------|------|
| **유사색 조화 (Analogous)** | 세라믹 화이트·샌드 베이지·코랄 블러썸 — 웜톤 3색 | 따뜻한 일체감, 휴양지의 온기 |
| **보색 대비 (Complementary)** | 라군 블루(쿨, ~200°) ↔ 코랄 블러썸(웜, ~13°) | 시선 유도, "바다와 석양"의 생동감 |
| **삼각 조화 (Triadic)** | 코랄·샌드·세이지 — 웜~뉴트럴 분산 | 균형 잡힌 다채로움 |
| **무채색 기반 (Achromatic Base)** | 세라믹 화이트·딥 챠콜 — 2색 기반 | 세련됨, 가독성, 안정감 |

> **핵심 원칙**: 라군 블루를 Primary(40%)로 설정하여 **바다의 앵커**를 확보하고, 웜톤(세라믹·샌드·코랄)으로 **휴양지의 온기**를 더하는 구조. 경쟁사(케네스레이디·써스데이아일랜드)의 **격식·트렌디 중심 팔레트와 명확히 분리**됩니다.

| **Secondary** | 오트밀 크림 `#FAF6EF` | 세라믹 화이트 `#F5F0EB` | 웜 아이보리 `#F7F4EF` |

| **Deep** | 웜 브라운 잉크 `#3B3A36` | 딥 챠콜 `#2C2C2C` | 인크 차콜 `#2C2E31` |

| **공통 베이스** | 웜 크림 계열 | 웜 크림 계열 | 웜 아이보리 계열 |
| **핵심 차이** | 그린 = 자연·정화 | **블루 = 바다·여유·포용** | 네이비 = 프로페셔널·신뢰 |

> 💡 세 카테고리 모두 **웜톤 베이스(크림/아이보리)**를 공유하면서, **Primary 컬러로 아이템 특성을 분리**합니다. 바디바=그린(자연), 원피스=블루(바다·여유), 치마=네이비(프로페셔널). 셀러가 복수 카테고리를 운영할 때 **통일된 브랜드 패밀리 + 독립적인 아이템 정체성**을 동시에 구축합니다.
