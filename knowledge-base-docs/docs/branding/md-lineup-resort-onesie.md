# MD 라인업 설계 — 사이즈프리 휴양지원피스

> 작성일: 2026-08-03
> 카테고리: 사이즈프리 휴양지원피스 (청정구역 컨셉)
> 경쟁사 벤치마크: 케네스레이디, 써스데이아일랜드, 빅사이즈 전문 브랜드

---

## MD 라인업 4단계 구조

```
① 미끼상품 (Entry) → ② 메인상품 (Core) → ③ 프리미엄 (Premium) → ④ 세트/번들 (Bundle)
```

---

## ① 미끼상품 (Entry) — 첫 경험

| 항목 | 내용 |
|------|------|
| **목적** | 바디타입 불안 해소, 체형 커버 체험 |
| **제품** | 미니 휴양지 원피스 (비치커버업) |
| **가격** | 24,000원 (정가) / 19,200원 (첫 구매 20% 할인) |
| **포지셔닝** | "체형과 디자인, 양자택일 없는 첫 경험" |
| **타겟** | 체형 걱정 입문자, 여행 첫 경험 |

---

## ② 메인상품 (Core) — 수익의 핵심

| 항목 | 내용 |
|------|------|
| **목적** | 가장 많이 팔리고 리뷰가 쌓이는 대표 상품 |
| **제품** | 사이즈프리 휴양지 원피스 (셔링·랩 디테일) |
| **가격** | 39,000원 (정가) |
| **포지셔닝** | "44부터 120까지, 모두가 아름다운 바다" |
| **핵심 차별점** | 44~120 사이즈 커버, 셔링·랩 체형 커버, 통기성 린넨 |

### 상세 스펙

| 구분 | 내용 |
|------|------|
| **사이즈** | 44 ~ 120 (FREE) - 조절식 웨이스트 |
| **소재** | 린넨 70% + 레이온 30% (통기성) |
| **기장** | 미디(85cm) / 맥시(100cm) |
| **색상** | 화이트, 베이지, 코랄, 민트, 네이비 5종 |
| **디테일** | 셔링, 랩, 조절식 스트랩, 사이드 포켓 |

---

## ③ 프리미엄 (Premium) — 객단가 UP

| 항목 | 내용 |
|------|------|
| **목적** | 소재·디자인·한정판으로 프리미엄 부각, 매출 20~30% 목표 |
| **제품** | 프리미엄 실크 휴양지 원피스 + 자카드 가디건 |
| **가격** | 69,000원 |
| **포지셔닝** | "여행의 특별한 순간, 실크로 완성하다" |
| **프리미엄 요소** | 실크 소재, 한정판 패턴, 매치 가디건 증정 |

---

## ④ 세트/번들 (Bundle) — 재구매율 × 객단가

| 항목 | 내용 |
|------|------|
| **목적** | 재구매율과 객단가 동시 상승, 휴양지 풀 룩 |
| **제품 구성** | 원피스 + 비치 커버업 + 선캡 |
| **가격** | 55,000원 (단품 67,000원 대비 18% 할인) |
| **포지셔닝** | "휴양지 풀 룩, 한 번에 완성" |

### 추가 번들 옵션

| 번들명 | 구성 | 가격 | 할인율 |
|--------|------|------|--------|
| **입문 세트** | 미니 원피스 + 레이스 가디건 | 35,000원 | 20% |
| **비치 세트** | 원피스 + 커버업 + 선캡 + 슬리퍼 | 58,000원 | 22% |
| **가족 세트** | 원피스 2종 (모녀) + 파우치 2 | 65,000원 | 25% |
| **리조트 세트** | 프리미엄 원피스 + 실크 가디건 + 백 | 79,000원 | 18% |

## 5가지 상품구성 방식 적용

### 1. 정기구독 (Subscription)

| 항목 | 내용 |
|------|------|
| **구조** | 시즌별 휴양지 컬렉션 구독 + 10% 할인 |
| **타겟** | 여행 자주 가는 30~60대 여성, 재구매층 |
| **혜택** | 시즌 신상 우선권 + 여행지 추천 큐레이션 |
| **경쟁사 벤치마크** | 시드물 세트 할인 → 시즌별 테마 구독 |

### 2. 묶음판매 (Bundle)

| 항목 | 내용 |
|------|------|
| **구조** | 2종 세트 = 무료배송 진입 (55,000원) |
| **타겟** | 배송비 민감 고객, 여행 세트 원하는 층 |
| **경쟁사 벤치마크** | 동구밭 기획세트 → 휴양지 풀 룩 세트 |

### 3. 업셀 (Upsell)

| 항목 | 내용 |
|------|------|
| **구조** | 미니 → 메인 → 프리미엄 실크 |
| **옵션** | 린넨 → 실크 한정판 → 자연염색 |
| **경쟁사 벤치마크** | 케네스레이디 프리미엄 → 사이즈 inclusivity 추가 |

### 4. 크로스셀 (Cross-sell)

| 항목 | 내용 |
|------|------|
| **구조** | 원피스 + 커버업 + 선캡 + 슬리퍼 + 백 |
| **타겟** | 여행 풀 준비 고객, 휴양지 완벽 룩 원하는 층 |
| **경쟁사 벤치마크** | 비치웨어 전문 브랜드 → 원피스+커버업 결합 강화 |

### 5. 예약판매 (Pre-order)

| 항목 | 내용 |
|------|------|
| **구조** | 와디즈 여행 시즌 한정판 얼리버드 20% 할인 |
| **타겟** | 여행 계획 고객, 한정판 선호층 |
| **목적** | 수요 검증 + 초기 자금 확보 + 재고 리스크 최소화 |

## 경쟁사 대비 차별점 요약

| 차별 요소 | 내용 |
|----------|------|
| **진입장벽** | 미니 19,200원 (케네스레이디 10~40만원 대비 낮음) |
| **사이즈 폭** | 44~120 (빅사이즈 6.4% CTR + 휴양지 5.8% 결합) |
| **청정구역** | "빅사이즈 휴양지원피스" 결합 키워드 데이터 전무 |
| **체형 커버** | 셔링·랩 + 조절식 (갑갑하지 않는 핏) |
| **여행 특화** | 휴양지 풀 룩 큐레이션 |

## MD 라인업 시각화

```
                       ┌─────────────┐
                       │  프리미엄   │ 69,000원
                       │  실크+가디건 │ (한정판)
                       └──────┬──────┘
                              │
              ┌───────────────┼───────────────┐
              ▼               ▼               ▼
    ┌─────────────┐  ┌─────────────┐  ┌─────────────┐
    │   세트/번들   │  │   메인상품   │  │  미끼상품   │
    │ 비치세트 58,000원 │ │  메인 39,000원 │ │ 미니 19,200원 │
    │ 휴양지 풀 룩  │  │ 44~120 FREE │ │  (체험용)   │
    └─────────────┘  └─────────────┘  └─────────────┘
           │                  │                  │
           └────────────────┴──────────────────┘
                              │
                    ┌─────────▼─────────┐
                    │ 시즌별 휴양지 구독 │
                    │  + 여행 큐레이션   │
                    └───────────────────┘
```

## 실행 액션 아이템

| 순위 | 액션 | 기대 효과 |
|------|------|----------|
| 1 | 다양한 체형 모델 룩북 (44/66/95/120) | 사이즈 inclusivity 시각화 |
| 2 | "빅사이즈 휴양지원피스" 청정구역 선점 | 결합 키워드 데이터 전무 공략 |
| 3 | 여행 시즌 한정판 컬렉션 런칭 | 시즌 수요 포획 |
| 4 | 휴양지 큐레이션 콘텐츠 (제주/강릉/해외) | 여행 타겟 매칭 |

| 발견 | 데이터 근거 |

| **40·50대 CTR 최상위** | 연령별 CTR 13~18% |
