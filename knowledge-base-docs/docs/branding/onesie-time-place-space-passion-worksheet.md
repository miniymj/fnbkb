## 워크시트 개요

앞서 발견한 **"디자인과 사이즈를 동시에 — 체형 걱정 없는 휴양지 스타일"** 아이디어를 4개 축(Time/Place/Space/Passion Points)에 맞춰 각각 한 문장씩 기술합니다. 완성된 4문장을 하나의 장면(Scene)으로 묘사하여, GPT 이미지 스토리보드의 핵심 소스로 활용합니다.

> **청정구역 발견**: 휴양지원피스(CTR 5.8%)·빅사이즈(6.4%) 개별 검증됐지만 **"빅사이즈 휴양지원피스" 결합 키워드는 데이터에 전무** → 시장 공백이자 선점 기회.

---

## 4개 축 한 문장 기술

| 축 | 한 문장 기술 |
|:---|:---|
| ⏰ **Time** | "소비자는 **여름 휴가철 7~8월, 주말 여행 시간에, 체형 스트레스 없이 입는 여행 패션**으로 이 원피스를 착용한다." |
| 📍 **Place** | "이 제품은 **해변·리조트·휴양지 비치클럽, 여행지 카페**에서 사용된다." |
| 🏠 **Space** | "**밝고 시원한 리조트·비치 무드, 자유롭고 편안한** 분위기의 공간과 어울린다." |
| ❤️ **Passion Points** | "소비자는 이 제품을 통해 **체형 걱정 없이 즐기는 여행과 '나답게 입는 자신감'을 실현한다." |

## 완성된 장면 (Scene) 묘사

### 스토리보드용 장면: "여름의 바다, 나답게 서다"

> **7월 둘째 주 토요일 오후 2시, 제주도 함덕 해변**

46세 주부 김영숙이 해변에 서 있다.
그녀의 몸을 감싸고 있는 것은 **셔링 디테일이 있는 린넨 원피스**.
44~120까지 커버하는 사이즈, 하지만 그녀에게는 완벽하게 핏이 되어 있다.

과거의 기억이 떠오른다:
- "체형 때문에 비치웨어는 안 입어"
- "다들 예쁘게 입는데 나만..."

하지만 오늘은 다르다.
셔링이 뱃살을 숨겨주고, 랩 디테일이 허리 라인을 살려준다.
통기성 좋은 린넨이 30도의 열기를 식혀준다.

해변을 걷는 영숙의 모습:
- 파도 위를 걷는 듯한 자신감
- 체형 의식 없이 자연스럽게 웃는 얼굴
- 가족사진 속 가장 빛나는 주인공

이것은 단순한 원피스가 아니다.
**"체형 커버와 디자인, 양자택일 없는 선택"**의 완성이다.
44 사이즈도, 120 사이즈도, 모두가 아름답게 느껴지는 순간.

---

### 장면 세부: "사이즈프리의 기적"

> **원단의 신장(Sizing) 편집 현장**

디자이너가 95사이즈 원피스를 44사이즈 마네킨에 입힌다.
너무 크다. 하지만 조절식 웨이스트밴드로 조절하니 완벽해진다.

이번엔 120사이즈 마네킹에 같은 원피스를 입힌다.
역시 완벽하다. 신축성 있는 소재가 체형을 따라간다.

한 벌의 원피스가:
- 40대 마른 여성에게
- 50대 보통 체형에게
- 60대 풀피규어 여성에게

모두에게 **"내 원피스"**가 되는 기적.

## 장면의 핵심 시각 요소 (GPT 이미지 프롬프트용)

| 요소 | 설명 |
|------|------|
| **조명** | 밝은 자연광, 햇살, 바다 반사광 |
| **공간** | 해변 모래사장, 리조트 수영장, 야자나무 그늘 |
| **제품** | 셔링·랩 디테일 원피스, 린넨/레이온 소재, 체형 커버 핏 |
| **인물** | 40~60대 여성, 다양한 체형 (44~120), 자신감 있는 미소 |
| **분위기** | 여유, 자유, 체형 긍정, 여행의 즐거움 |
| **컬러** | 바다 블루, 샌드 베이지, 화이트, 코랄, pastel tones |

## USP와 가치 제안

### 고객에게 제시할 가치

| 가치 | 설명 |
|------|------|
| **기능적 가치** | 셔링·랩 체형 커버, 44~120 사이즈 휴양지원피스, 신축성 소재 |
| **감성적 가치** | 체형 스트레스 해소, 여행의 자유, "나답게" 입는 자신감 |
| **사회적 가치** | 체형 다양성 inclusivity, 40·50대 여성 뷰티 리프레셰 |
| **경제적 가치** | 한 벌로 다양한 체형 커버, 가족/친구와 공유 가능 |

### 일관된 USP 문구

```
"체형과 디자인, 양자택일 없는 휴양지원피스"
"44부터 120까지, 모두가 아름다운 바다"
"체형 걱정 없는 여행, 시작하세요"
```
