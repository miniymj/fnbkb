## 워크시트 개요

앞서 발견한 **"청정구역"** 아이디어를 4개 축(Time/Place/Space/Passion Points)에 맞춰 각각 한 문장씩 기술합니다. 완성된 4문장을 하나의 장면(Scene)으로 묘사하여, GPT 이미지 스토리보드의 핵심 소스로 활용합니다.

---

## 4개 축 한 문장 기술

| 축 | 한 문장 기술 |
|:---|:---|
| ⏰ **Time** | "소비자는 **하루 일과를 마친 저녁 8~10시, 혹은 아침 출근 전 6~7시**에 이 제품을 **샤워하며 사용한다**." |
| 📍 **Place** | "이 제품은 **집의 욕실·샤워 공간**에서 사용된다." |
| 🏠 **Space** | "**깨끗하고 정돈된, 미니멀하고 친환경적인** 분위기의 공간과 어울린다." |
| ❤️ **Passion Points** | "소비자는 이 제품을 통해 **나를 위한 작은 친환경 실천과 지속가능한 라이프스타일**을 실현한다." |

---

## 완성된 장면 (Scene) 묘사

### 스토리보드용 장면

> **장면: "청정의 시작, 샴푸 하나에서 시작하는 작은 혁명"**

---

**저녁 8시 30분, 회사에서 돌아온 28세 직장인 민지의 욕실**

욕실 조명은 은은한 웜화이트 ton으로 켜져 있다. 
욕실 한구석, 세면대 위에는 쓰레기 없는 삶을 상징하듯 **나무 받침대 위에 올려진 샴푸바 하나**가 덩그러니 놓여 있다. 
포장은 없다. 플라스틱 병도 없다. 오직 순수한 성분이 압축된 직육면체 덩어리뿐.

민지가 샴푸바를 손에 쥐고 미지근한 물을 적신다. 
부서지기 쉬운 듯한 텍스처가 물과 만나 **부드러운 거품**으로 변한다. 
그 거품이 머리카락을 감싸는 순간, 하루 동안 쌓였던 먼지와 스트레스가 함께 씻겨나간다.

이것은 단순한 샴푸가 아니다.
**"가능한 친환경"**을 선택하는 작지만 의미 있는 선택이다.
플라스틱 병 하나를 덜 쓰는 것. 천연 성분으로 내 두피를 돌보는 것.
편리함과 생활함, 양자택일 없는 **불가능한 실력**을 경험하는 순간.

샴푸거품이 씻겨내려간 욕실 바닥에는, 
자연스럽게 분해되는 성분만이 남는다.
이것이 민지가 매일 밤 마주하는 **나만의 청정구역**이다.

---

## 장면의 핵심 시각 요소 (GPT 이미지 프롬프트용)

| 요소 | 설명 |
|------|------|
| **조명** | 은은한 웜화이트, 촛불이나 무드등 따뜻한 분위기 |
| **공간** | 미니멀한 욕실, 나무/자연 소재, 식물 배치, 정돈된 정리 |
| **제품** | 나무 받침대 위의 샴푸바, 포장 없는 순수한 형태, 거품 |
| **인물** | 20대 후반~30대 초반 여성, 편안한 표정, 샴푸 중이거나 씻고 난 후 |
| **분위기** | 평화, 청정, 친환경, 자연, 지속가능성 |
| **컬러** | 초록, 화이트, 나무 브라운, 파스텔 톤 |

## USP와 가치 제안

### 고객에게 제시할 가치

| 가치 | 설명 |
|------|------|
| **기능적 가치** | 펌/염색 후에도 가능한 순한 성분, 두피 자극 최소화 |
| **감성적 가치** | 하루 끝의 힐링 타임, 나를 위한 작은 사치 |
| **사회적 가치** | 플라스틱 쓰레기 감소, 친환경 라이프스타일 실현 |
| **경제적 가치** | "가능한" 가격으로 접근 가능한 친환경 선택 |

### 일관된 USP 문구

```
"가능한 친환경, 불가능한 실력"
"샴푸 하나로 시작하는 청정구역"
"편리함과 생활함, 양자택일 없는 선택"
```
