## 🎯 BRAND CONCEPT

**Confident Curation — 당당한 큐레이션**

"상황에 맞는 완벽한 핏, 체형에 맞는 나만의 스타일"

상황(면접·하객·오피스)과 체형(키·밴딩)을 동시에 큐레이션하는 전문관. 트렌드를 쫓는 것이 아니라, **자신의 체형과 상황에 가장 적합한 선택**을 돕는 브랜드. 프로페셔널하면서도 따뜻한 맞춤 감각.

## 📐 설계 방법론

### 왜 이 6색인가 — BMC 4축 연동

| 축 | BMC 요소 | 컬러 반영 |
|---|---------|----------|
| **Target (19~45세 여성 3세그먼트)** | 면접·하객·오피스 상황별 수요, "체형에 맞는" 자신감 | 네이비(프로페셔널) + 아이보리(청정) + 코랄(자신감) |
| **Value (상황×체형 큐레이션)** | 청정구역, "상황별 핏, 첫인상의 완성" | 네이비(신뢰) + 비스트(따뜻한 큐레이션) + 라벤더(포용) |
| **Place (오피스·면접장·웨딩홀)** | 프로페셔널 공간, 세련된 무드 | 네이비(격식) + 차콜(고급) + 아이보리(깨끗함) |
| **Passion (자신감·당당함·맞춤)** | "나를 믿어보세요", 체형 긍정 | 코랄(자신감) + 네이비(신뢰) + 라벤더(포용) |

### 색채 심리학 근거

> 색채 심리학은 **색상이 인간의 감정·행동·인지에 미치는 영향**을 연구하는 학문입니다. 브랜드 컬러는 구매 결정의 **50~85%**에 영향을 미치며, 소비자가 브랜드를 가장 먼저 시각적으로 인식하는 요소입니다.

## 🎨 컬러별 색채 심리학 해설

### 1. Primary — 넌 트루 네이비 `#1B3A5C`

| 항목 | 내용 |
|------|------|
| **색채 심리** | **신뢰·프로페셔널·깊이·첫인상**. 네이비는 색채 심리학에서 가장 **신뢰도가 높은 색** 중 하나로, 블랙보다 부드러우면서도 깊은 권위를 전달합니다. 면접·하객·오피스라는 **상황의 공통 언어**가 바로 네이비입니다. |
| **타겟 연동** | 대학생 취준생(29%)이 면접장에서, 직장인(22%)이 출근할 때, 하객(26%)이 웨딩홀에 갈 때 — **모든 상황의 베이스 컬러**. TPSP 장면 1(면접)의 핵심 컬러 힌트 "네이비, 화이트, 그레이"를 직접 수용합니다. |
| **BMC 연동** | ② 가치제안 "상황(면접·하객·오피스) × 체형(키·밴딩)을 맞춘 치마 큐레이션" — **"첫인상의 3초"**를 책임지는 시각적 앵커. MD 라인업 Core 색상(블랙, 네이비, 베이지, 그레이) 중 네이비를 브랜드 Primary로 승격합니다. |
| **사용 비율** | 전체의 **35~40%** (로고, 네비게이션, 헤더, 주요 블록) |

#### 색채학 분석

- **명도(Value)**: 36% (중간~낮음) — 안정감, 깊이
- **채도(Saturation)**: 55% (중간~높음) — 프로페셔널한 생동감
- **색온도**: 쿨톤 — Secondary(웜 아이보리)와 **보색 대비 효과** → 시선 유도
- **비교**: `#000000`(블랙)보다 **15% 더 따뜻한 느낌** — 완전한 블랙의 무거움을 피하고, 신뢰를 유지
- **Pantone 근사**: 289 C (Classic Blue 근처)

#### 왜 블랙이 아닌가

MD 라인업에 블랙이 포함되어 있으나, 브랜드 아이덴티티 Primary로서의 블랙은 **"경쟁사(스누디·UNIQLO·데일리앤)와 동일한 블랙"**으로 차별화가 어렵습니다. 넌 트루 네이비는 블랙의 **신뢰감을 유지하면서 '상황별 큐레이션 전문관'의 지성과 깊이**를 더하는 선택입니다.

### 2. Secondary — 웜 아이보리 `#F7F4EF`

| 항목 | 내용 |
|------|------|
| **색채 심리** | **순수·여백·깨끗함·시작**. 완전한 흰색(`#FFFFFF`)의 차가움을 피하고, 미세한 웜톤이 섞인 아이보리는 **"깨끗하면서도 따뜻한"** 인상을 줍니다. 새로운 시작(면접), 축하(하객), 매일의 출발(오피스)을 상징합니다. |
| **타겟 연동** | 19~45세 여성이 브랜드와 처음 만나는 순간 — **"여기는 나의 상황을 이해하는 공간"**이라는 메시지를 배경색으로 전달합니다. TPSP 전 장면의 공통 컬러 힌트 "화이트"를 웜톤으로 정제합니다. |
| **BMC 연동** | ② 가치제안 "상황별 핏, 첫인상의 완성" — **여백이 곧 완성**이라는 큐레이션 철학의 시각적 표현. ⑥ 핵심 자원 "10년차 디자인 디렉터 감각" — 디자이너 브랜드의 정체성 = 여백. |
| **사용 비율** | 전체의 **25~30%** (배경, 카드, 여백) |

#### 색채학 분석

- **명도(Value)**: 97% (매우 밝음) — 개방감·여유로움
- **채도(Saturation)**: 4% (매우 낮음) — 차분함·고급스러움
- **색온도**: 웜톤 (R:247, G:244, B:239 — 레드 채널 미세 우위)
- **비교**: `#FFFFFF`(순백)보다 **14% 더 따뜻한 느낌** — 병원·화장실의 차가운 흰색과 차별화
- **Pantone 근사**: 663 C (Warm White 근처)

### 3. Tertiary — 샌드 비스트 `#C4A77D`

| 항목 | 내용 |
|------|------|
| **색채 심리** | **따뜻함·자연·안정·신뢰**. 베이지 계열은 색채 심리학에서 **편안함과 접근성**을 나타냅니다. 샌드 비스트는 "경험 있는 큐레이터의 따뜻한 손길"을 연상시킵니다. |
| **타겟 연동** | 3세그먼트 모두가 느끼는 **"이 브랜드는 나를 따뜻하게 안내해준다"**는 감정. MD 라인업 Core 색상 중 **베이지**를 브랜드 팔레트에 직접 수용합니다. |
| **BMC 연동** | ⑤ 수익 흐름 Entry 19,000원 / Core 29,000원 — **접근 용이성**을 색으로 표현. "누구나 편하게 들어올 수 있는 큐레이션 샵" |
| **사용 비율** | 전체의 **15~20%** (카드 배경·보더·구분선·태그) |

#### 색채학 분석

- **명도(Value)**: 76% (밝음) — 가독성 확보
- **채도(Saturation)**: 36% (중간) — 자연스러운 따뜻함
- **색온도**: 웜톤 — Secondary(아이보리)와 **유사색 조화** → 통일감
- **Pantone 근사**: 155 C (Sand Beige 근처)

### 4. Accent 1 — 블러시 코랄 `#D4856A`

| 항목 | 내용 |
|------|------|
| **색채 심리** | **자신감·우아함·여성성·감성**. 코랄 계열은 색채 심리학에서 **자신감과 사교성을 높이는** 색으로 연구됩니다. 붉은색의 열정을 부드럽게 순화하여 **공격적이지 않은 당당함**을 표현합니다. |
| **타겟 연동** | TPSP 장면 2(하객)의 핵심 감정 — **"축하의 자리에서도 과하지 않은 적절한 비중"**. 장면 4(큐레이션) 컬러 힌트 "코랄"을 직접 수용하여, **체형 긍정과 자기 수용**의 시각적 상징으로 활용합니다. |
| **BMC 연동** | ② 가치제안 "체형에 맞는 스커트, 상황에 맞는 스타일" — **선택의 기쁨과 당당함**을 시각화. "나를 믿어보세요"라는 무언의 메시지. |
| **사용 비율** | 전체의 **5~8%** (하이라이트·CTA·세일 태그·하객 캠페인) |

#### 색채학 분석

- **명도(Value)**: 64% (중간) — 우아한 가시성
- **채도(Saturation)**: 53% (높음) — Accent 역할, 시선 집중
- **색온도**: 웜톤 — 네이비(쿨톤)와 **보색 대비** → 강력 시선 유도 포인트
- **Pantone 근사**: 1635 C (Living Coral 변형)

### 5. Accent 2 — 소프트 라벤더 `#A89BB5`

| 항목 | 내용 |
|------|------|
| **색채 심리** | **포용·균형·섬세함·감성**. 라벤더(퍼플 계열)는 색채 심리학에서 **창의성, 섬세함, 포용**을 나타냅니다. 소프트 라벤더는 강하지 않은 우아함으로 **"다양한 체형과 상황을 포용하는"** 브랜드 철학을 시각화합니다. |
| **타겟 연동** | 155cm 대학생부터 172cm 하객 참석자까지, 44~99 사이즈 모두를 **포용**하는 큐레이션 정신. TPSP 장면 2(하객) 컬러 힌트 "파스텔, 핑크, 민트"의 감성을 라벤더로 승화합니다. |
| **BMC 연동** | ④ 고객 관계 "체형별 사이즈 팁 + 후기 신뢰" — **사이즈 inclusivity(포용)**의 시각적 상징. 청정구역 "체형×스타일 큐레이션 전문관"의 감성적 표현. |
| **사용 비율** | 전체의 **5~8%** (태그·부가 정보·시즌 캠페인·프리미엄 라인) |

#### 색채학 분석

- **명도(Value)**: 70% (중간~밝음) — 편안한 가독성
- **채도(Saturation)**: 14% (낮음) — 차분함, 과하지 않음
- **색온도**: 뉴트럴 (퍼플은 웜·쿨 모두 수용) — **중립적 포용**의 시각적 은유
- **Pantone 근사**: 7527 C (Soft Lavender 근처)

### 6. Deep — 인크 차콜 `#2C2E31`

| 항목 | 내용 |
|------|------|
| **색채 심리** | **고급·신뢰·안정·품격**. 완전한 블랙(`#000000`)은 과한 무거움을 줄 수 있습니다. 인크 차콜은 **고급스러움을 유지하면서 접근 가능한** 톤으로, 미니멀하면서도 품격 있는 인상을 전달합니다. |
| **타겟 연동** | 19~45세 타겟이 인지하는 **"디자이너 브랜드의 품격"**. 10년차 디자인 디렉터의 전문성과 신뢰를 텍스트 컬러로 전달합니다. |
| **BMC 연동** | ⑥ 핵심 자원 "10년차 디자인 디렉터 감각" — **전문성·신뢰**의 시각적 기반. MD 라인업 Core 색상 중 **그레이**를 브랜드 Deep 톤으로 승격합니다. |
| **사용 비율** | 전체의 **10~15%** (본문 텍스트·네비게이션·로고 타입) |

#### 색채학 분석

- **명도(Value)**: 19% (어두움) — 텍스트 가독성 확보
- **채도(Saturation)**: 5% (무채색에 가까움) — 차분함·중립
- **명암 대비**: Secondary `#F7F4EF` 대비 **16.2:1** → **WCAG AAA 준수** (본문 텍스트 기준 4.5:1 이상)
- **접근성**: 인크 차콜 + 웜 아이보리 조합은 **시각 장애·고령 타겟(40~60대)에게 최적화된 명암 대비**

## 🔄 컬러 팔레트 조화론 (Color Harmony)

### 색상환 기반 조화 구조

```
                네이비 (#1B3A5C · 쿨)
               ╱                              ╲
    라벤더 (#A89BB5 · 뉴트럴)       코랄 (#D4856A · 웜)
              ╲                              ╱
               비스트 (#C4A77D · 웜)

        ●  웜톤 삼각 조화: 코랄 — 비스트 — 라벤더
        ▲  쿨+웜 대비 축: 네이비(쿨) ↔ 코랄(웜)
        ◆  무채색 앵커: 차콜 (안정) + 아이보리 (청정)
```

### 4가지 조화 원리 적용

| 원리 | 적용 | 효과 |
|------|------|------|
| **유사색 조화 (Analogous)** | 아이보리·비스트·코랄 — 웜톤 3색 | 따뜻한 일체감, 접근성 |
| **보색 대비 (Complementary)** | 네이비(쿨) ↔ 코랄(웜) | 시선 유도, 생동감 |
| **삼각 조화 (Triadic)** | 코랄·비스트·라벤더 — 120° 간격 | 균형 잡힌 다채로움 |
| **무채색 기반 (Achromatic Base)** | 아이보리·차콜 — 2색 기반 | 세련됨, 가독성, 안정감 |

> **핵심 원칙**: 네이비를 Primary(40%)로 설정하여 **프로페셔널한 앵커**를 확보하고, 웜톤(아이보리·비스트·코랄)으로 **따뜻한 접근성**을 더하는 구조. 경쟁사(스누디·데일리앤·UNIQLO)의 **무채색/블랙 중심 팔레트와 명확히 분리**됩니다.

## 📊 컬러 팔레트 vs 기존 브랜드 가이드라인

> 3개 카테고리(바디바·원피스·치마)의 컬러 정체성 비교. 각 아이템의 **컬러 철학이 독립적으로 존재**하도록 설계한 의도입니다.

| 항목 | 바디바 | 원피스 | 치마(스커트) |
|------|--------|--------|-------------|
| **Primary** | 시즈널 세이지 `#7C9C8C` | 세라믹 화이트 `#F5F0EB` | 넌 트루 네이비 `#1B3A5C` |
| **Secondary** | 오트밀 크림 `#FAF6EF` | 라군 블루 `#5B8FA8` | 웜 아이보리 `#F7F4EF` |
| **Accent** | 피치 코랄 `#E07A5F` | 코랄 블러썸 `#E8917A` | 블러시 코랄 `#D4856A` |
| **Deep** | 웜 브라운 잉크 `#3B3A36` | 딥 챠콜 `#2C2C2C` | 인크 차콜 `#2C2E31` |
| **브랜드 톤** | 따뜻한 정화 (Warm Clean) | 바다의 정원 (Garden Sea) | 당당한 큐레이션 (Confident Curation) |
| **공통 베이스** | 웜 크림 계열 | 웜 크림 계열 | 웜 아이보리 계열 |
| **핵심 차이** | 그린 = 자연·정화 | 블루 = 바다·포용 | **네이비 = 프로페셔널·신뢰** |

> 💡 세 카테고리 모두 **웜톤 베이스(크림/아이보리)**를 공유하면서, **Primary 컬러로 아이템 특성을 분리**합니다. 바디바=그린(자연), 원피스=블루(바다), 치마=네이비(프로페셔널). 셀러가 복수 카테고리를 운영할 때 **통일된 브랜드 패밀리 + 독립적인 아이템 정체성**을 동시에 구축합니다.
