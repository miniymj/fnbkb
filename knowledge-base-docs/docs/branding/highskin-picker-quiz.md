# 하이피부(HIGHSKIN) 픽커 퀴즈 — "나만의 하이피부 친구 만들기"

> **작성일**: 2026-08-09
> **목적**: 구매 홈페이지 진입 시 고객 맞춤 설문(피부타입·향·얼굴 커스텀) → 캐릭터 완성 → 추천 상품+쿠폰 구매유도
> **제작 도구**: 스모어(Smore) 설문조사 — 문항 카드·분기 로직·이미지 옵션 사용
> **그래픽 스타일**: Pinterest 보드 '바디바 표정들, 로고 등' 분석 기반 — 아이 손그림·둥근 셰이프·크림-핑크 파스텔 (그래픽 생성 프롬프트는 `moodboard-prompt-guide.md` 부록 B 참고)
> **팔레트**: Cream `#FFF8EF` · Soft Pink `#F6A6B8` · Milk Pink `#FCE8EC` · Apricot `#F4B27D` · Soft Sage `#AFC7A8` · Leaf Green `#6F9470` · Deep Brown `#403735`

## 🎯 설문 전략

| 목표 | 방법 |
|---|---|
| **재미** | 눈·코·입을 골라 "나만의 하이피부 친구" 완성 — 인형 하듯 꾸미는 놀이 |
| **특별함** | 이름을 입력하면 "OO님 전용 하이피부 친구" + 이름이 박힌 쿠폰 발급 |
| **구매유도** | 결과 → 피부타입×향 매칭 상품 1~2종 CTA + 첫 구매 쿠폰 + 리필 구독 유도 |
| **SNS 바이럴** | 완성 캐릭터 이미지 저장/공유 버튼 (공유 이벤트) |

**플로우 요약**
```
참여 시작 → ① 피부타입 → ② 향 → ③ 얼굴 꾸미기(눈→코→입) → ④ 이름 짓기(선택)
        → 🎁 결과: 캐릭터 완성 + 추천 상품 + 쿠폰 + 공유
```

## 📋 문항 카드 (스모어 복붙용)

### Q1 · 내 피부는요? (피부타입 — 이미지+텍스트, 이모지 캐릭터)

| 옵션 | 표정 캐릭터 | 멘트 | 추천 결과군 |
|---|---|---|---|
| 💧 건성 | 말라서 쭈글 (눈 감음) | "건조해요, 당기는 느낌이 아쉬워요" | 수분·진정 바디바 |
| 🍑 민감 | 연갈색 볼, 조심스런 눈 | "자극이 제일 걱정돼요" | 구성 성분 배제·무향 베이스 |
| 🌿 지성/복합 | 반짝이는 이마 | "T존이 번들거려요" | 과하지 않은 딥 클렌징 |
| 😌 무난/보통 | 편안한 미소 | "온 가족이 함께 써요" | 올라운드 밸런스 |

### Q2 · 어떤 향을 원해요? (향 — 이미지+텍스트, 향을 맡는 코 킁킁 캐릭터)

| 옵션 | 향 설명 | 멘트 |
|---|---|---|
| 🌿 허브 & 라벤더 | 스파에서 쉬는 느낌 | "하루의 피로를 풀게 해줘요" |
| 🍊 시트러스 | 아침처럼 상쾌 | "눈이 번쩍! 기분까지 리프레시" |
| 🌸 소프트 플로랄 | 은은한 꽃 향 | "싸-하게 남지 않는 포근한 향" |
| 💚 프레쉬 그린 | 유칼립투스·로즈마리 | "숲 속에서 샤워하는 기분" |
| 🚿 무향 | 순수 그대로 | "향 없이 가장 순하게" |

### Q3 · 얼굴 꾸미기 — 나의 하이피부 친구 (핵심 재미요소)

> 세 단계로 진행: ① 눈 → ② 코 → ③ 입. **각 선택지에 이미지 옵션**(나노바나로 생성한 부품 시트) 사용.
> 스타일: 아이 손그림 — 두꺼운 선 없이 부드럽고 삐뚤어진 손그림, 크림 배경 + 소프트 핑크/세이지 부품.

**3-1. 눈을 골라줘** (4종)
| 부품 | 이름 | 성격 |
|---|---|---|
| ⭐ 반짝 별눈 | 별빛 하이피부 | 설레는 기대 |
| 🥰 감은 미소눈 | 포근 하이피부 | 편안한 휴식 |
| 👀 큰 동그란 눈 | 호기심 하이피부 | 놀라운 발견 |
| 💖 하트 눈 | 사랑 가득 하이피부 | 두근두근 |

**3-2. 코를 골라줘** (3종)
| 부품 | 이름 |
|---|---|
| • 작은 점코 | 콕! 똑똑이 코 |
| ⚪ 둥근 콩알코 | 포동포동 코 |
| ~ 삐죽 삐죽코 | 재미꾼 코 |

**3-3. 입을 골라줘** (4종)
| 부품 | 이름 | 성격 |
|---|---|---|
| 😆 크게 웃는 입 | 킥킥 하이피부 | 웃음 보증 |
| 🙂 고양이 입 | 냥냥 하이피부 | 도도+귀여움 |
| 💗 하트 입 | 몽글 하이피부 | 애교 만렙 |
| 😌 잔잔 미소 입 | 차분 하이피부 | 은은한 안심 |

### Q4 · 이름 짓기 (선택 — 특별함 포인트)

- 입력창: **"우리 하이피부 친구 이름을 지어주세요"**
- 완성 화면: *"[이름]이(가) 태어났어요! 이제 [고객명]님의 하이피부 친구예요."*
- 쿠폰: *"[이름] 전용 10% 쿠폰"* — 이름이 박히는 맞춤형 혜택으로 특별함+구독 유도

## 🎁 결과 화면 (구매 유도 설계)

| 요소 | 내용 |
|---|---|
| **캐릭터 완성도** | 선택한 눈·코·입 조합이 적용된 하이피부 캐릭터 1마리 (Q1·Q2 결과에 따라 배경색·소품 차등) |
| **피부타입×향 매칭** | 추천 바디바 1~2종 + **라벨**: 사용자가 고른 피부타입·향에 맞는 포뮬라 설명 |
| **상품 CTA 3단** | ① 리필 홀더 번들(브러시+비누) ② 여행용 미니+거품망 세트 ③ 단품 바디바 |
| **쿠폰** | 첫 구매 10% + 리필 구독 6개월 15% (이름 박힘) |
| **공유** | "내 하이피부 친구 보러 가기" 이미지 저장·SNS 공유 (공유 시 추첨 이벤트) |

### 결과군 분기 로직 (스모어 결과 로직)
- **건성 + (허브/무향)** → 수분·진정 라인 (오트밀·세이지 톤)
- **민감 + 무향** → 센스티브 라인 (크림·무향, 배제 성분 안내)
- **지성 + 시트러스** → 리프레시 라인 (리프 그린·시트러스)
- **그 외 조합** → 밸런스 라인 (소프트 핑크·플로랄)
> 캐릭터 배경색: 라인별로 Soft Pink / Soft Sage / Leaf Green / Apricot 배정
