# 네이버 API 권한 신청 가이드

> 검색트렌드 API 사용을 위한 인증 절차

---

## ⚠️ 현재 상황

API 인증 정보는 있으나 **검색트렌드 API 권한**이 필요합니다.

---

## 🔑 권한 신청 단계

### 1. 네이버 개발자센터 접속

https://developers.naver.com/

---

### 2. 애플리케이션 등록

1. **로그인** → 네이버 계정으로 로그인
2. **Application** → [애플리케이션 등록] 클릭

#### 애플리케이션 정보
- **애플리케이션 이름**: 패션뷰티 시장조사
- **사용 API**: 검색트렌드 API 선택 ⭐
- **비 로그인 오픈 API 서비스**: ON
- **환경**: 다른 PC에서도 호출 허용

---

### 3. 검색트렌드 API 권한 신청

⚠️ **중요**: 검색트렌드 API는 별도 권한 신청이 필요합니다!

1. **[검색트렌드 API]** 탭 클릭
2. **[API 권신청]** 버튼 클릭
3. **신청 내용 작성**:
   - **목적**: 시장조사 및 트렌드 분석
   - **사용량**: 하루 100회 이내
   - **사용 예시**: 패션/뷰티 아이템별 검색량 추이 분석

---

### 4. 승인 대기

- **승인 시간**: 보통 1~2 영업일
- **승인 결과**: 이메일 또는 개발자센터 알림

---

## ✅ 권한 승인 후

승인이 완료되면 다음 명령어로 데이터 수집:

```bash
cd /Volumes/MINIY/중랑/scripts
python3 naver_trend_api.py
```

---

## 📋 대안: 수동 데이터 수집

API 승인 대기 중에는 수동으로 데이터를 수집할 수 있습니다.

### 네이버 데이터랩 이용

1. https://datalab.naver.com/shoppingInsights/sCategory.naver 접속
2. 검색어 입력: 원피스, 치마, 스커트, 샴푸바
3. 기간 설정: 최대 10년
4. [엑셀 다운로드] 클릭

### 수집한 파일 저장 위치

```
/Volumes/MINIY/중랑/data/
├── naver_datalab_원피스.xlsx
├── naver_datalab_치마.xlsx
├── naver_datalab_스커트.xlsx
└── naver_datalab_샴푸바.xlsx
```
