> - 40·50대 CTR 최상위 (13~18%) → 셀러 본인(40대) 연령대와 일치

## ① 고객 세분화 (Customer Segments)

**1차 타겟 — 빅사이즈 × 휴양지 결합 (청정구역)**
- 빅사이즈 CTR **6.4%** (실구매 검증) + 휴양지원피스 CTR **5.8%**
- **결합 키워드 "빅사이즈 휴양지원피스" 데이터 전무** → 선점 기회
- 출처: `md-lineup-resort-onesie.md:177-184`, `competitive-analysis-onesie.md:70`

**연령별 타겟 (CTR 데이터 기반)**
- **40·50대 CTR 최상위 (13~18%)** — 셀러 본인(40대) 연령대, 모델 겸 타겟
- 여행 자주 가는 30~60대 여성 (재구매층)
- 체형 걱정 입문자 (44~120 사이즈 포괄)
- 출처: `md-lineup-resort-onesie.md:184`, `competitive-analysis-onesie.md:91`

**페르소나 기반 타겟 (셀러 양민정 관점)**
- 프라이머리: 40~50대 빅사이즈 여성 (체형 스트레스 해소)
- 세컨더리: 휴양지 여행 30~60대 (시즌 수요)
- 터셔너리: 체형 걱정 입문자 (미니 커버업으로 첫 경험)
- 출처: `seller-persona.md:72-75`, `md-lineup-resort-onesie.md:22-26`

**시장 규모**
- 원피스 전체 시장 3,750,000명 (`onesie-potential-customers.md`)
- 그중 빅사이즈·휴양지 결합 니즈는 미검증이지만 CTR 합산 12.2%로 실구매 잠재력 확인

## ② 가치 제안 (Value Proposition)

**핵심 메시지 (BMC ⭐ 블록)**
> "44부터 120까지, 모두가 아름다운 바다 — 디자인과 사이즈를 동시에, 부위별 피팅(셔링·랩) × 44~120 사이즈 휴양지원피스"
> 출처: `md-lineup-resort-onesie.md:36`, `competitive-analysis-onesie.md:92`

**청정구역 차별화 — 경쟁사가 못 하는 것**
- **디자인 + 사이즈 동시 충족** — 경쟁사는 "디자인 **또는** 사이즈" 한쪽만 (`competitive-analysis-onesie.md:64`)
- 44~120 사이즈 포괄 — 빅사이즈 CTR 6.4% 실구매, 아무도 휴양지에서 커버 안 함
- 부위별 피팅 — 셔링·랩·조절식 스트랩으로 체형별 핏
- 출처: `md-lineup-resort-onesie.md:36-48`, `competitive-analysis-onesie.md:92`

**제품별 포지셔닝 메시지**
- 미끼(미니 커버업): "체형과 디자인, 양자택일 없는 첫 경험"
- Core(휴양지원피스): "44부터 120까지, 모두가 아름다운 바다"
- Premium(실크+가디건): "여행의 특별한 순간, 실크로 완성하다"
- 출처: `md-lineup-resort-onesie.md:24,36,58`

**디자이너 역량 (무형 자산 — 경쟁자 복제 불가)**
- 10년차 디자인 디렉터 → 체형별 피팅 패턴 설계 역량
- VMD 경력 → 다체형 모델 룩북 연출 품질
- 출처: `seller-persona.md:27-29`

## ④ 고객 관계 (Customer Relationships)

**관계 전략**
> 실측 사이즈 차트 + 다체형 모델 룩북(44/66/95/120) + 체형별 후기 + 사이즈 큐레이션
> 출처: `competitive-analysis-onesie.md:94`

**신뢰 기반 관계 (데이터 근거)**
- 착용 후기/리뷰 **29.44% 비포화** → 실측 사이즈 차트·다체형 모델 룩북으로 신뢰 구축
- 코디/액세서리 **23.84%** → 휴양지 풀 룩 큐레이션으로 관계 강화
- 출처: `onesie-potential-customers.md`

**사이즈 inclusivity 락인 (차별화 관계)**
- 44/66/95/120 다체형 모델 룩북 → "내 체형도 예쁘게 나온다" 신뢰
- 다체형 후기 시스템 → 체형별 실착용 데이터 축적
- 출처: `md-lineup-resort-onesie.md:170`

**시즌 컬렉션 구독 (재구매 락인)**
- 시즌별 휴양지 컬렉션 구독 + 10% 할인 + 여행지 추천 큐레이션
- 여행 자주 가는 30~60대 재구매층 타겟
- 출처: `md-lineup-resort-onesie.md:87-92`
