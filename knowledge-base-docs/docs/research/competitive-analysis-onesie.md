# PART 2. 차별화 포인트

## 실습: 레드오션/청정구역 매핑

> 브랜드 A = 써스데이아일랜드, B = 케네스레이디, C = 타이니모

| BMC 블록 | 브랜드 A (써스데이) | 브랜드 B (케네스레이디) | 브랜드 C (타이니모) | 판정 |
|----------|----------|----------|----------|------|
| 가치 제안 (VP) | 디자인·문화 영감 | 체형 커버 디테일 | 사이즈 폭 + 가격 | 🔴 모두 "디자인 **또는** 사이즈" 한쪽 |
| 고객 세그먼트 (CS) | 30~50대 디자인 소비층 | 30~50대 하객·오피스 | 20~40대 중저가 | 🔴 모두 20~50대 여성 |
| 채널 (CH) | 백화점+몰 | 백화점 중심 | 온라인 몰 | 🔴 모두 멀티채널 |
| 고객 관계 (CR) | 브랜드 스토리 | 매장 서비스 | 리뷰·상세페이지 | 🔴 모두 신뢰·콘텐츠형 |
| 수익원 (RS) | 시즌 컬렉션 단품 | 고가 단품 | 중저가 단품 | 🟢 "사이즈프리 × 휴양지" 선점하는 곳 없음 |

> **🎯 발견된 청정구역**: "디자인과 사이즈를 **동시에** 갖춘 **휴양지원피스**" — 시장진출 보고서 검증: 휴양지원피스(CTR 5.8%)·빅사이즈(6.4%) 개별 검증됐지만 **결합 키워드(빅사이즈 휴양지원피스)는 데이터에 전무** → 미검증 니즈이자 선점 가능 공백.

## 실습: Time/Place/Space/Passion Points 형상화

> 실습 대상: **사이즈프리 휴양지원피스**

| 축 | 한 문장 기술 |
|----|-------------|
| ⏰ Time | "소비자는 여름 휴가철과 주말 여행 시간에, 체형 스트레스 없이 입는 여행 패션으로 이 원피스를 착용한다." |
| 📍 Place | "이 제품은 해변·리조트·휴양지에서, 그리고 비치웨어로 여행 캐리어에 담겨 이동한다." |
| 🏠 Space | "밝고 시원한 리조트·비치 무드의 공간과 어울린다." |
| ❤️ Passion Points | "소비자는 이 제품을 통해 체형 걱정 없이 즐기는 여행과 '나답게 입는 자신감'을 실현한다." |

# PART 3. 상품 구성 설계

## 실습: 비즈니스모델 캔버스 BMC 작성

| BMC 블록 | 내 비즈니스 모델 내용 | 출처 (경쟁사 참조 / 청정구역) |
|----------|---------------------|------------------------------|
| 고객 세그먼트 (CS) | 40·50대 빅사이즈 여성 + 휴양지 여행 수요 30~60대 | 연령 특화 키워드 CTR 최상위(13~18%) |
| 가치 제안 (VP) ⭐ | "디자인과 사이즈를 동시에 — 부위별 피팅(셔링·랩) × 44~99+ 사이즈 휴양지원피스" | **청정구역**: 사이즈프리 × 휴양지 결합 전무 |
| 채널 (CH) | 네이버 스마트스토어 + 블로그/인스타 코디 콘텐츠 | SNS 몰(아뜨랑스) 채널 벤치마크 |
| 고객 관계 (CR) | 실측 사이즈 차트 + 체형별 후기 + 사이즈 큐레이션 | 리뷰 신뢰 (착용 후기 비포화 29.4%) |
| 수익원 (RS) | 단품 + 시즌 세트 + 커버업 번들 | 2~4만원 HIT 가격 구간 |
| 핵심 자원 (KR) | 디자이너 감각, 체형별 피팅 데이터, 원단 소싱 | 페르소나 디자인 역량 |
| 핵심 활동 (KA) | 코디 콘텐츠, 사이즈 큐레이션, 시즌 기획 | 인스타 코디 마케팅 |
| 핵심 파트너 (KP) | OEM 제조, 린넨·레이온 원단 공급사 | - |
| 비용 구조 (C$) | 원단·제조비, 콘텐츠 제작비, 광고비 | 통기성 소재 중심 → 원단 원가 |

## 실습: 경쟁사 상품구성 분석

> 경쟁사 A = 우리다움(사이즈 직접 경쟁), B = 타이니모(사이즈+가격 직접 경쟁) — ⚠️ 수치 **추정**

| 구성 패턴 | 경쟁사 A (우리다움) | 경쟁사 B (타이니모) | 내가 참고할 점 |
|-----------|----------|----------|----------------|
| 가격대 라인업 | 3~5만원 | 2~4만원 | 2~4만원 진입 + 5만원대 프리미엄 2단 |
| 옵션 구성 | 66~130 사이즈 | 44~99 사이즈 | 44~120 사이즈(CTR 5.4~9.9%) 포괄 |
| 번들/세트 구성 | - | - | 원피스 + 비치웨어/커버업 번들 |
| 정기구매/구독 | - | - | 시즌 신상 구독 알림 |
| 무료배송 조건 | 일정 금액 이상(추정) | 일정 금액 이상(추정) | 3만원 이상 무료배송 |

## 실습: 내 상품구성 설계

| 적용 방식 | 선택 (✅) | 구체적 구성안 | 예상 효과 |
|-----------|----------|----------------|-----------|
| ① 정기구매 | ✅ | 시즌별 신상 구독 + 멤버십 5% 할인 | 재구매율 상승 |
| ② 묶음판매 | ✅ | 린넨 휴양지원피스 + 빅사이즈 커버업 2종 세트 | 객단가 상승, 교차 구매 |
| ③ 업셀 | ✅ | 기본: 린넨/레이온 / 프리미엄: 실크·자연염색 한정판 | 객단가 상승 |
| ④ 크로스셀 | ✅ | 원피스 + 비치웨어 + 유자 리넨 가방 "휴양지 룩 세트" | 연관 구매 유도 |
| ⑤ 예약판매 | ✅ | 와디즈 얼리버드 20% 할인, 목표 200개 | 출시 전 수요 검증 |

> **MD 라인업 연결**: ① 미끼상품 = 비치웨어(래쉬가드 커버업) · ② 메인상품 = 린넨 휴양지원피스(셔링·랩) · ③ 프리미엄 = 실크·자연염색 한정판 · ④ 세트/번들 = 휴양지 룩 세트
