# 경쟁사 리뷰 조사 · 클렌징 · 분석 방법론

> 하꼬·중저가 경쟁사(`small-brand-competitors.md` 참조)의 **실제 리뷰**를 신뢰할 수 있는 인사이트로 바꾸는 실행 방법
> 리뷰에는 광고성·체험단·이벤트 리뷰가 섞여 있어, **클렌징 없이는 소비자 니즈를 왜곡**한다. 이 문서는 조사 → 클렌징 → 분석 → 인사이트 4단계를 정의한다.
> 작성일: 2026-08-03 | 실행 도구: `scripts/review_cleaner.py`

---

## 왜 클렌징이 필수인가

아로마티카 벤치마킹 조사 결과, 브랜드 바디바 관련 UGC 중 상당수가 **체험단·서포터즈 협찬 콘텐츠**("새싹에디터")였습니다. 이런 리뷰를 그대로 분석하면:
- ✅ 좋은 리뷰 비율이 과장됨 (광고성 5점 다수)
- ✅ 진짜 불만(예: 아로마티카 "보습력 62%")이 묻힘
- ❌ 차별화 인사이트(불만 → USP)를 놓침

따라서 **광고성 리뷰 제거 → 중복·노이즈 정리 → 진짜 소비자 목소리 분석**이 핵심입니다.

## 1단계: 리뷰 조사 (어디서 수집할까)

| | 아로마티카 | **올리브영**·네이버쇼핑·자사몰 | 올리브영 리뷰 (평점·토픽%) |

| | 핫핑 | 무신사 | 무신사 리뷰 |

### 수집 방법 (2가지 병행)

1. **AI 요약리뷰 활용 (네이버쇼핑·쿠팡 제공)**
   - 상품 상세의 AI 요약 태그(긍정/부정 토픽 %)와 별점 분포를 캡처
   - 예: 아로마티카 올리브영 — "향 만족도 86% / 보습력 62%" 같은 집계 바로 확보
   - → 광고성 리뷰가 이미 어느 정도 집계에서 희석됨

2. **원본 리뷰 텍스트 수집 → 클렌징 도구**
   - 네이버쇼핑/쿠팡/자사몰 리뷰 탭에서 베스트 리뷰 + 최근 리뷰를 **텍스트로 복사**
   - 입력 형식: 리뷰 1줄 = 1건, 별점 있으면 `5점, 리뷰내용` 형식
   - → `scripts/review_cleaner.py`로 클렌징·분석 (아래 실행 도구 참고)

## 2단계: 리뷰 클렌징 (무엇을 제거할까)

`review_cleaner.py`가 자동 처리하는 제거 규칙:

| 구분 | 판별 키워드 예시 | 이유 |
|------|------------------|------|
| **이벤트·체험단** | 체험단, 서포터즈, 새싹에디터, 제품을 제공, 구매후기 이벤트, 쿠폰 받 | 광고성 — 소비자 진짜 목소리 아님 |
| **노이즈** | 배송 빨라, 포장 꼼꼼, 로켓배송 | 상품 본질(성분·핏·효능)과 무관 |
| **중복** | 같은 문구 반복 | 이벤트 참여용 복붙 리뷰 |
| **극단 짧은 5점** | 15자 미만 5점 | 봇·이벤트성 — 별도 리스트로 분리해 확인 |
| **짧은 리뷰** | 10자 미만 | 정보량 부족 |

> 💡 클렌징 기준은 카테고리별로 조정 가능. `review_cleaner.py`의 `EVENT_PATTERNS`·`NOISE_PATTERNS`·`POSITIVE_WORDS`·`NEGATIVE_WORDS` 리스트를 열어 고치면 됩니다.

---

## 3단계: 리뷰 분석 (무엇을 볼까)

클렌징된 리뷰에서 4가지 지표를 뽑습니다 (`review_cleaner.py` 자동 출력):

1. **별점 분포** — 별점 1~5 분포. 극단(5점 과다)이 제거된 뒤의 실제 만족도
2. **긍정/부정 비율 + 키워드 TOP** — "향 좋·보습·편해요" vs "비침·물빠짐·건조·아쉬워"
3. **토픽 분류** — 성분·효능 / 향 / 사이즈·핏 / 가격 / 배송 / 사용감 별 등장 빈도
4. **의심 리뷰 리스트** — 짧은 5점은 직접 확인

**수동 추가 분석 (도구 밖)**: AI 요약리뷰의 긍정/부정 태그 %와 교차 확인, 리뷰에서 체형·키·피부타입 언급 수동 수집.

---

## 4단계: 인사이트 전환 (불만 → USP)

클렌징 분석 결과를 워크북 차별화로 연결합니다:

| 발견 (클렌징 후) | 전환 예시 |
|------------------|-----------|
| "보습력 아쉬워요" 반복 (아로마티카 62%) | 우리 제품에 보습 성분 강화 + "보습력 검증" USP |
| "비침 심해요" (타이니모 원피스) | 이중원단·안감 처리 → "비침 Zero" 문구 |
| "물빠짐·줄어들어요" (원피스 순위3) | 저온세탁 가공 + 관리법 상세페이지 |
| "팔은 맞는데 몸통만 커 보여요" (타이니모) | 부위별 피팅(셔링·랩) → 사이즈프리 USP |
| "뒷밴딩이라 편해요" 긍정 다수 (퍼플리아) | 편안함을 기본값으로 + 상황별 코디 |

> 결과는 `ai-brand-analysis-results.md`의 "주요 약점(소비자 반응)"과 `competitive-analysis-*.md` 실습 2의 "내 검증 메모"에 반영합니다.

## 실행 도구: review_cleaner.py

```bash
# 1. 리뷰를 텍스트 파일로 수집 (리뷰 1줄 = 1건, 별점 있으면 "5점, 내용")
# 예: 리뷰.txt
#   5점, 거품 풍성하고 향 좋아요 재구매합니다
#   4점, 향은 좋은데 보습이 아쉬워요

# 2. 클렌징·분석 실행
python3 scripts/review_cleaner.py 리뷰.txt

# 옵션
python3 scripts/review_cleaner.py 리뷰.txt --min-len 15   # 최소 길이 조정
python3 scripts/review_cleaner.py 리뷰.txt --out result   # 결과 파일명 지정
```

**출력물**
- `리뷰_cleaned.txt` — 클렌징된 유효 리뷰 (재사용 가능)
- 분석 보고서 — 별점 분포 · 긍정/부정 비율 · 키워드 TOP · 토픽 분포 · 의심 리뷰 리스트
