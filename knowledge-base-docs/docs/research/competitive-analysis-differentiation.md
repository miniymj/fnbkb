## 0. 데이터 용도의 이해

올바른 데이터를 올바른 목적에 활용하는 것이 경쟁사 분석의 핵심입니다.

| 데이터 종류 | 무엇을 알려주는가 | 어떤 판단에 쓰는가 |
|-------------|-------------------|-------------------|
| **검색 데이터** (네이버 데이터랩, 구글 트렌드) | 광고 규모, 검색어 트렌드(시장 수요·관심), 쇼핑 트렌드(전환 가망) | 시장 진입 타이밍, 키워드 선정, 수요 예측 |
| **소셜 미디어** (인스타그램, 틱톡 등) | 수요·관심 규모, 회자성(버즈량), 감성 트렌드 | 해시태그, 댓글을 통한 트렌드 파악, 타깃 고객 관심사 확인 |
| **AI (SQREEM)** | 축적된 공신력, PR·미디어 노출, 브랜드 이미지 | 소비자가 노출되는 맥락, 브랜드 포지셔닝, 강약점 |

## 2. 브랜드별 소비자 인식 — 썸트렌드 & 리뷰 데이터

소비자가 브랜드에 대해 실제로 어떻게 이야기하는지를 데이터로 파악합니다. 기업이 자체 발표하는 이미지가 아닌, 시장의 **'진짜 목소리'**를 추출하는 것이 핵심입니다.

### 실습: 클로드인크롬 브랜드 분석

> 분석 대상: **동구밭** (샴푸바·바디바 카테고리 선두, 친환경 USP 원조)

| 분석 항목 | AI 분석 결과 요약 | 내 검증 메모 |
|-----------|-------------------|--------------|
| 핵심 고객군 | 친환경·제로웨이스트 가치소비 20~45세 여성, 가족 단위 구매자, 민감피부·알레르기 걱정 보유자 | 잠재고객 페르소나: 건강웰빙 34% · 가족 20% · 친환경 10% |
| 가격 포지셔닝 | 합리적(가성비) — 비건·천연 제품군 대비 낮은 단일 가격대 | 가격대 관심 낮음(5.2%) → 가격 민감도 낮음, 원가 여지 큼 |
| 주요 강점 (USP + 소비자 반응) | 국내 천연 성분 + 제로웨이스트 패키징 + 동물실험 NO → "업사이클링 포장재(73.8%)" "동물성 원료 배제(70.6%)" "친환경 브랜드 선호(70.3%)" | 브랜드 신뢰도 최상위(12.0%) — 신뢰가 핵심 자산 |
| 주요 약점 (소비자 반응) | 피부 타입·사용 빈도 대응 약함 (research: 피부타입 "관련 없음", 사용 빈도 "거의 없음") → 민감피부별 세분화 니즈 미충족 | 민감피부 소비자는 성분 비교 후 이탈 — 여기가 진입 틈새 |
| 차별화 요소 (USP + 소비자 반응) | 친환경·가치소비 선도 이미지, Leaping Bunny 등 인증 | "Leaping bunny 로고(32.4%)" 관심 → 인증 가시화 전략 벤치마크 |

## 5. 데이터 종합 — 경쟁사 BMC 역설계

비즈니스 모델 캔버스(BMC)는 기업의 전체 비즈니스 구조를 9개 블록으로 요약하는 프레임워크입니다. 지금까지 수집한 데이터로 경쟁사의 BMC를 역으로 추정할 수 있습니다.

| BMC 블록 | 대응 데이터 소스 |
|----------|-----------------|
| **고객 세그먼트 (CS)** | 리뷰 작성자 프로필, 소셜 팔로워 특성, 썸트렌드 연령대 |
| **가치 제안 (VP)** | 리뷰 긍정 키워드, 브랜드 슬로건, 클로드인크롬 분석 결과 |
| **채널 (CH)** | 멀티채널 경쟁사 리스트업 결과 |
| **고객 관계 (CR)** | 리뷰 응답 패턴, SNS 운영 방식, 멤버십 구조 |
| **수익원 (RS)** | 가격 정책, 번들/구독 구성, 네이버쇼핑 상품 구조 |
| **핵심 자원 (KR)** | AI 분석, 유튜브 콘텐츠, 특허·인증 언급 |
| **핵심 활동 (KA)** | 노트북LM 영상 분석, 소셜 콘텐츠 빈도 |
| **핵심 파트너 (KP)** | 협찬 언급, 유통채널, 제조사 공개 여부 |
| **비용 구조 (CS)** | 광고비 추정(데이터랩), 가격 마진 분석 |

### 실습: 경쟁사 BMC 역설계 워크시트

> 역설계 대상: **동구밭** (추정값 기반 — 데이터 근거는 OneInsight 잠재고객 분석 토픽)

| BMC 블록 | 내용 (추정) | 데이터 근거 |
|----------|--------------|-------------|
| 고객 세그먼트 (CS) | 친환경·가치소비 25~45세 여성, 가족 단위 구매자, 제로웨이스트/비건 성향 | 페르소나 분포(건강웰빙 34%·가족 20%·친환경 10%), "온 가족 다 사용할 수 있어요(38.6%)" |
| 가치 제안 (VP) | 국내산 천연 성분 바디바 + 제로웨이스트 패키징 + 온 가족 안심 사용 | "업사이클링 포장재(73.8%)" "동물성 원료 배제(70.6%)" "아이에게 안전한 제품(44.9%)" |
| 채널 (CH) | 네이버 스마트스토어·쿠팡·위메프 + 오프라인 유기농/친환경 매장 | "위메프 오 구매(37.4%)" 토픽, 구매 경로 관심 상위 |
| 고객 관계 (CR) | 리뷰/후기 기반 신뢰, 친환경 커뮤니티 소통 | "추천 및 후기(6.8%)" "브랜드 신뢰도(12.0%)" |
| 수익원 (RS) | 단품 판매 + 다품 구성 세트 + 선물용 패키지 | "선물용으로 정말 좋아요(44.4%)" "백화점 브랜드 가격(66.9%)" |
| 핵심 자원 (KR) | 국내 제조 역량, 친환경 인증(Leaping Bunny), 브랜드 스토리 | "Leaping bunny 로고(32.4%)" "패키지 디자인(5.1%)" |
| 핵심 활동 (KA) | 친환경 캠페인·제로웨이스트 콘텐츠, 시즌 신제품 출시 | 유튜브·메타 친환경/뷰티 콘텐츠 참여도(2.2x) |
| 핵심 파트너 (KP) | 원료 공급사, 제조 위탁(OEM), 유기농 유통 파트너 | "고급 제품 선호자(34.9%)" 세그먼트 유통 연동 |
| 비용 구조 (C$) | 원료·제조비, 인증·패키징비, 유통 수수료, 친환경 캠페인 마케팅비 | 가격 요인 낮음(5.2%) → 원가 상방 여지 큼 |

# PART 2. 차별화 포인트

카테고리 선두 브랜드 BMC - 경쟁 브랜드 & SQREEM 데이터의 활용

경쟁사 분석을 넘어, 레드오션 속에서 **'청정구역'**을 찾고 나만의 차별화 포인트를 구체화합니다.

## 1. 데이터 읽는 법 — 내림차순으로 쪼개기

| 구간 | 키워드 범위 | 특성 | 활용 방안 |
|------|------------|------|-----------|
| 🔴 **상위권** (TOP 20%) | 1위 ~ _위 | 메인 스트림 — 명백하게 규모감 있는 키워드, 핵심 견인 항목. 경쟁이 치열할 수 있음 | 큰 맥락을 이해하는데 활용 |
| 🟡 **중위권** (MIDDLE 30-60%) | _위 ~ _위 | 기회의 구간 — 관심은 있지만 아직 경쟁이 치열하지 않은 키워드. 진입 타이밍이 좋은 구간 | 집중 분석 필요 |
| 🟢 **하위권** (BOTTOM 40%) | _위 ~ _위 | 니치 & 잠재 수요 — 아직 시장이 형성되지 않았거나 새롭게 부상하는 키워드. 선점 가능성 높은 블루오션 후보 | 상위 키워드와 믹스해 잠재력 있는 니치 확보 |

## 2. 레드오션 속 청정구역 찾기

선두 브랜드들이 공통으로 집중하는 영역이 **레드오션**입니다. 역설적으로, 이 공통점을 파악하면 아무도 다루지 않는 **'청정구역'**이 드러납니다.

### 실습: 레드오션/청정구역 매핑

> 브랜드 A = 동구밭, B = 아로마티카, C = 더바디샵

| BMC 블록 | 브랜드 A (동구밭) | 브랜드 B (아로마티카) | 브랜드 C (더바디샵) | 판정 |
|----------|----------|----------|----------|------|
| 가치 제안 (VP) | 천연 성분 + 제로웨이스트 | 고기능 천연 성분(브라질너트 등) | 동물실험 NO + 에센셜 오일 | 🔴 모두 "천연·윤리" VP 경쟁 |
| 고객 세그먼트 (CS) | 가치소비 20~40대 여성 | 민감피부 30~40대 여성 | 선물·백화점 30~50대 | 🔴 모두 20~50대 여성 |
| 채널 (CH) | 스마트스토어 + 오프라인 | 자사몰 + 올리브영 | 글로벌 오프라인 + 몰 | 🔴 모두 멀티채널 유통 |
| 고객 관계 (CR) | 친환경 커뮤니티 | 성분 분석 콘텐츠 | 멤버십 + 매장 경험 | 🔴 모두 콘텐츠·커뮤니티형 |
| 수익원 (RS) | 단품 + 세트 | 단품 + 스타터 키트 | 단품 + 번들 | 🟢 민감피부 맞춤 정기구독·루틴을 파는 곳 없음 |

> **🎯 발견된 청정구역**: "민감피부·알레르기 성분 배제를 정면으로 내건 **성분표 큐레이션** + **맞춤 루틴 정기구독**" — 브랜드 공백 분석에서 성분 선호(47.6%)·알레르기 여부(46.1%)가 가장 비포화. 40대 디자이너 민감피부 페르소나와 정확히 일치.

- 🔴 = 레드오션 (3곳 이상 동일)
- 🟢 = 청정구역 (아무도 다루지 않음)

## 3. 쓰임 형상화 — Time / Place / Space / Passion Points

발견한 청정구역을 추상적 개념으로 두지 말고, 실제 소비자의 삶 속 장면으로 구체화합니다. 4개의 축으로 형상화하면 제품 기획, GPT 이미지 스토리보드, 콘텐츠 제작의 소스가 됩니다.

| 축 | 질문 | 예시 |
|----|------|------|
| ⏰ **Time** | 소비자가 이 제품을 사용하는 구체적인 시간대는 언제인가? | 출근 전 5분 루틴, 퇴근 후 릴렉스 타임 |
| 📍 **Place** | 어디에서 사용하거나 구매하는가? | 회사 화장실, 헬스장 락커룸, 카페 테이블 위 |
| 🏠 **Space** | 어떤 공간 감성·무드와 어울리는가? | 미니멀 화이트 욕실, 그린 인테리어 홈오피스 |
| ❤️ **Passion Points** | 소비자가 이 제품을 통해 실현하고 싶은 가치나 라이프스타일은 무엇인가? | 지속가능한 소비, 자기관리 루틴 |

### 실습: Time/Place/Space/Passion Points 형상화

> 실습 대상: **민감피부 올인원 바디바**

| 축 | 한 문장 기술 |
|----|-------------|
| ⏰ Time | "소비자는 퇴근 후 저녁 샤워 시간에 하루의 피로를 씻어내며 두피와 바디를 동시에 케어하는 셀프 루틴으로 이 제품을 사용한다." |
| 📍 Place | "이 제품은 집 욕실 선반, 헬스장 락커룸, 여행용 세면 키트에서 사용된다." |
| 🏠 Space | "미니멀 화이트·그린 인테리어의 자연 친화적 욕실 무드와 어울린다." |
| ❤️ Passion Points | "소비자는 이 제품을 통해 민감피부도 안심하는 지속가능한 소비와 '내 몸은 내가 관리한다'는 자기관리 루틴을 실현한다." |

# PART 3. 상품 구성 설계

## 2. 상품구성 벤치마킹 — 선두 경쟁사 방식

## 3. 내 상품구성 설계 — 5가지 방식

단순히 상품 하나를 파는 것을 넘어, 고객의 구매 패턴에 맞춘 상품구성 전략을 설계합니다.

| 방식 | 설명 | 예시 |
|------|------|------|
| **정기구매** | 베이직 아이템, 소모성 제품에 최적. 구독 할인으로 고객 유지율 상승 | 매달 자동 배송 + 10% 할인 |
| **묶음판매** | 배송비 인사이트 활용. 단품보다 세트가 객단가를 높이고 배송비 부담을 줄여줌 | 3개 세트 = 무료배송 |
| **업셀 (옵션 믹스)** | 같은 카테고리 내 프리미엄 버전 제안 | 기본 → 프리미엄 향·용량 업그레이드 |
| **크로스셀 (이종 믹스)** | 연관 카테고리 상품과 큐레이션 세트 구성 | 스킨케어 + 마사지 도구 뷰티 루틴 세트 |
| **예약판매 (와디즈 방식)** | 출시 전 수요 검증과 초기 자금 확보. 얼리버드 가격으로 충성 고객 확보. 재고 리스크 최소화 | 얼리버드가, 목표 수량 |

### 실습: 내 상품구성 설계

| 적용 방식 | 선택 (✅) | 구체적 구성안 | 예상 효과 |
|-----------|----------|----------------|-----------|
| ① 정기구매 | ✅ | 할인율: 10%, 주기: 2개월 (바 1개 소진 기준) | 재구매율·LTV 상승, 재고 안정화 |
| ② 묶음판매 | ✅ | 두피바 + 바디바 + 여행용 미니바 **3종 세트** | 객단가 상승, 무료배송 기준 달성 |
| ③ 업셀 | ✅ | 기본: 순한 허브 바 / 프리미엄: 시어버터·향 강화 라인 | 객단가 상승, 프리미엄 매출 20~30% 목표 |
| ④ 크로스셀 | ✅ | 샴푸바 + 대나무 거품망 + 바디로션 "민감피부 셀프케어 루틴 세트" | 연관 구매 유도, 단품 이탈 방지 |
| ⑤ 예약판매 | □ | (기획) 얼리버드 20% 할인, 목표 수량 100개 | 출시 전 수요 검증 + 초기 자금 확보 |

> **MD 라인업 연결**: ① 미끼상품 = 여행용 미니바 · ② 메인상품 = 순한 허브 바디바 · ③ 프리미엄 = 시어버터 향 강화 라인 · ④ 세트/번들 = 3종 루틴 세트

## MD 라인업 설계 구조

상품 하나가 아니라 **흐름**을 팝니다. 각 단계는 고객의 신뢰를 쌓으며 다음 단계로 이어집니다.

```
① 미끼상품 (Entry)
      ↓
② 메인상품 (Core)
      ↓
③ 프리미엄 (Premium)
      ↓
④ 세트/번들 (Bundle)
```

| 단계 | 설명 | 예시 |
|------|------|------|
| **① 미끼상품** | 가격 부담 없이 구매 결정 가능한 저관여 상품. 브랜드 첫 경험을 좋게 만드는 것이 목적 | 소용량·단품·입문형 |
| **② 메인상품** | 수익의 핵심. 가장 많이 팔리고 리뷰가 쌓이는 대표 상품. 차별화 문구와 포지셔닝을 가장 강하게 적용 | |
| **③ 프리미엄** | 객단가를 높이는 업셀링 상품. 소재·기능·한정판 등 프리미엄 요소 부각. 전체 매출의 20~30% 목표 | |
| **④ 세트/번들** | 기존 상품을 조합해 재구매율과 객단가를 동시에 높임 | |
