# 중저가 · 하꼬 브랜드 경쟁사 분석

> 신규 셀러(양민정)의 **실제 경쟁자**는 대형 브랜드가 아니라, 같은 가격대·같은 온라인 채널에서 싸우는 중소 브랜드와 쇼핑몰입니다.
> 이 문서는 각 카테고리에서 **하꼬(소규모)·중저가 경쟁자**를 별도 타게팅해 가격·구성·강약점·공략 포인트를 분석합니다.
> 조사 방법: 웹 검색 직접 재현 + 쇼핑몰 노출 정보 + 프로젝트 데이터 | 작성일: 2026-08-03

---

## 왜 하꼬/중저가가 진짜 경쟁자인가

| 구분 | 대형 브랜드 | **중저가 · 하꼬 브랜드** |
|------|-------------|--------------------------|
| 타겟 고객 | 프리미엄·백화점층 | **가성비·온라인 우선 고객 (우리 타겟과 동일)** |
| 가격대 | 10만원대 이상 | **1~5만원대 (우리 가격대와 겹침)** |
| 채널 | 백화점·브랜드몰 | **네이버 스마트스토어·쿠팡·지그재그·에이블리 (우리 채널)** |
| 경쟁 포인트 | 브랜드 가치 | **가격·상세페이지·리뷰·키워드 노출** |
| 분석 목적 | 벤치마크 (참고) | **직접 공략 대상 (이겨야 할 상대)** |

> 대형 브랜드는 "참고"(벤치마크)이지만, 하꼬·중저가 브랜드는 **"공략"**(이겨야 할 상대)입니다. SEO 키워드, 광고 입찰가, 상세페이지 경쟁이 모두 하꼬와 붙습니다.

### 하꼬 심층 분석: **비누옹달샘**

| 항목 | 내용 | 우리 브랜드 대비 |
|------|------|------------------|
| 제품 | 하수오(볼륨)·어성초·모링가·블랙빈(검은콩) 4종 | 성분군이 다름 |
| 가격 | 8,800~9,400원 — **우리(12,000원)와 근접** | 가격 경쟁 심화 |
| 특징 | 100% 천연, 수제 CP, **6주 숙성**, 설페이트/실리콘/파라벤 프리 | "숙성" 스토리는 동일 강조 가능 |
| 구성 | **어성초 5개 묶음 41,670원** (묶음판매 이미 함) | 묶음 단가로 맞대응 |
| 채널 | 공식몰 + 쿠팡/옥션/G마켓 멀티 | 쿠팡 입점 필수 확인 |
| 약점 | 브랜드 스토리·디자인 약함, 성분 검증·인증 정보 부족 | **성분표 큐레이션·인증으로 차별** |

### 공략 포인트 (샴푸바)

1. **가격 단독 대응 금지** — 비누옹달샘과 가격전은 불리. 대신 **"검증된 성분표 + 인증 + 디자인"**으로 12,000원의 정당성 확보
2. **묶음 단가 맞대응** — 3종 세트(두피+바디+미니)로 1개당 실질 단가를 낮춰 체감 가성비 확보
3. **하꼬의 공통 약점**(성분·인증 정보 부족)을 정면 공략 — 화장품 성분 규제(알레르기 유발성분 표시) 이슈가 시장 신뢰 기반

2. **지그재그·에이블리 입점** — 리리앤코가 쓰는 채널에서 가시성 확보
3. **상세페이지·후기 차별** — 실측 사이즈 차트 + 체형별 후기 (리리앤코·타이니모 대비 신뢰 신호)

### 하꼬 심층 분석: **퍼플리아 (스커트 전문)**

| 항목 | 내용 | 우리 브랜드 대비 |

| 가격 | 27,900~42,800원 — **우리(3~5만)와 유사** | 균등 |
| 특징 | **뒷밴딩 편안함 + 소재 명시**(비스코스 100%·리오셀 100%) | 소재 정보성은 동일 벤치마크 |

1. **상황 × 체형 큐레이션** — 퍼플리아가 "스타일"로 파는 걸, 우리는 "면접·하객·데이트 상황 + 키별 기장"으로 차별
2. **실구매 니치 선점** — 테니스스커트(CTR 4.42%)·플리츠스커트(월검색 18,170) 등 하꼬가 안 쓰는 **전환 키워드 SEO**
3. **"치마+스커트" 검색어 통합** — 제목·상품명에 양쪽 키워드 모두 노출 (검색 분산 대응)
