# 실습 4. 유튜브 리뷰 영상 공통 반응 분석 (샴푸바 · 바디바)

> **카테고리**: 샴푸바 / 바디바 (고체형 친환경 헤어·바디 케어)
> **목적**: 카테고리 관련 유튜브 리뷰 영상 3종의 공통 긍정·부정 반응을 도출해 **소비자 니즈와 페인포인트를 한 문장으로 압축**
> **실행 방식**: NotebookLM(외부 서비스) 직접 호출 불가 → **동일한 작업(다중 소스 통합 분석 → 공통 키워드·감성 도출 → 한 줄 요약)을 에이전트가 직접 수행**. 실제 NotebookLM에 올릴 소스 링크와 질문 템플릿도 함께 제공해 사용자가 재실행 가능.
> **작성일**: 2026-08-04

:::note NotebookLM 대체 안내
NotebookLM은 Google의 클라우드 서비스로 외부에서 API 호출할 수 없습니다. 본 문서는 NotebookLM이 수행하는 핵심 작업(① 다중 소스 업로드 ② 질문 기반 인사이트 도출 ③ 요약)을 **에이전트가 웹 검색·트랜스크립트 분석으로 직접 수행**한 결과입니다. 같은 방법론을 실제 NotebookLM에 적용할 수 있도록 **Step별 소스·질문 템플릿**을 부록으로 제공합니다.
:::

## Step 2. 질문하기 — "공통 긍정 반응과 부정 반응은?"

> NotebookLM 질문: **"이 영상들에서 공통으로 언급되는 긍정 반응과 부정 반응은 무엇인가요?"**

3종 영상 + 교차 검증 소스에서 **반복 등장하는 키워드와 감성**을 추출했습니다. 키워드 옆 괄호는 등장한 소스 수(신뢰도 지표).

## 인사이트 → 우리 브랜드(BodyBar) 적용

이 공통 반응은 우리 차별화 전략과 정확히 맞닿아 있습니다. 부정 반응 5종을 **모두 솔루션으로 전환**할 수 있는 것이 우리의 기회입니다.

| 소비자 페인포인트 | 우리 솔루션 | 제품/구성 |
|------|------|------|
| 떡짐·적응 기간 | 거품망 번들 + 적응 가이드 콘텐츠 | Entry 미니 + 거품망 세트 |
| 모발 뻣뻣함 | **트리트먼트/컨디셔너바 크로스셀** (톤28 벤치마크) | "민감피부 루틴 세트" (샴푸바+컨디셔너바+거품망) |
| 거품 약함 | 거품망 + "충분히 물 적시기" 사용법 콘텐츠 | 보관/사용 가이드 카드 동봉 |
| 물 무름·빠른 소모 | **전용 드레인트레이/스탠드** 사은품 + 건조 보관 가이드 | Bundle 부가품 |
| 세정력 강한 타입 | **민감피부 전용 순한 라인** (알레르기 프리 포지셔닝) | Core 순한 허브 / Premium 시어버터 2택 |

> 핵심: 경쟁사(톤28·동구밭·비누옹달샘)도 같은 페인포인트를 안고 있지만 **솔루션(거품망·보관함·트리트먼트바 번들)을 상품 구성에 녹인 곳은 드묾** → 우리의 **MD 라인업 5가지 방식(정기구독·묶음·업셀·크로스셀·예약)**이 정확히 이 격차를 공략.
