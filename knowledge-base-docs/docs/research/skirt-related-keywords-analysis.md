# 치마(스커트) 연관어 트렌드 분석

> 출처: 네이버 데이터랩 연관검색어 분석
> 분석 기간: 2025.07.30 ~ 2026.07.29 (12개월)
> 분석 일시: 2026-08-03

---

## 경영진 요약

스커트 카테고리에서 **길이(짧은/긴)**가 소비자 결정의 1순위 요소이며, **디자인**이 유일한 상승 추세 키워드로 확인되었습니다. 착용감 관련 부정 지표("갑갑하다")가 지속적으로 나타나며, 코디 수요(청바지, 블라우스)가 안정적인 것으로 확인되었습니다.

---

## 1. 검색어 부정 지표 분석

### 주요 부정 지표 (2025.07.30~2026.07.29)

| 키워드 | 크기 | 의미 | 개선 방안 |
|--------|------|------|-----------|
| **갑갑하다** | 중간 | 착용감 불편 (지속적 문제) | 신축성 있는 소재 사용, 핏 개선 |
| **조제감** | 중간 | 인위적인 느낌 | 자연스러운 디자인 디테일 강화 |
| **메렉젝** | 큼 | 이상 현상 (브랜드/제품 이슈 가능성) | 추가 조사 필요 |
| **슬림** | 중간 | 핏 관련 불만 (너무 타이트) | 사이즈 inclusivity 강화 |

### 주요 긍정 지표

- **잘어울리다** (가장 큼), **좋다**, **인기**, **장점**
- **세련된 느낌**, **신상**

---

## 2. 연관어 트렌드 분석

### 가장 빈도 높은 연관어

| 연관어 | 특징 | 트렌드 |
|--------|------|--------|
| **짧은/긴** | 가장 큰 노드 | 안정적 (길이 = 1순위 구매 요인) |
| **디자인** | 상승 추세 (오렌지색) | **유일한 상승 키워드** |
| **패션** | 안정적 (녹색) | 시장 성숙도 반영 |
| **청바지** | 안정적 (녹색) | 코디 수요 |
| **블라우스** | 안정적 (녹색) | 코디 수요 |

### 트렌드 패턴

- **"디자인"**은 유일한 상승 추세 키워드 → 소비자가 디자인 요소에 점점 더 관심
- 대부분의 연관어는 안정적(녹색) → 시장 성숙도를 나타냄
- 하락 추세(노란색)의 두드러진 키워드 없음

---

## 3. 종합 인사이트

### 핵심 발견

1. **길이와 디자인이 주요 구매 결정 요인**
   - 짧은/긴 스커트에 대한 관심이 동등
   - 디자인 관심이 상승 중 (유일한 상승 추세)

2. **착용감(Comfort)이 지속적인 문제**
   - "갑갑하다"는 시스템적 문제 → 개선 필요
   - 신축성 있는 소재, 핏 개선, 조절식 웨이스트밴드 도입

3. **코디 수요가 안정적**
   - 청바지, 블라우스와의 매칭이 중요한 판매 요인
   - 평균 주문 금액 상향 기회

---

## 4. 실행 권장사항

| 순위 | 액션 | 기대 효과 |
|------|------|----------|
| 1 | 디자인 강화 | 상승하는 "디자인" 트렌드 포획 |
| 2 | 착용감 개선 | "갑갑하다" 부정 지표 해소 |
| 3 | 길이별 타겟 마케팅 | 짧은/긴 스커트별 개별 캠페인 |
| 4 | 코디 콘텐츠 강화 | 청바지/블라우스 매칭 아이디어 제공 |
