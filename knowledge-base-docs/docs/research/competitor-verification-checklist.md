## 4. 채널별 확인 방법

1. **네이버쇼핑**: 검색 → 상품 클릭 → 가격·별점·리뷰 수·배송비 캡처
2. **공식몰**: 자사몰 가격·세트 구성·배송 조건 캡처
3. **올리브영**: 상품 페이지 (가격·AI 요약 리뷰)
4. **쿠팡**: 브라우저 차단 가능 → 수동 확인
5. **지그재그/에이블리**: SNS 몰 가격대 확인
6. 캡처 저장: `{아이템}/경쟁사 실측/{YYYY-MM-DD}/{브랜드}_{채널}.png`
