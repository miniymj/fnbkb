- [ ] **화장품책임판매업 신고** (화장품법 제3조) — ODM/OEM 위탁생산 시 우리는 "책임판매업자"로 지방식약처에 신고. **판매 시작 전 필수**
- [ ] 기능성화장품 여부 확인 (탈모·두피·진정 등 기능 표현 시 식약처 심사·인증)
- [ ] 화장품 표시: 제품명 / 전성분 / 용량·중량 / 사용기한(또는 개봉 후 사용기간) / 책임판매업자·제조판매업자 / 신고번호 / 소비자상담실 전화
- [ ] 화장품책임판매업 신고번호를 제품 용기에 표시
- [ ] 전성분 표기법 준수 (한글 성분명·INCI 규정)

## 4. 표시·광고 표현 점검 (가장 위험한 영역)

> 화장품 효능·효과 및 안전성 관련 표현은 「화장품 표시·광고 실증에 관한 규정」(식약처 고시) 및 표시광고법 대상. 실증자료 없이 게재 시 과태료·행정처분 가능.

| 우리 문서에 있는 표현 | 리스크 | 조치 |
|---|---|---|
| "알레르기 프리" | 성분 불포함 주장 → 실증 요구 가능성 | 실증자료 확보 or "알레르기 유발 주의성분 미사용"으로 완화 |
| "두피 진정" / "탈모 감소" / "딥 클렌징" | 효능·효과 표현 → 실증·심사 | 표시·광고 실증 규정 확인 후 재작성 |
| "비건" / "동물실험 안함" | 인증 근거 필요 | Vegan Society 등 인증 취득 또는 근거자료 |
| "제로웨이스트" / "친환경" | 환경성 표시·광고 가이드라인(환경부) 적용 | 근거·정량 표현으로 전환 |
| "눈에 들어가도 찡하지 않음" / "삼켜도 안전" | 안전 보증형 표현 — 소비자 오인·안전사고 책임 위험 | **삭제 권장** (현재 md-lineup-bodybar에 존재) |
| "온 가족 안심" | 무조건적·과장 표현 주의 | 근거 기반(임상·인증)으로 재작성 |
