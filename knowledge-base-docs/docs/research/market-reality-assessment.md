## 4. "청정구역" 논리의 강점과 한계

- **강점**: 알레르기 프리 선호 46.09%·성분 선호 47.61% 등 니치 지표는 비포화 → 포지셔닝은 명확
- **한계**:
  1. 비포화 = "수요가 적어 비어있을" 가능성도 동일하게 설명
  2. YoY 하락 국면의 니치이므로 규모 자체가 작을 수 있음
  3. "검색어 부재 = 선점 기회"라는 추론은 "검색어 부재 = 수요 부재"일 수도 있음
- **검증 과제**: 니치 키워드의 절대 검색량·광고 노출량·경쟁사 유무를 실데이터(SA 예비조사)로 재확인

## 5. 데이터 수집 한계 (신뢰성)

- `data/user_downloaded/datalab_collection_log.json`: results가 **빈 배열** — 자동수집 미완료, 실데이터는 수동 다운로드분에 의존
- **미완성월 이슈**: 당월 데이터는 수집 시점에 따라 1~2자리로 왜곡 — 반드시 완성월 기준 사용
- 쿠팡: 브라우저 정책상 접속 차단 → 채널 데이터 공백
- `trend_analysis_summary.json`의 growth_rate 공식이 미문서화 → 재현 불가 상태
- 경쟁사 가격·리뷰 수 상당수 "추정" → `competitor-verification-checklist`로 실측 전환 필요

## 6. 진입 타이밍 판단

| 관점 | 판단 |
|---|---|
| 시장 성장 | ❌ 성장기 아님 — 하락·성숙 국면 |
| 니치 유효성 | ⚠️ 미검증 — 실데이터 확인 필요 |
| 경쟁 진입장벽 | ✅ 낮음 (하꼬 수준, 신뢰로 차별 가능) |
| 리스크 완화 수단 | ✅ 소량 초도(500개)·예약판매·미니 2,900원 프로모션 → 투자 최소화 |

**결론**: 하락국면 시장이므로 **"작게 시작 → 니치 검증 → 증산"** 순서가 필수입니다. 대규모 초도 물량·광고비 투입은 부적절하며, 예약판매·체험단으로 수요를 먼저 검증하십시오.

## 7. 데이터 사용 원칙

1. "최신 검색량"은 항상 **완성월(직전 월)** 값 사용 — 미완성월(당월) 값 사용 금지
2. YoY 계산은 기준 기간을 명시하고 재현 가능하게 기록
3. 검색트렌드(일반 검색)와 쇼핑인사이트(쇼핑 검색·클릭)는 **서로 다른 지표**임을 구분 표기
4. 수치 인용 시 원본 파일 경로 + 계산식 병기
