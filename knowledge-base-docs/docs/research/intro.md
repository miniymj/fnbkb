# 시장조사

> 성공적인 창업을 위한 체계적인 시장조사 방법

## 시장조사의 중요성

시장조사는 창업 아이템 선정부터 성공적인 런칭까지 필수적인 과정입니다.

## 조사 프로세스

```
아이템 선정 → 키워드 분석 → 경쟁사 분석 → 타겟 고객 파악 → 시장 규모 파악
```

## 주요 도구

- **네이버 데이터랩**: 검색량, 연관검색어, 클릭률 분석
- **썸트렌드**: 소셜 미디어 반응, 긍정/부정 분석
- **네이버 쇼핑**: 경쟁사 상품, 가격대 분석
