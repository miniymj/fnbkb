# 시장조사 실행 계획

> 3개 아이템(원피스, 치마/스커트, 샴푸바)에 대한 체계적 시장조사

---

## 📅 전체 일정

| Week | 작업 | 대상 | 산출물 |
|:---:|:---|:---|:---|
| 1 | 네이버 API 인증 발급 | - | Client ID, Secret |
| 1 | 연관검색어 수집 | 전체 | xlsx 파일 |
| 1 | 10년 트렌드 조회 | 전체 | 차트, JSON |
| 2 | 소셜 언급 분석 | 전체 | 보고서 |
| 2 | 리뷰 수집 및 분석 | 전체 | xlsx 파일 |
| 2 | 업종 트렌드 분석 | 전체 | 보고서 |
| 3 | 가격비교 크롤링 | 전체 | CSV 파일 |
| 3 | 경쟁사 분석 | 전체 | 보고서 |
| 4 | 종합 분석 | 전체 | 최종 보고서 |

---

## 🎯 Week 1: 기본 데이터 수집

### 1. 네이버 API 인증 발급

**작업**:
- [ ] 네이버 개발자센터 가입
- [ ] 애플리케이션 등록
- [ ] 검색트렌드 API 권한 신청
- [ ] Client ID, Secret `.env`에 저장

**산출물**: `.env` 파일
```
NAVER_CLIENT_ID=your_client_id
NAVER_CLIENT_SECRET=your_client_secret
```

---

### 2. 연관검색어 수집

**검색어 리스트**:
| 카테고리 | 검색어 |
|:---|:---|
| 원피스 | 원피스, 여름원피스, 빅사이즈원피스 |
| 치마 | 치마, 롱치마, 미니치마, 플레어치마 |
| 스커트 | 스커트, 롱스커트, 미니스커트 |
| 샴푸바 | 샴푸바, 바디샴푸, 고체샴푸, 클렌징바 |

**작업**:
- [ ] 네이버 데이터랩 - 쇼핑인사이트 접속
- [ ] 각 검색어별 연관검색어 TOP 100 다운로드
- [ ] 엑셀 파일로 정리

**산출물**: `1. 키워드 데이터/{아이템} - 연관키워드 {날짜}.xlsx`

---

### 3. 10년 트렌드 조회

**작업**:
- [ ] 네이버 검색트렌드 API로 10년 데이터 조회
- [ ] 각 아이템별 월별 검색량 추출
- [ ] 계절성 및 성장추이 분석

**산출물**:
- `1. 키워드 데이터/{아이템} - 10년 트렌드 {날짜}.json`
- `1. 키워드 데이터/{아이템} - 10년 트렌드 차트.png`

---

## 🎯 Week 2: 소셜 및 리뷰 분석

### 4. 소셜 언급 분석

**작업**:
- [ ] 네이버 뉴스/블로그 API로 게시물 수 조회
- [ ] 인스타그램 해시태그 수동 수집
- [ ] 긍정/부정 키워드 추출

**산출물**: `2. 리뷰 분석/{아이템} - 소셜 언급 분석 {날짜}.xlsx`

---

### 5. 리뷰 수집

**작업**:
- [ ] 네이버 쇼핑 상위 10개 상품 선정
- [ ] 각 상품 리뷰 100개씩 수집
- [ ] 광고성 리뷰 필터링
- [ ] 키워드 빈도 분석

**광고성 리뷰 필터링 기준**:
- 리뷰 내용 20자 미만
- 동일 문구 반복
- 상품 관련 없는 내용

**산출물**:
- `2. 리뷰 분석/{아이템}순위1- 리뷰 원본 {날짜}.xlsx`
- `2. 리뷰 분석/{아이템} - 리뷰 키워드 분석 {날짜}.xlsx`

---

## 🎯 Week 3: 가격 및 경쟁사 분석

### 6. 가격비교 크롤링

**대상 사이트**:
- 네이버 쇼핑
- 다나와 (가격비교)
- 쿠팡
- 11번가

**작업**:
- [ ] 크롤링 스크립트 개발
- [ ] 각 사이트별 가격 수집
- [ ] 최저가/평균가/최고가 분석

**산출물**: `5. 경쟁사 상품 분석/{아이템} - 가격비교 {날짜}.csv`

---

### 7. 경쟁사 분석

**작업**:
- [ ] 상위 5개 브랜드 선정
- [ ] 브랜드별 매출 규모 조사
- [ ] 차별화 포인트 분석

**산출물**: `6. 시장 분석 보고서/{아이템} - 경쟁사 분석.md`

---

## 🎯 Week 4: 종합 분석

### 8. SWOT 분석

**작업**:
- [ ] 각 아이템별 SWOT 분석
- [ ] 시장 매력도 평가
- [ ] 최종 아이템 선정

**산출물**: `6. 시장 분석 보고서/SWOT 분석 및 아이템 선정.md`

## 🔧 필요한 리소스

### 도구
- 네이버 API 계정
- Python 환경 (Selenium, BeautifulSoup, pandas)
- 크롬 브라우저 (크롤링용)

### 데이터 저장소
```
/Volumes/MINIY/중랑/
├── scripts/               # 크롤링 스크립트
├── data/                 # 원본 데이터
├── analysis/             # 분석 결과
└── reports/              # 최종 보고서
```
