## Step 2. 질문하기 — "공통 긍정 반응과 부정 반응은?"

> NotebookLM 질문: **"이 영상들에서 공통으로 언급되는 긍정 반응과 부정 반응은 무엇인가요?"**

3종 본 영상 + 교차 검증 소스에서 **반복 등장하는 키워드와 감성**을 추출했습니다.

### ✅ 공통 긍정 반응 (TOP 5)

| 순위 | 공통 키워드 | 소스 수 | 대표 반응 |
|:---:|------|:---:|------|

| 2 | **다용도 (휴양지·데일리·하객 겸용)** | 5+ | "휴양지부터 데일리, 하객룩까지" (캉캉 숏츠), "수영복 위에 툭 걸쳐도 예쁜 바캉스룩" (맥시 릴스) |
| 3 | **사이즈 inclusivity (55~88 / 5~8)** | 4 | "마른 55부터 77·88 빅사이즈까지 모두 커버" (맥시 릴스), "넉넉하게 5~8 추천" (여름 원피스) |

| 5 | **조절식 디테일 (끈·스트랩·밴딩)** | 3 | "끈 조절 가능" (휴가룩), "밴딩 허리" 선호, 체형별 핏 조절 |

## 인사이트 → 우리 브랜드(휴양지원피스) 적용

이 공통 반응은 우리 청정구역(빅사이즈 × 휴양지 디자인 동시)과 정확히 맞닿아 있습니다. 부정 반응 5종을 **모두 솔루션으로 전환**할 수 있는 것이 우리의 기회입니다.

| 소비자 페인포인트 | 우리 솔루션 | 제품/구성 |
|------|------|------|
| 빅사이즈 퉁명스러운 디자인 | **셔링·랩 체형 커버 디테일** + 디자인 감각 | Core 휴양지원피스 (셔링·랩) |
| 가격대 양극화 (저가 vs 고가) | **HIT 3~5만원 + 프리미엄 7만원 2단** 구성 | Entry 24,000 → Premium 69,000 |
| 소재 퀄리티 편차 | **린넨 70%+레이온 30% 통기성** 프리미엄화 + 소재 가이드 | Core/Premium 린넨·실크 라인 |
| 사이즈 실측 정보 부족 | **44/66/95/120 다체형 모델 룩북** + 실측 차트 | 다체형 룩북 시스템 (최우선 차별화) |
| 여행 특화 디테일 부족 | **사이드 포켓 + UV 차단 소재** 기본화 | 전 라인 포켓·UV 옵션 |

> 핵심: 경쟁사(리리앤코·우리다움·타이니모)도 "빅사이즈 디자인 부족"·"실측 정보 부재" 페인을 안고 있지만 **다체형 모델 룩북으로 사이즈 inclusivity를 시각화한 곳은 전무** → 우리의 **MD 라인업(커버업→휴양지원피스→실크→비치세트)** + **44~120 다체형 룩북**이 정확히 이 격차를 공략.
