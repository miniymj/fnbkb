# 경쟁사 멀티채널 검증 결과

> 실습 1(멀티채널 경쟁사 리스트업)의 직접 검증 결과
> 검증 방법: 웹 검색(구글 스타일 검색) 직접 재현 + 프로젝트 조사 데이터 + AI(Claude) 지식 교차 검증
> 검증 일시: 2026-08-03

---

## 검증 방법 (클로드인크롬 대체 채널 검증 절차)

클로드인크롬/강의용 AI 도구 없이도 채널별 노출 브랜드를 검증하는 방법:

1. **구글 검색**: 검색 엔진에서 `[키워드] 추천` / `[키워드] 브랜드` 검색 → 상위 노출 브랜드 수집
2. **소셜 미디어**: 공식 인스타그램 계정 확인(인증 배지), 해시태그 볼륨, 팔로워·참여율 확인
3. **AI 추천**: AI에게 "OO 카테고리 추천 브랜드" 질의 → AI가 제시하는 브랜드와 그 근거 수집
4. **교차 검증**: 3개 채널 결과를 기존 조사 데이터(OneInsight 잠재고객 분석·전략 보고서)와 대조

---

## 1. 샴푸바 · 바디바 (클렌징 바)

| 채널 | 브랜드 1 | 브랜드 2 | 브랜드 3 | 검증 근거 |
|------|----------|----------|----------|-----------|
| 네이버 검색 | 동구밭 | 아로마티카 | 라운드랩 | OneInsight 경쟁사 분석 + 키워드 데이터 |
| 구글 검색 | 동구밭 | 케세리 | 아로마티카 | "샴푸바 추천" 검색 — 동구밭 최다 언급, 케세리·아로마티카·러쉬 추적 |
| 소셜 미디어 | 아로마티카 | 동구밭 | 케세리 | 아로마티카 공식 계정 7.8만 팔로워·ESG 콘텐츠, 동구밭 인지도 1위 |
| 데이터랩 랭킹 | 아모레퍼시픽 | 라운드랩 | 셀리맥스 | OneInsight 경쟁사 관련성 분석 |
| AI 추천 (Claude) | 동구밭 | 아로마티카 | 러쉬 | 카테고리 선두 2개 + 해외 벤치마크(러쉬) |

**추가 발견**:
- **아로마티카 로즈마리 샴푸바**: 웹 검색에서 "단단한 제형으로 오래 사용" 후기 확인 — 아로마티카 벤치마킹 자료와 일치
- **알레르기 유발성분 표시 이슈**: 동구밭·러쉬·린넨앤키친 일부 제품에서 성분 표시 기준 미준수 지적 검색 확인 → **"성분표 큐레이션" 차별화(우리 브랜드 USP)의 시장 신뢰 기반 강화**
- **린넨앤키친**: "수분가득 약산성 샴푸바" — 약산성·수분 니치를 이미 선점 중인 중소 브랜드로 확인

## 2. 원피스

| 채널 | 브랜드 1 | 브랜드 2 | 브랜드 3 | 검증 근거 |
|------|----------|----------|----------|-----------|
| 네이버 검색 | 써스데이아일랜드 | 케네스레이디 | 지컷 | OneInsight 경쟁사 분석 + 시장진출 전략 보고서 |
| 구글 검색 | 쉬즈미스 | 잇미샤 | 지고트 | "30대 여성 원피스 브랜드 추천" — 모던·비즈니스 캐주얼 3강 |
| 소셜 미디어 | 아뜨랑스 | 오드(ODE) | 조이유 | 원피스 쇼핑몰 추천 검색 — SNS 기반 몰 3개 노출 |
| 데이터랩 랭킹 | 모조에스핀 | 잇미샤 | 온앤온 | OneInsight 경쟁사 관련성 분석 |
| AI 추천 (Claude) | 케네스레이디 | 써스데이아일랜드 | 아뜨랑스 | 시장진출 보고서 경쟁사 5개사 + SNS 채널력(아뜨랑스 92,100) |

**추가 발견**:
- 30대 원피스 구글 검색에서는 **모던·비즈니스 캐주얼 브랜드(쉬즈미스·리스트·지고트·잇미샤)**가 지배 — 오피스룩/하객룩 수요
- 쇼핑몰 검색에서는 **SNS 기반 중소몰(아뜨랑스·오드·리리앤코·조이유)**이 상위 — 파편화 시장 확인
- → "사이즈프리 × 휴양지원피스" 니치(시장진출 보고서 1순위)는 기존 브랜드 어디에도 없음 → **청정구역 재확인**

## 3. 치마 · 스커트

| 채널 | 브랜드 1 | 브랜드 2 | 브랜드 3 | 검증 근거 |
|------|----------|----------|----------|-----------|
| 네이버 검색 | 스누디 | 트리밍버드 | 딘트 | OneInsight 경쟁사 분석 + 시장 분석 보고서 |
| 구글 검색 | 데일리앤 | enc | 스테파니 | "여성 치마 스커트 브랜드 추천" — 베스트 상품 브랜드 |
| 소셜 미디어 | 아뜨랑스 | 핫핑 | 플레이스 스튜디오 | 치마 쇼핑몰 검색 — 무신사·SNS 몰 노출 |
| 데이터랩 랭킹 | 쓰리타임즈 | 기준 | 인스턴트펑크 | OneInsight 경쟁사 관련성 분석 |
| AI 추천 (Claude) | 스누디 | 아뜨랑스 | UNIQLO | 시장 분석(스포츠·SPA·국내 몰) + SPA 벤치마크 |

**추가 발견**:
- 구글 검색의 치마/스커트는 **대형 쇼핑몰(신세계·SSF·이마트몰) 중심** 노출 + 데일리앤·enc·스테파니 같은 중소 브랜드 혼재
- **테니스스커트**(CTR 모바일 4.42%)·**플리츠스커트**(월검색 18,170) 등 실구매 키워드 중심 니치 확인 (연관키워드 데이터)
- → 대형 SPA와 중소몰 사이의 **"연령대별 전문관(40·50대) × 체형별 핏"** 청정구역 재확인
