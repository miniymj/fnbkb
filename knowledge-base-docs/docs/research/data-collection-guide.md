# 시장조사 데이터 수집 가이드

## 📋 데이터 수집 체크리스트

각 아이템별로 다음 데이터를 수집하세요. 이미 원피스는 대부분의 데이터가 수집되어 있습니다.

---

## 1. 키워드 데이터 (`1. 키워드 데이터/`)

### 1.1 네이버 데이터랩 - 쇼핑인사이트

**접속**: https://datalab.naver.com/shoppingInsights/sCategory.naver

#### 수집 항목:
- [ ] **연관검색어 TOP 50**
  - 검색어 입력: [아이템명]
  - 기간: 최근 12개월
  - 다운로드: 엑셀 파일 (.xlsx)
  - 포함 데이터: 월간검색수, 월평균클릭수, 클릭률, 경쟁정도

- [ ] **성별/연령대별 데이터**
  - 조회기간: 최근 12개월
  - 캡처: 성별, 연령별 검색비중
  - 저장: JPG 파일

- [ ] **월별 검색추이**
  - 조회기간: 2025년 7월 ~ 2026년 6월
  - 다운로드: CSV 파일 + 캡처(JPG)

#### 키워드 리스트:
| 아이템 | 검색어 |
|--------|--------|
| 원피스 | 원피스 ✓ 완료 (잠재고객 분석 포함) |
| 치마 | 치마, 롱치마, 미니치마, 플레어치마 ✓ 잠재고객 분석 완료 |
| 스커트 | 스커트, 롱스커트, 미니스커트, A라인스커트 |
| 샴푸바 | 샴푸바, 바디샴푸, 고체샴푸, 클렌징바 ✓ 잠재고객 분석 완료 |

### 1.2 썸트렌드 데이터

#### 수집 항목:

  - 저장: 엑셀 파일

## 2. 리뷰 분석 (`2. 리뷰 분석/`)

### 2.1 네이버 쇼핑 상위 노출 상품 리뷰

**접속**: https://shopping.naver.com/

#### 수집 방법:
1. 검색어: [아이템명]
2. 상단 노출 상품 1~3위 선택
3. 각 상품의 리뷰탭에서:
   - 별점分布 (1~5점 비율) 캡처
   - 베스트 리뷰 5개씩 캡처
   - 사이즈/품질 관련 키워드 정리

#### 파일명 예시:
```
[아이템]순위1- 리뷰 데이터 1.jpg
[아이템]순위1- 리뷰 데이터 2.jpg
...
```
