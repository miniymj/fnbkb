# AI 브랜드 분석 방법론 — 클로드인크롬 대체 방안

> 강의에서 사용하는 **클로드인크롬**(AI 브랜드 분석 도구)을 사용할 수 없을 때, 같은 목적(브랜드 입체 분석)을 달성하는 대체 절차
> 적용 도구: Claude Code (대화형 AI) + 웹 검색 + 프로젝트 조사 데이터

---

## 1. 왜 대체가 필요한가

클로드인크롬은 브랜드명을 입력하면 소비자 인식·포지셔닝·강약점을 AI가 분석해주는 강의용 도구입니다. 도구 접근권이 없거나 로그인이 불가할 때, 동일한 분석 목적은 **이미 사용 중인 Claude Code**로 달성할 수 있습니다.

---

## 2. 대체 프로세스 (5단계)

| 단계 | 클로드인크롬(원본) | Claude Code 대체 (실행 방법) | 산출물 |
|------|-------------------|------------------------------|--------|
| 1. 브랜드 선정 | 브랜드명 입력 | 분석할 브랜드를 카테고리별 1~2개 선정 (선두 + 2위권) | 분석 대상 리스트 |
| 2. 2차 데이터 수집 | AI가 자체 지식으로 분석 | 웹 검색(`추천/브랜드/리뷰` 검색) + 네이버쇼핑/올리브영 가격·평점 수집 | 채널·가격·평점 근거 |
| 3. 소비자 인식 추출 | AI가 정성 분석 | 리뷰 키워드·토픽(OneInsight 토픽 %) + 긍/부정 워드맵 활용 | 강점·약점 근거 |
| 4. AI 정성 분석 | 클로드인크롬 | **Claude에게 지시**: "브랜드 X의 핵심 고객군, 가격 포지셔닝, USP, 약점, 차별화 요소를 조사 데이터 기반으로 요약해줘" | 분석 결과 표 |
| 5. 검증 메모 | 대시보드 | 수집 데이터·토픽 %와 AI 요약을 대조 → "내 검증 메모" 작성 | 검증 완료 표 |

> 💡 **핵심 원칙**: AI(Claude)의 정성 분석은 반드시 **수집된 데이터(리뷰 토픽 %, 가격, 평점, SNS 지표)로 검증**합니다. AI의 지식만으로 채우지 않고, 근거를 함께 기록합니다.

---

## 3. Claude Code에 보낼 프롬프트 템플릿

```
다음 조사 데이터를 바탕으로 브랜드 [브랜드명]의 분석을 수행해줘.

[조사 데이터 입력 — 아래 항목을 붙여넣기]
- 경쟁사 관련성 분석 표 (성분·가격대·친환경 등 강도)
- 소비자 토픽 Top (%, 예: "업사이클링 포장재 73.8%")
- 가격/평점/리뷰 수
- SNS 팔로워·콘텐츠 방향

분석 항목:
1. 핵심 고객군 (누가 사는가, 연령·성향)
2. 가격 포지셔닝 (가격대, 가격 민감도)
3. 주요 강점 (USP + 소비자 반응 근거)
4. 주요 약점 (소비자 반응 근거)
5. 차별화 요소 (남들이 안 하는 것)

각 항목에 "데이터 근거"를 반드시 포함해줘.
```

## 5. 한계와 보완

| 한계 | 보완 방법 |
|------|-----------|
| AI 지식의 시점 한계 | 웹 검색으로 최신 가격·리뷰·신제품 확인 |
