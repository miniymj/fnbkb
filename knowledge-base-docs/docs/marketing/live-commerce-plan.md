## 3. 방송 구성

### 오프닝 (첫 5분)

- 인사 + 셀프 소개 (브랜드 스토리 30초 버전)
- 오늘 방송 혜택 3가지 미리 예고: "20% 할인, 무료배송, 댓글 이벤트"
- 시청 유도: "좋아요·알림 눌러주시면 다음 방송 놓치지 않아요"

### 라이브 혜택 (이벤트 기획)

1. **할인 혜택**: 20% 할인 + 무료배송
2. **이벤트 고지**: 댓글왕 / 퀴즈왕 / 구매왕
   - 댓글왕: "여름에 옷 고를 때 제일 불편한 점" 댓글 → 3명 사은품
   - 퀴즈왕: "이 원피스 허리의 비밀은? (정답: 스트링)" → 정답 댓글 중 5명
   - 구매왕: 구매 금액 1위 → 다음 방송용 쿠폰

### 상품 구성 소개 순서

```
오프닝 → 라이브혜택 → 상품구성 → 제품장점/차이점 → 왜 사야되는지 → 스토리 → 이벤트 마무리
```

### 상품 안내

- **상품소개 판넬 활용** (자막으로 대체해도 좋음)
  - 가격/할인가/구성/사이즈 정보 자막 상시 노출
- **상품 핵심요약 자막**
  - "바람 통하는 린넨 · 몸매 부담 ZERO · 스트링으로 허리선"

### 제품 장점 / 차이점 실연

- **스트링 전·후 비교 시연** — 묶기 전(편안 모드) vs 묶은 후(실루엣 모드) 같은 옷 두 가지 연출
- **치맛단·소매 흔들기** — 바람에 살랑이는 모습으로 "시원함" 시각화
- **앉고 일어나기·팔 올리기** — 활동성·몸매 부담 없음 증명

### 왜 사야 되는지

- 한여름 최고 더위 시기 — 지금 사야 여름 내내 입음
- 라이브 가격은 이번 방송만 (20% 할인 종료 예고)
- 색상별 한정 수량

### 스토리

> "저도 편한 옷만 입다가 '예쁘고 싶다'는 마음을 포기하면서 살았어요. 그래서 만들었어요. 편한데, 밋밋하지 않게 포인트를 넣은 옷. 스트링 하나로 편할 때는 편하게, 예쁠 때는 예쁘게. 같은 고민 하는 분들이 이 옷을 입고 '나 예쁘다'라고 느꼈으면 좋겠어요."

### 방송 전략

1. **(대본)** — Padlet 라이브커머스 프롬프트로 생성 (아래 5번)
2. **(의상)** — 호스트가 직접 메인 상품 착용 (스트링 묶은 상태로 시작 → 중간에 풀어서 변신 연출)
3. **(컨셉)** — "시원하고 편한데 예쁜 옷" = 무더위 해결 방송. 과장보다 진정성
