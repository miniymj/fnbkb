## 🧴 1. 하이피부(HIGHSKIN) — 바디바

### 타겟 고객
- **1차**: 30~40대 엄마(온가족 케어 담당) — 아이·남편과 함께 쓸 안심 바디케어
- **2차**: 민감피부 소비자 · 여행·셀프케어 선호자
- **성격**: 즐거움을 중시하지만 "씻어도 괜찮을" 안심도 요구 — 위글위글(재미)과 동구밭(자연) 사이

### 카테고리
- 바디바 / 솔리드 샴푸바 — 친환경 클린뷰티 (용기 제로 · 리필 구조)

### 차별점 (경쟁사 대비)
| 경쟁사 | 이미지 | 하이피부 차별 |
|---|---|---|
| 톤28 · 동구밭 | 소박한 제로웨이스트(딥그린) | 귀여움·즐거움 + **리필 편의** (무거운 자연주의 대신) |
| 아로마티카 | 쿨 클린뷰티(화이트·블랙) | 따뜻한 핑크 아이덴티티 + 캐릭터 |
| 러쉬 | 블랙+네온 팝 | 소프트 파스텔 안심 |
| 위글위글 | 고채도 팝아트 | **캐릭터성만 차용**, 색은 안정적으로 |
- **핵심**: 핑크 아이덴티티 + 리필 홀더(반복구매) + 여행 미니 세트 + 픽커 퀴즈(참여·전환)

## 👗 2. 치마(SKIRT) — Confident Curation

### 타겟 고객
- 19~45세 여성 **3세그먼트**: 대학생 취준생(29%·면접) · 직장인(22%·오피스) · 하객(26%·웨딩홀)
- 체형 다양성: 155~172cm · 44~99사이즈 — "체형에 맞는" 자신감

### 카테고리
- 여성 스커트 — **상황별 큐레이션 전문관** (기성복이 아닌 "맞춤 안내")

### 차별점
- **상황(면접·하객·오피스) × 체형(키·밴딩) 이중 큐레이션** — "첫인상의 3초"를 위한 선택
- 컬러: 넌 트루 네이비(깊이·전문성) + 웜톤(따뜻한 접근성) — 경쟁사(스누디·UNIQLO·데일리앤)의 **무채색/블랙 범용과 명확한 분리**

---

## 🌊 3. 원피스(RESORT ONESIE) — Garden Sea

### 타겟 고객
- 40·50대 여성 (빅사이즈 중심) — 체형 스트레스 해소 · 자신감 회복 · 휴양지 여행 수요
- 사이즈 인클루시브: 44~120 전 사이즈

### 카테고리
- 휴양지원피스 (해변·리조트·여행) — **사이즈프리**

### 차별점
- **사이즈프리(44~120) + 조절식 웨이스트** — 체형과 디자인, 양자택일 없음 ("포용의 바다")
- 컬러: 라군 블루(여유·신뢰) + 웜톤 — 경쟁사(케네스레이디·써스데이아일랜드)의 **격식·트렌디와 분리**

## 🧭 포지셔닝 맵 (자연주의 ↔ FUN ↔ 프리미엄)

```
          자연주의
            ↑
   동구밭     │    아로마티카(프리미엄·쿨)
   ·톤28      │
─────────────┼────────────→ 프리미엄
       하이피부 ● (Natural+Fun+Family)
   위글위글    │
            ↓
            FUN
```
- **하이피부**: 귀여움(위글위글)과 자연(동구밭)의 중간 — "즐거운 가족 웰니스"
- **치마**: 상황별 전문성 — 무채색 범용(UNIQLO류) 대비 **네이비+웜톤 감성**
- **원피스**: 포용(사이즈프리) — 격식(케네스레이디) 대비 **여유·바다 무드**
