## 2. 상품 등록 데이터 (SEO)

### 상품명 공식
```
[브랜드] + [아이템] + [전환 키워드] + [핵심 기능] + [용량/사이즈]
예) 바디바 민감피부용 알레르기프리 고체 샴푸바 80g
```

### 전환 키워드 매핑 (시장조사 데이터 근거)

| 아이템 | 전환 키워드 (모바일 CTR) | 활용 |
|---|---|---|
| 바디바/샴푸바 | 샴푸바, 고체샴푸, 클렌징바, 바디샴푸, 민감피부 | 대표어 CTR 낮음 → 니치어 결합 필수 |
| 스커트 | 테니스스커트(4.42%), 플리츠스커트(2.27%), 롱스커트, 청치마 | "치마+스커트" 이중 검색어 병기 |
| 원피스 | 하객룩(4.31%), 오피스룩(3.4%), 비치웨어(8.54%), 빅사이즈원피스 | "빅사이즈+휴양지" 결합 키워드 선점 |

> 상품명·태그·광고에 같은 키워드 세트를 일관 사용 (검색 유입 일치).

### AI 검색 최적화(GEO) 체크리스트 — ChatGPT·네이버 AI쇼핑 추천 대비

> 근거: Criteo×OpenAI 광고는 **경쟁 입찰 없이 관련성 기반**으로 노출 → 입찰가가 아니라 **상품 피드 품질**이 승부처 (`ai-performance-insights.md` §5)

- [ ] 상품명에 **누가·언제·무엇에** 녹이기 — "키즈 여행용 고체 샴푸바 50g" (AI가 쿼리와 매칭할 메타데이터)
- [ ] **카테고리 1개로 확정** — AI 추천의 1차 필터, 애매하면 대표 카테고리로
- [ ] **속성(옵션) 전부 입력** — 용량·사이즈·향·소재 = "상황에 맞는 상품"을 고르는 근거
- [ ] 상세설명 **첫 3문장에 핵심 정보** (사용 상황·타겟·차별점) — AI가 요약해 답변에 사용
- [ ] **후기 키워드 관리** — AI 추천의 근거로 리뷰 문장이 쓰임
- [ ] 분기 1회 셀프 테스트: ChatGPT에 "【내 상품 키워드】 추천줘" → 내 상품 언급 여부 점검

## 3. 상세페이지 구조 (모바일 퍼스트 8섹션)

1. 첫 화면: 브랜드 한 문장 + 제품 이미지 (3초 내 가치 전달)
2. 고객 불만 → 솔루션 (사용법 낯섦 → 거품망·드레인팁 번들)
3. **성분표 큐레이션** (디자이너의 눈 해석 — 우리 USP)
4. 신뢰 신호 (알레르기 검증 근거·비건 인증·후기 수)
5. 사이즈/용량 선택 옵션 (SKU: 30g·80g·100g·120g)
6. 세트·번들 유도 (객단가·무료배송 기준 달성)
7. 사용 후기 배치 (실측 리뷰 — 체험단 후기)
8. FAQ + 배송·반품 안내

## 4. 검색광고(SA) 운영 — 목표 설정 → 학습 → 테스트 (Criteo GO 인사이트 적용)

> 🤖 상세 배경: `ai-performance-insights.md` §3~§4 — 이 섹션은 그 실행 요약

### 4-0. 목표 먼저 고르기 (광고 만들기 화면을 열기 전)

| 단계 | 목표 | 네이버 최적화 목표 | 전환 조건 |
|---|---|---|---|
| 1 | 방문 최적화 (Criteo BVO) | 클릭 최적화 | 신생 스토어·리뷰 0~20건 |
| 2 | 전환 최적화 (BCO) | 구매 전환 최적화 | 전환 데이터 축적 후 |
| 3 | 목표 비용 (ACO) | 목표 CPC/CPA | 원가 구조 확인 후 |
| 4 | 목표 수익 (ARO) | 목표 ROAS | 마진율 기준 지출 한도 산출 후 |

> **하이피부 경로**: 첫 달 방문 → 리뷰 20건 + 전환 데이터 → 전환 → 마진율 55% 확정 후 ROAS.

### 4-1. 초기 구성 (3단 셋업 — "3단계·10분")

- [ ] **① 목표·예산** — 위 표에서 1개 + 일 예산 10,000원 (월 30만원) · 손실 한도 확정
- [ ] **② 콘텐츠 자동 생성** — 키워드 3층(브랜드어→카테고리어→니치어) + AI 소재(nstore-* 이미지·카드뉴스 E2c) + 광고 문구는 상품명 공식 재사용
- [ ] **③ 런칭 + 추적** — UTM 발행 (`utm_campaign = 연도-월_테마_booster`) 후 **1주일 뒤 첫 진단**

- 광고 문구: "민감피부도 안심 / 알레르기 유발 성분 배제" — **`compliance-checklist` §4 확인 후 사용**
- 실시간 인기검색어 → SA 키워드 반영 루프 (월 1회)

### 4-2. 학습기간(램프업) 규칙 — 첫 2~10일은 참는다

| 기간 | OK | 금지 |
|---|---|---|
| D0~D3 | 데이터 수집만 | 예산 변경·중단 ❌ (학습 리셋) |
| D4~D10 | 노출·클릭 흐름 확인 | 키워드 대폭 수정 ❌ |
| D11~ | 첫 진단 (CTR·CPC·전환수) | 수정·확장 ✅ |

### 4-3. 순차 테스트 — 수동 4주 → 자동 4주 (동일 예산·목표)

| 주차 | 모드 | 기록 지표(주 1회) |
|---|---|---|
| 1~4주 | 수동 (키워드 직접 선정·입찰 조정) | CTR · CPC · 전환수 · ROAS |
| 5~8주 | 자동 (스마트 자동화 상품, 동일 예산·목표) | 동일 |
| 8주 후 | 우위 모드를 **Always-On 베이스**로 채택 | — |

> 두 모드 동시 운영 금지 — 예산 분산으로 비교 무의미. Criteo 사례: 자동화 전환 시 CPA −62%.

### 4-4. Always-On + 시즌 부스터 (월별 이슈 캘린더 연동)

- **Always-On 베이스**: 캘린더 priority Mid/Low 달 — 소액 자동화 상시, 손대지 않음
- **부스터**: priority High 달(설·가정의달·여름휴가·추석·연말) — 예산 상향 + 수동 정밀 타겟 + 시즌 크리에이티브
- 시즌 종료 후 **베이스 예산으로 복귀** (올린 채 방치 = 지출 누수 1위)

## 7. KPI 대시보드 (주간 점검)

- 방문수 · 클릭수 · 전환율 (네이버 애널리틱스)
- 주문건수 · 리뷰수 · 평점
- 광고 ROAS = 광고매출 ÷ 광고비
- 재구매율 (월 1회 집계 → 목표 30%)
- **유입 소스별 성과** — 모든 링크에 UTM 규칙 적용 (`ai-performance-insights.md` §7: `utm_campaign = 연도-월_테마_booster`) → 캘린더 priority와 대조해 어느 달 광고가 먹혔는지 구분
