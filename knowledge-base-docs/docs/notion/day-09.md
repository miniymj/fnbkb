GEO : AI 인용
GEO(생성형 엔진 최적화, Generative Engine Optimization) 기반 홈페이지 설계는 AI가 검색 결과에서 자사 콘텐츠를 정확히 이해하고 신뢰할 수 있는 출처로 인용하도록 구조화하는 작업

AI 답변 채택 - 신뢰 (근거 -인증서, 지표 등- 알러지 프리) 피부에 좋다
AI(Chat gpt, 에이전트 N…)사이트 마다 신뢰가 가는 근거 있는 정보를 보는 기준이 다르다. 
근거가 있는가? 결과를 보여줘야 하는게 있고 이미 나온걸 가지고 결과로 만들어서 보여주는 방법
근거가 일치하는 정보인가?
AI : 홈페이지, 블로그, 인스타그램, 유튜브, 틱톡, 쇼핑몰, 저널(잡지), 언론보도 기사, 학술지, 논문, 책
신뢰 - 비교 제품을 조사해서 수납력이 좋다는 결과를 보여줌
정보의 일치성 - 사이트들 소개 내용을 일정하게 작성하여  AI가 근거가 있는 정보를 수집함
예를 들어 사이트 설명에서 27년의 경력이라고 해놓고 해가 넘어가서 수정을 안해놨을때 정보 불일치라고 함 (그냥  since 1997 이라고 해놓는게 좋음)
많은 AI 프로그램 중 고아라 선생님은 chat.gpt의 기준으로 이야기함
GEO - 챗지피티 / 네이버 GEO (외부채널) : 둘다 인용이 가능한 홈페이지를 먼저 만든다
(GEO에 적합한) 홈페이지 → 상세페이지(상품)→ 소셜미디어 홍보 콘텐츠 순서로 만들 예정
정리 하자면 홈페이지는 모든 AI 인용이 가능함
쇼핑몰 - 자사몰(카페24), 입점몰(스마트스토어, 쿠팡, 에이블리, 29cm, 무신사…) ,AI는 네이버는 크롤링을 안되서 따로 인용
홈페이지 - 홈페이지만, 바이브코딩 → 검색반영신청
홈페이지: 이 브랜드는 누구인가 , 상세페이지
연결: 1) 어떤 질문의 답인가(고객이 묻는 질문과 우리 페이지를 잇는다) → 2) 근거: 왜 믿을 수 있나(’좋다’ 대신 숫자,항목,표로 뒷받침) → 3) 신뢰: 믿어도 되는가(사업정보, 출처, 리뷰로 신뢰를 만듬)
GEO마케팅: 홈페이지(브랜드) → 상세페이지(상품) (자사몰,에이불리, 스마트스토어) → 콘텐츠(정보 콘텐츠) 블로그, 유튜브(제일 신뢰함) - 스트립트 , 인스타그램
통이미지 ( 상품 기본 정보 입력) 분할이미지 사이 중간에 텍스트를 넣어서 만듬 - 블로그형 상세페이지 (텍스트, 사진)
