## 1. 스튜디오 장비 및 촬영 환경 세팅

- **마이크(BOYA) & 스튜디오(MATA STUDIO)**: 5만 원 상당의 장비로 깨끗한 음성 수집 환경 구축
- **카메라 세팅**: 캐논(Canon) 카메라로 촬영, 수동 모드로 직접 제어
- **조명 세팅**: 조명 활용 촬영 환경 조성
- **촬영 장비 세부**:
  - **DJI 오즈모 3 (짐벌)**: 3축 안정화 — 흔들림 없는 영상
  - **노출 보정**: 촬영 시 화면이 **10~15% 정도 어둡게** 보이도록 세팅 (하이라이트 날림 방지 — 후보정 여유 확보)
  - **필터(Lookspace)** 사용 예정

## 2. 삽입(Insert) 영상과 Clipchamp 편집 작업

- **삽입 영상(B-roll) 확보**: 본 영상(주 내용) 외에 중간중간 삽입할 보조 영상(풍경 등)을 촬영해 확보
- **배경 음악 삽입**: 오디오(사운드트랙) 삽입, 저작권 없는 무료 음원 사용
- **자막 작업**: 음성 인식(스크립트) 기반 **자동 자막 생성** 후, 오류는 수동 수정
- **AI 편집 도구 활용**: Clipchamp의 **스톡(Stock) 영상**, **텍스트→음성 변환(TTS)** 등 부가 기능 활용

## 3. 파일 확장자(포맷) 및 관리

- **MOV 포맷**: 고용량 고품질(무손실) — **원본 그대로 보관용**에 최적
- **이미지 확장자 변환 순서**:
  ```
  BMP (원본 무손실) → JPG (손실 압축, 웹 게시용) → PNG (무손실, 투명 배경 지원)
  ```
- **텍스트 파일 관리**: 한글(HWP)과 MS 워드(DOCX) 모두 사용 가능하며, 텍스트는 **UTF-8**로 저장 권장 (호환성)

## 4. 썸네일 및 미리보기 이미지 전략

- **썸네일 제작**: 채널 방문자들이 가장 먼저 보는 이미지 — 채널 아이덴티티를 반영해 일관성 있게
- **클릭 유도 요소의 우선순위**:
  1. **사람 얼굴** (감정이 표현된)
  2. **큰 텍스트**
  3. **색 (고채도)**
  4. **반전/대비 요소**
- **썸네일 촬영 장비**: 75mm 렌즈 활용 (배경 압축·인물 부각), 관련 비용 약 320만 원 규모 언급
- **최종 '스토리보드' 협업**: 컨셉을 미리 공유하고 "이런 느낌으로 갈 거야"를 정한 뒤 촬영·편집 진행 — **기획의도(다리)를 먼저 확정하는 KCCA 원칙과 동일한 맥락**

## 5. AI 이미지 생성 및 콘텐츠 확장

- **레퍼런스 기반 생성**: 실제 사진을 AI로 변환·활용하는 워크플로우
- **이미지 생성 도구**: 최신 AI 모델 활용
- **작업 3단계 프로세스**:
  ```
  [1단계] 콘텐츠 PNG 이미지 확보 (기본 소재 생성)
      ↓
  [2단계] 캐릭터 성형(합성) 작업 — 소재를 조합·변형
      ↓
  [3단계] Higgsfield AI로 최종 결과물 '컷' 생성
  ```

> 💡 **Higgsfield**: 실존하는 AI 영상·이미지 생성 도구. 카메라 무브먼트(프롬프트 기반 촬영 기법) 제어가 강점

## 6. AI 영상 제작 실습 사례 (힉스필드 슈퍼컴퓨터 · 구글플로우)

### 힉스필드 (Higgsfield)

- 여러 AI 프로그램이 연결되고 기능이 많은 **AI 허브형 도구**
- 최근 **"슈퍼컴퓨터(Supercomputer)"** 라는 신기능이 새로 나옴
- **혼다(Honda) 영상 따라 만들기 실습**: 카톡에 공유된 자막 없는 유튜브 혼다 영상을 참고해, 이미지 **3장만** 가지고 제작
  - 카메라 촬영 전혀 없이, **빈 손가락에 너트가 "퐁" 하고 생기고** → 손을 이리저리 움직이면 → **엔진으로 변신**하는 모습
  - 마치 **트랜스포머 방식**으로 보여주는 **10초짜리 영상** 생성
  - 프롬프트 예시: *"이 세 장의 이미지를 가지고 카메라는 전혀 없이 빈 손가락에 너트가 퐁하고 생기고 그게 손을 이리저리 움직이니까 엔진으로 바뀌어버리는 모습을 마치 트랜스포머의 방식으로 보여주는 10초짜리 영상으로 만들어줘."*

### 구글플로우 (Google Flow) 제작 사례

- **신비한건축사전**: 구글플로우에서 만든 영상 (선생님 제작)
- **하남지식센터 홍보영상**: 하남에 있는 하남지식센터 홍보영상 제작 — 구글플로우로 만듦
- **방배동 GOLD 신축건물 홍보영상** (유튜브):
  1. **실제 드론으로 촬영한 영상**
  2. **네이버지도 길찾기 영상** (화면 녹화)
  3. **도면을 받아 AI로 만든 내부 건물 이미지** 영상
  - → 실사 촬영 + 지도 소스 + AI 생성 이미지를 조합한 하이브리드 방식

